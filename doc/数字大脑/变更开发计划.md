# 数字大脑变更开发计划

## 一、变更背景

### 1.1 MVP 实施总结

MVP 阶段已完成：
- LearnableTokenizer 可学习分词
- 知识包驱动学习模式（1plus1 / grade1_math / grade1_chinese）
- 空白脑启动 + 人工 learn 触发学习
- 76 个 pytest 全部通过

### 1.2 发现的问题

从 `1+1=?`（直接算式）到 `爸爸的年龄31，妈妈的年龄25，他们的年龄之和是多少？`（应用题），暴露 5 个层面差距：

| # | 问题 | 根因 |
|---|------|------|
| 1 | 词素知识两份拷贝 | LearnableTokenizer 有独立 known_morphemes，与知识图谱重复 |
| 2 | 模式硬编码 | PatternMatcher._register_defaults() 写死在代码里 |
| 3 | 算法硬编码 | AlgorithmRegistry 5 个算法是代码实现，不能通过学习组合 |
| 4 | 单步推理 | 一个输入→一个意图→一个算法→输出，不支持多步推理链 |
| 5 | 无工作记忆 + 无持久化 | 上下文丢失 + 重启丢失 |

### 1.3 变更目标

- 知识图谱成为唯一知识来源
- 模式、算法步骤、推理DAG全通过知识包学习
- DAG推理：问题→问题DAG（理解）→DAG执行（求解）
- 工作记忆支持上下文和中间结果
- 记忆固化到硬盘，启动时恢复

## 四、验证标准

### 4.1 基本功能验证

```
空白脑问 "1+1=?"          → 无法回答 ✓
learn base_curriculum
问 "1+1=?"                → 答案 2 ✓
问 "3+5=?"                → 答案 8 ✓
问 "一加一等于多少"         → 答案 2 ✓
```

### 4.2 应用题验证

```
问 "爸爸的年龄31，妈妈的年龄25，他们的年龄之和是多少？"
→ 答案 56 ✓
→ 推理链: 绑定→绑定→消解→检索→检索→加法 ✓
```

### 4.3 "不理解"验证

```
问 "光速是多少？"
→ 无法回答 ✓
→ 提示：缺少"光速"相关知识 ✓
```

### 4.4 持久化验证

```
learn base_curriculum → 退出 → 重启
问 "1+1=?" → 答案 2 ✓（知识还在）
```

### 4.5 回归验证

```
全量 pytest ≥ 76 通过 ✓
```
