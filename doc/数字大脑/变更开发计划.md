# 数字大脑变更开发计划

## 一、变更背景

### 1.1 MVP 实施总结

MVP 阶段已完成：
- LearnableTokenizer 可学习分词
- 知识包驱动学习模式（1plus1 / grade1_math / grade1_chinese）
- 空白脑启动 + 人工 learn 触发学习
- 76 个 pytest 全部通过

### 1.2 发现的问题

从 `1+1=?`（直接算式）到 `爸爸的年龄31，妈妈的年龄25，他们的年龄之和是多少？`（应用题），暴露 5 个层面差距：

| # | 问题 | 根因 |
|---|------|------|
| 1 | 词素知识两份拷贝 | LearnableTokenizer 有独立 known_morphemes，与知识图谱重复 |
| 2 | 模式硬编码 | PatternMatcher._register_defaults() 写死在代码里 |
| 3 | 算法硬编码 | AlgorithmRegistry 5 个算法是代码实现，不能通过学习组合 |
| 4 | 单步推理 | 一个输入→一个意图→一个算法→输出，不支持多步推理链 |
| 5 | 无工作记忆 + 无持久化 | 上下文丢失 + 重启丢失 |

### 1.3 变更目标

- 知识图谱成为唯一知识来源
- 模式、算法步骤、推理DAG全通过知识包学习
- DAG推理：问题→问题DAG（理解）→DAG执行（求解）
- 工作记忆支持上下文和中间结果
- 记忆固化到硬盘，启动时恢复

## 六、Phase 5:统一激活引擎

### 6.1 变更背景

Phase 4 完成后,跑小学应用题"小明书包里有4本故事书,妈妈又给他买了3本。小明现在一共有多少本故事书?" 暴露架构根本问题:

- 意图无法识别,fallback 到 counting 算法对最后激活数字 [3] 计数,错误返回 3
- 进一步分析:`PatternMatcher / DAGBuilder / DAGExecutor / AlgorithmRegistry` 四类解释器构成"领域特定的硬编码脑区",违反脑科学范式
- 知识图谱在这四类眼里只是查表数据库,真正解题的是 Python 类的 if/elif 分发

依据 [自由神经网络.txt](../自由神经网络.txt) 与 [总述.txt](../总述.txt):脑皮层只有神经元+突触+激活扩散,不存在"模式匹配脑区""DAG构建脑区"。

### 6.2 设计目标

消除四类解释器,统一为**单一机制:激活扩散 + 程序性记忆触发**。详见 [详细设计/统一激活引擎设计.md](详细设计/统一激活引擎设计.md)。
