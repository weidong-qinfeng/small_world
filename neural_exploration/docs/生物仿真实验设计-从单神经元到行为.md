# 生物仿真实验设计：从单神经元到行为（电子神经网络逼近真实大脑）

> 版本：v0.1（整体实验设计稿）
> 核心科学问题：**能否用尽量复刻真实神经元结构与特性的确定性神经网络，在行为层面逼近真实生物？**
> 实验路线：单神经元 → 突触/神经元对 → 最小行为回路（反射弧）→ 全连接组生物（秀丽隐杆线虫 C. elegans）→ 学习与可塑性 → 更复杂网络。
> 验证金标准：每一层都用**真实生物行为学数据**做对照，能复现行为才算"达到效果"。

---

## 一、背景与动机

### 1.1 为什么从概率模型转向生物仿真

现有路线（无论纯符号派还是统计-符号混合）的本质问题：**模型对世界的"理解"建立在概率/枚举之上**——统计模型输出概率分布，符号模型枚举规则。两者都无法回答一个根本问题：

> 人脑作为一个物理系统，究竟是怎么"理解"的？

神经科学的一个基本事实：**神经元不是概率推理单元，而是确定性动力学系统**。
- 膜电位由离子通道动力学决定（Hodgkin–Huxley 方程是确定性的）
- 动作电位是否发放，由膜电位是否越过阈值决定（确定性）
- 网络层面的"不确定性"来自：突触量子释放的概率性、通道随机开闭的噪声、高维混沌动力学——**是局部的、物理的随机，不是参数层面的概率推理**

本实验的目标：**自底向上搭建一个尽量复刻真实生物神经系统的电子神经网络，以生物行为为验证标准，检验"确定性动力学 + 局部物理随机"能否涌现出智能行为。** 如果它能复现真实生物的行为（趋化、逃避、学习），就证明智能不需要概率推理引擎，只需要真实的结构和动力学。

### 1.2 为什么从 C. elegans 开始

| 理由 | 说明 |
|---|---|
| 连接组完全已知 | 302 个神经元、~7000 化学突触 + ~700 缝隙连接，全图已解析（White 1986；Cook 2019） |
| 行为库完整 | 趋化、机械逃避、趋温、进食、交配、习惯化、联想学习，都有定量行为学数据 |
| 规模可仿真 | 302 神经元在单台 CPU 上即可实时仿真（比果蝇 10 万、小鼠 7000 万小几个数量级） |
| 从基因到行为 | 每个神经元的类型、神经递质、连接已知 → 不需要"猜测"网络结构 |
| 有真实"电子孪生"先例 | OpenWorm 项目已尝试全连接组仿真——我们站在其经验上，但强调**逐层验证** |

### 1.3 实验哲学：三条铁律

1. **自底向上，逐层验证**：每一层（离子通道→神经元→突触→回路→行为）必须先通过该层的生物验证，才能进入下一层。不允许"跳层"——因为每层都有独立的物理规律。
2. **保真度与验证绑定**：建模精细度由"该层能否用现有行为学数据验证"决定。比如单神经元层需要复现动作电位波形（需要 HH 模型），但如果某行为只需膜电位阈值就能复现，就不为它引入更精细模型。**不为精细而精细，只为可验证而精细。**
3. **确定性与随机性分层**：神经元动力学（离子通道、膜电位）用**确定性方程**；突触传递（囊泡释放、受体结合）用**局部概率模型**（量子释放）。两者都是物理事实，不把"概率"上升到推理层。

## 二、多尺度建模框架（5 层）

```
┌─────────────────────────────────────────────────────────┐
│  L5 行为层：虚拟身体 + 环境（食物梯度、机械刺激、温度场）   │
├─────────────────────────────────────────────────────────┤
│  L4 网络层：连接组（connectome）+ 网络动力学 + 可塑性      │
├─────────────────────────────────────────────────────────┤
│  L3 回路层：感觉神经元 → 中间神经元 → 运动神经元（反射弧）  │
├─────────────────────────────────────────────────────────┤
│  L2 突触层：化学突触（量子释放/受体动力学）+ 电突触(缝隙)   │
├─────────────────────────────────────────────────────────┤
│  L1 神经元层：Hodgkin–Huxley 多隔室模型（胞体/树突/轴突）   │
├─────────────────────────────────────────────────────────┤
│  L0 离子通道层：Na/K/漏电流动力学 + 静息膜电位            │
└─────────────────────────────────────────────────────────┘
```

### L0 离子通道层（物理基础）

- **静息膜电位**：Nernst 方程
  $$E_X = \frac{RT}{zF}\ln\frac{[X]_{out}}{[X]_{in}}$$
  （37°C 时 RT/F ≈ 61.5 mV；K⁺ 平衡电位 ~ -77 mV 主导静息电位 ~ -70 mV）
- **离子通道模型**：电压门控 Na⁺（激活+失活）、延迟整流 K⁺、漏电流 —— Hodgkin–Huxley 1952 参数：
  - gNa=120 mS/cm², gK=36, gL=0.3；ENa≈+50mV, EK≈-77mV, EL≈-54.4mV
- **可选扩展**：Ca²⁺ 通道（L 型/T 型）、A 型 K⁺ 通道（树突）、通道随机开闭（Langevin/马尔可夫门控）——按验证需求引入

**本层验证标准**：模拟动作电位波形（峰值、超射、上升/下降速率、不应期）与 HH 1952 原始电压钳实验数据逐点对照，误差 < 5%。

### L1 神经元层（细胞结构）

- **多隔室模型**：胞体（soma）+ 树突（dendrite）+ 轴突（axon）+ 郎飞结（node of Ranvier）
- 每个隔室有自己的膜面积、电容（~1 µF/cm²）、离子通道密度
- 空间传导：电缆方程（cable equation）描述电位沿树突/轴突的被动传播
- **确定性核心**：膜电位方程
  $$C_m\frac{dV}{dt} = -\sum g_i(V - E_i) + I_{syn} + I_{inj}$$

**本层验证标准**：① 胞体注入电流 → 动作电位发放频率-电流曲线（f-I 曲线）与生物数据一致；② 树突输入 → 胞体 PSP 的时间/幅度与实验一致。

### L2 突触层（神经元间通信）

- **化学突触**（主要，C. elegans 的 7000 个）：
  - 突触前：动作电位 → Ca²⁺ 内流 → 囊泡释放（**量子化，泊松过程**——这是"局部随机"的来源）
  - 突触后：递质→受体（兴奋性：谷氨酸/乙酰胆碱 → AMPA 型快速去极化、NMDA 型慢+Mg²⁺ 阻断；抑制性：GABA → Cl⁻ 内流超极化）
  - 突触延迟 ~0.5–2 ms；释放失败概率（失败率）
- **电突触/缝隙连接**（C. elegans 特有且大量，~700 个）：
  - 连接蛋白（connexin/innexin）形成的缝隙连接，快速、双向、可整流
- **可塑性（M6 引入）**：
  - STP 短期可塑性：突触易化/抑制（几十 ms~秒）
  - STDP 时序依赖可塑性：ΔW ∝ exp(-|Δt|/τ)（LTP/LTD）—— 学习的物理基础

**本层验证标准**：① 单刺激 → EPSP/IPSP 波形与文献对照；② 高频刺激 → 短期易化/抑制曲线；③ 释放失败 → 成功概率与量子大小符合二项/泊松分布。

### L3 回路层（最小行为单元）

- 最简反射弧（3–5 神经元）：感觉神经元 → 中间神经元 → 运动神经元 → 肌肉
- C. elegans 实例：**触觉逃避回路**（身体触碰 → PLM/ALM 感觉神经元 → AVM/PVM 中间神经元 → 背/腹运动神经元 → 后退/前进）
- 目的：验证"确定性神经环路能产生行为"的最基本前提——**刺激-反应映射的可重复性**

**本层验证标准**：机械刺激 → 反应方向/潜伏期/强度-响应曲线与行为学数据一致。

### L4 网络层（连接组 + 动力学）

- 载入 C. elegans 全连接组（302 神经元：感觉 ~70 / 中间 ~80 / 运动 ~110 / 咽部 ~20；化学突触 + 缝隙连接）
- 神经元按真实类型配置递质/受体（乙酰胆碱/谷氨酸/GABA/多巴胺/血清素）
- 网络动力学：同步发放、节律生成（咽部节律、爬行节律 CPG）、状态转换

**本层验证标准**：① 网络静息态发放率分布与电生理记录一致；② 局部回路节律（如咽部泵动节律）频率与生物一致；③ 无刺激时的自发行为时间分布（前进/后退/转弯比例）与行为学数据一致。

### L5 行为层（虚拟身体 + 环境）

- **虚拟身体**：把运动神经元输出映射为肌肉收缩 → 身体姿态（正弦爬行/后退/转弯）
- **虚拟环境**：
  - 二维平面 + 食物梯度（趋化实验）
  - 机械刺激点（逃避实验）
  - 温度场（趋温实验）
- 闭环：感知（感觉神经元）→ 处理 → 运动 → 环境反馈

**本层验证标准（最高金标准）**：在虚拟环境中，仿真虫的**趋化指数、转向频率、逃避概率、习惯化曲线**与真实 C. elegans 行为学数据统计一致（p>0.05 或误差 < 20%，按指标定）。

## 三、验证标准总则

### 3.1 "准确"的定义

本实验对"准确"的可操作定义：**行为层面统计一致**——
- 不是要求仿真虫与真实虫逐神经元状态一致（那既不可能也无意义）
- 而是要求：**在同样的环境刺激下，仿真虫的行为指标分布与真实虫的行为学数据在统计上不可区分**

### 3.2 每层验证原则

| 层 | 对照数据来源 | 指标 | 通过线 |
|---|---|---|---|
| L0/L1 | HH 1952 电压钳原始数据；文献 f-I 曲线 | 波形/频率误差 | <5% |
| L2 | 突触生理学文献（EPSP 幅度/时间常数、失败率） | 波形/概率分布 | <10% |
| L3 | 反射弧行为学（潜伏期、强度-响应） | 方向/潜伏期/斜率 | 一致（统计） |
| L4 | 电生理记录（发放率、节律频率） | 分布/频率 | <20% |
| L5 | 行为学文献（趋化指数、转向率、习惯化） | 统计一致性 | p>0.05 或 <20% |

### 3.3 失败即反证（重要的科学价值）

如果某一层无法通过生物验证，**这不是实验失败，而是有价值的科学结论**：
- 例如：若 HH 模型 + 真实连接组无法复现趋化行为 → 说明"确定性动力学假设"不完整，需要引入更高保真度（如神经调质浓度、胶质细胞、更细的空间结构）
- 每一层都有明确的"反证路径"，保证实验不是自我实现的预言

## 四、里程碑规划（长期，每个可独立交付）

> 预估总周期 12–24 个月（单人全职，含学习曲线）。每个里程碑有明确 Pass/Fail 标准，未通过不得进入下一阶段。

### M0：工具链与环境（第 1–2 周）
- 选定仿真引擎（见 §五），搭建统一评测框架（数据集加载、指标计算、可视化）
- 复现一个已发表的 C. elegans 局部回路仿真（作为引擎正确性冒烟测试）
- **交付**：可运行的最小闭环（1 感觉神经元 → 1 运动神经元 → 虚拟肌肉）；评测框架骨架
- **Pass**：最小闭环能对刺激产生响应

### M1：单神经元精确模拟（第 2 周–2 月）
- 实现 HH 模型（Na/K/漏）→ 动作电位复现
- 多隔室扩展：胞体+树突+轴突（电缆方程）
- 参数标定：用 HH 1952 实验数据拟合
- **交付**：单神经元仿真库 + 验证报告（波形对照图、f-I 曲线）
- **Pass**：动作电位波形误差 <5%；f-I 曲线形状与文献一致
- **反证路径**：若 HH 无法拟合 → 检查离子通道参数 → 或改用更完整通道模型（Ca²⁺ 参与）

### M2：突触与神经元对（第 2–3 月）
- 化学突触（量子释放 + AMPA/NMDA/GABA 受体动力学）
- 电突触（缝隙连接）
- 神经元对：前神经元 → 后神经元 PSP 复现；高频刺激 → STP
- **交付**：突触仿真库 + EPSP/IPSP 验证报告
- **Pass**：EPSP 波形与文献 <10% 误差；释放失败率符合泊松
- **反证路径**：若 PSP 时间常数偏差大 → 检查膜电容/通道密度 → 或加入树突滤波

### M3：最小行为回路——触觉反射弧（第 3–4 月）
- 搭建 C. elegans 触觉逃避回路（~5 神经元：感觉→中间→运动→肌肉）
- 施加机械刺激 → 观察后退反应
- **交付**：反射弧仿真 + 刺激-反应曲线验证报告
- **Pass**：刺激 → 定向反应；强度-潜伏期曲线与行为学一致
- **反证路径**：若反应方向错误 → 检查缝隙连接极性/递质类型 → 或检查中间神经元抑制连接

### M4：局部功能回路——嗅觉趋化（第 4–6 月）
- 搭建嗅觉趋化回路（ASE 感觉神经元 → AIY/AIB 中间 → 运动），~20 神经元
- 虚拟二维环境 + 食物梯度；仿真虫应能"爬向食物"
- **交付**：趋化仿真 + 趋化指数 vs 真实数据对照报告
- **Pass**：趋化指数显著 >0 且与真实虫一致（统计）
- **反证路径**：若无法趋化 → 检查 ASE 编码机制（ON/OFF 细胞对）→ 或检查运动神经元两侧激活的平衡/竞争机制

### M5：全连接组——302 神经元 + 行为闭环（第 6–12 月）
- 载入 C. elegans 全连接组（含缝隙连接）
- 全网络动力学 + 虚拟身体（正弦爬行）+ 完整环境
- 多行为验证：趋化、机械逃避、自发行为分布（前进/后退/转弯比例）
- **交付**：全虫仿真 + 多行为对照报告（这是本实验的**核心里程碑**）
- **Pass**：至少 2 种行为（趋化 + 逃避）通过统计验证；自发行为时间分布一致
- **反证路径**：若行为不涌现 → 逐回路排查（M3/M4 已单独验证过，问题必在网络耦合/神经调质/缺失环节）→ 引入神经调质浓度模型或修正连接权重

### M6：学习与可塑性（第 12–16 月）
- 引入 STP + STDP + 神经调质（多巴胺/血清素）调节
- 行为验证：**习惯化**（重复机械刺激 → 逃避反应衰减）与真实习惯化曲线对照
- 探索：联想学习（盐+食物关联，AWC 神经元）—— C. elegans 经典学习范式
- **交付**：学习行为仿真 + 习惯化/联想学习对照报告
- **Pass**：习惯化曲线形状/时程与真实数据一致；联想学习成功（行为改变可逆）
- **反证路径**：若学习不出现 → 检查 STDP 时间窗/调质浓度 → 或引入多巴胺能调控回路

### M7（延伸，非本实验必达）：更复杂生物/应用迁移
- 扩展到果蝇幼虫（~10k 神经元，连接组部分已知）或斑马鱼幼体
- 或：把验证过的生物神经机制（如 CPG、趋化回路）**迁移回数字大脑项目**，作为其"先天感知/运动机制"的真生物来源
- **Pass**：在更大生物上至少复现 1 种行为；或迁移机制在数字大脑中通过原有应用题测试

## 五、技术选型

### 5.1 仿真引擎（三选一，M0 决定）

| 引擎 | 优势 | 劣势 | 适用 |
|---|---|---|---|
| **NEURON**（Python 接口） | HH/多隔室/突触最成熟；学术界标准；C. elegans 有现成模型 | 学习曲线陡 | **首选**（M1–M5） |
| **Brian2** | Python 原生、灵活、声明式 | 大规模性能一般 | M2–M4 快速原型 |
| **NEST** | 大规模网络性能强 | 单神经元精细度弱于 NEURON | M5 全虫 + 未来扩展 |

建议：**M1–M4 用 Brian2 或 NEURON 快速迭代；M5 全虫用 NEURON（性能+完整度）。** M0 做一个引擎基准对比，选一个主线引擎。

### 5.2 数据与依赖

- **连接组数据**：OpenWorm 项目（openworm.org）提供 C. elegans connectome 结构化数据（JSON/CSV），MIT 协议
- **行为学数据**：文献提取（趋化指数、习惯化曲线、自发行为比例），整理为 `tests/behaviour_data/` 数据集
- **HH 参数**：HH 1952 原文；多隔室参数参考 ModelDB（senselab.med.yale.edu/modeldb/）

## 七、风险、假设与反证路径总表

| 假设 | 风险 | 缓解/反证 |
|---|---|---|
| HH 模型足够描述神经元 | 某些神经元有非 HH 动力学（如起搏器细胞） | M1 用真实 f-I 曲线验证；失败则加通道 |
| 连接组结构已知即可复现行为 | 突触权重未知（连接组只有连接有无，无强度） | 权重作为自由参数，用行为学数据反推（M4/M5） |
| 确定性动力学能涌现智能 | 也许需要更大规模的随机性/神经调质 | M5 失败则逐层反证，明确缺什么 |
| 虚拟身体足够近似 | 肌肉-身体耦合过于简化可能压制行为 | 虚拟身体单独验证（爬行波形 vs 真实虫运动轨迹） |
| 仿真规模可承受 | 302 神经元 + 全突触实时仿真可能慢 | NEURON 分布式/减少隔室数；行为层用降阶模型 |
| 行为学数据可比 | 文献数据来自不同品系/条件 | 固定实验协议，优先同一品系（N2）数据 |

## 八、与现有数字大脑项目的关系

| 维度 | 数字大脑（现有） | 生物仿真（本实验） |
|---|---|---|
| 层次 | 认知层（图谱/激活/程序性记忆） | 生理层（离子通道→网络→行为） |
| 输入 | 应用题文本 | 环境刺激（梯度/触碰/温度） |
| 输出 | 数学答案 + 推理链 | 行为（运动/趋化/学习） |
| 关系 | **上层认知** | **下层机制（先天硬件）** |

**衔接点（M7）**：生物仿真验证过的机制（如趋化回路、CPG、习惯化）可作为数字大脑的**"先天感知/运动机制"**——回答"数字大脑的数字从哪来、先天结构从哪来"的终极问题。两者最终合并为一个"从神经到认知"的完整模型。

## 九、实验节奏与交付物

- 每个里程碑：**1 份验证报告（数据对照图 + 统计检验）+ 1 个可运行仿真 + 对应测试全绿**
- 每层通过后冻结为基准（baseline），后续改动不得破坏已通过层（回归测试）
- 全程记录"反证路径"命中情况——**实验的科学产出不仅是"成功复现行为"，也包括"哪些生物机制必不可少"的清单**

## 十、附录：M1 起点参数（HH 1952 标准参数）

```
C_m  = 1.0 µF/cm²
gNa  = 120 mS/cm²   ENa = +50 mV
gK   = 36  mS/cm²   EK  = -77 mV
gL   = 0.3 mS/cm²   EL  = -54.4 mV
门控变量：m（Na 激活，τ~0.1ms）、h（Na 失活，τ~1ms）、n（K 激活，τ~1ms）
```
这些参数即 M1 的起点；`tools/param_fit.py` 用真实实验数据做标定。
