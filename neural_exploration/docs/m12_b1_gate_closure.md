## 1 ★ F1–F6 的「可计算性」逐条补证（输入列 → 在哪个源 → 当前是否可得 → 用错后果）


## 2 ★ 门标准「`p>0.05` 或 `<20%`」的操作化（**统计检验名 + 检验对象 + 多重比较 + 样本量门**）

### 2.1 先纠正一个可被误读的支路（**这一条必须写死**）

> **`p > 0.05` 单独出现时，一律不得作为 pass。**
> 依据：§1.2 附加条款 6（"`p>0.05` 永远不能单独作 pass：必须与 `CI95` 或 `MDE` 或 F1 的 margin 一并报告"）。
>
> ⇒ 门标准里的"`p>0.05` 支路"**只能**以**等价检验**的形式实现，即下列二选一（两式等价，报告都要给）：

| 写法 | 判定式 | 备注 |
|---|---|---|
| **TOST 形式** | 两个单侧检验 p 值 `p_low`、`p_high`；**等价 ⟺ `max(p_low, p_high) < α_tost`** | `α_tost = 0.05`（每侧） |
| **CI 形式（等价且更易报）** | **`100(1−2α)` = 90% CI ⊂ (−δ, +δ)`** | 报告 `Δ̂`、`CI90`、`δ`、`n_sim`、`n_data` |

而"`<20%` 支路"就是 F2（相对偏差 + bootstrap CI 上界门）。

### 2.2 检验名与检验对象（逐支路，**禁止只说"做 p 值"**）

| 形式 | **统计检验名** | **检验对象**（精确到量） | **margin / 阈值** | **不通过或失效 ⇒ 判** |
|---|---|---|---|---|
| **F1** | **两个单侧 t 检验（TOST）**；非正态时用 **bootstrap TOST**（≥10,000 重抽样，百分位 CI） | 仿真的**逐 session 行为指标**（准确率 / RT 中位 / RT p25 / 斜率）与数据侧同口径指标的**均值差** `Δ̂ = mean_sim − mean_data` | `δ = 0.20 × |ref|`（**相对 margin**，优先）；跨零量用 `δ_std` | CI90 宽度 > `2δ` ⇒ `invalid`（信息不足）；`n_valid < n_min` ⇒ `invalid` |
| **F2** | **点估计 + 非参数 bootstrap（≥10,000 次）** | 单点量 `θ̂`（斜率 / 阈值 / 命中率 / 耦合系数）的**相对偏差** | `|θ̂_sim − θ_ref| / |θ_ref| ≤ 0.20` **且** bootstrap **95% CI 上界 ≤ 0.20** | 点估计 ≤20% 但 CI 上界 >0.20 ⇒ **`invalid`（样本量不足）**；`θ_ref` 不可得 ⇒ `unavailable` |
| **F3** | **置换检验（`n_perm ≥ 1000`）+ 预注册下限** | 解码准确率 `acc_sim`、互信息 | `acc_sim ≥ acc_min` **且** `acc_sim > Q95(置换零分布)` | 未跑置换臂 ⇒ `invalid`；`acc_min` 无 provenance ⇒ `invalid` |
| **F4** | **Clopper–Pearson 精确二项 CI** | 扰动命中的**锚集**（分母**预注册**） | CI95 **下界 ≥ 0.70**（或锚级下限，如 "有锚 ≥ 20/50"） | 分母 < `n_min` ⇒ `invalid`；`unavailable`/`injection_ineffective`/`no-experiment` **计入分母** ⇒ **该判定作废** |
| **F5** | **三层断言**（非 p 值型） | ① 作用域（读回 + 表达式级）② 最小阳性对照（开/关两臂 `sha256` 不等 **且** 目标量变化 > 带/2）③ 动态范围（`std` 落量级门） | 三层全过才可谈"机制有效/无效" | 任一层不过 ⇒ **`MECHANISM_NOT_IMPLEMENTED`**（不是 fail、不是反证） |
| **F6** | **方向一致率 + 精确二项 CI** | 预注册方向表的逐行方向 | 一致率 ≥ 0.70 | 方向表事后修改 ⇒ 该轮 `invalid` |

### 2.3 多重比较处理（**family 必须运行前定义**）

- **方法**：**Holm–Bonferroni**（逐步降序，控制 FWER；比 Bonferroni 检出力高且无额外假设）。
- **报告**：**同时给 raw p 与 adjusted p**（§1.2 附加条款 3）。
- **预注册 family（本节点建议，须由主 agent 定稿）**：

| family | 成员 | 大小 |
|---|---|---|
| `P8-behavior` | 准确率 / RT 中位 / RT p25 / 斜率 / 偏置 | **5** |
| `P10-activity` | 区域率分布 / dwell / 任务依赖率差 | **3** |
| `P11-perturbation` | 逐锚命中 | **N_anchor**（锚数，预注册） |
| `P7-region` | 逐区域方向一致（6 区域） | **6** |

- **禁止**："20 个指标挑 1 个通过"（§1.2 附加条款 3 明文）。
- ⚠️ **等价检验的 p 值 = `max(p_low, p_high)`**（不是两倍最小值）——用错会把"等价"变成"差异"的假阳性。

### 2.4 样本量门（**给出可执行的闭式解，不写"样本要够"**）

**F1/F2 主门（power 法）**：TOST 在 `α_tost=0.05`（每侧）、power `1−β=0.80` 下，两组等样本量：

```
n_min^power = 2 σ² (z_{0.95} + z_{0.90})² / δ²      z_{0.95}=1.6449,  z_{0.90}=1.2816
            = 2 σ² (2.9265)² / δ²  =  17.134 σ² / δ²
```

代入相对 margin `δ = 0.20·|ref|` 与 `σ = CV·|ref|`（`CV` = 变异系数）：

```
n_min^power = 17.134 / 0.20² × CV²  =  428.3 × CV²
```

| `CV`（session 间变异系数） | `n_min^power`（**每组**） | 说明 |
|---|---|---|
| 0.20 | **18** | M12 行为侧（同源 IBL）目标区 |
| 0.30 | **39** | 中等异质 |
| 0.50 | **108** | 高异质（跨 lab/跨制备） |
| 1.00 | **429** | 跨制备混用时才会到的量级——**说明"跨源混比"在样本量上也不可行** |

**F1 信息门（CI 宽度法）**：要求 `90% CI 半宽 ≤ δ` ⇒ `1.6449·se ≤ δ` ⇒

```
n_min^CI = 2 × (1.6449 σ / δ)² = 5.411 σ²/δ² = 135.3 × CV²   （每组）
```

**★ 边界可达性自检门（§1.2 附加条款 4 的强制后果）**：判据要先把**目标数据**按区组随机劈两半、
用**同一协议同一 margin** 判等价并**必须通过** ⇒ 每一半都要满足 `n_min` ⇒

```
n_total ≥ 2 × n_min^power  =  856.6 × CV²   （两组合计）
且 n_total ≥ n_min^CI × 2  =  270.7 × CV²
⇒ 操作门：  n_total_min = ceil( 856.6 × CV² )     ← 取较严者（power 法）
```

| `CV` | **`n_total_min`（合计）** |
|---|---|
| 0.20 | **35** |
| 0.30 | **78** |
| 0.50 | **215** |

**MDE @ `n_min`（必须随判据一起报，§1.2 附加条款 2）**：

```
δ_detectable(n) = sqrt(17.134 / n) × σ        （单组 n）
```

- **本节点的实测含义（立刻可用）**：白名单 A 分区 **13 session**、全白名单 **40 session**。
  ⇒ 即使取 `CV=0.20`（乐观），`n_total_min` 也要 **35**；**A 分区（13）单独用不够**
  ⇒ **A 必须扩到 ≥18，或改用全白名单 40 作拟合集并把 B 分区扩到同量级**。
  （这是本节点基于实测 session 数给出的**具体裁决输入**，不是泛泛提醒。）

**F3/F4 的门**：F4 分母下限按锚数预注册（如 `n_min=50` ⇒ 目标 ≥35 命中才可能 CI95 下界 ≥0.70）；
F3 的 `acc_min` 必须给 provenance（否则 `invalid`）。
