## 0. M4 目标与验收标准（Pass 定义）

**目标**：搭建 C. elegans 嗅觉/味觉趋化局部回路（~20 神经元：
ASE 感觉神经元（ON/OFF 细胞对编码）→ AIY/AIB 中间 → 运动神经元 → 虚拟身体），
在虚拟二维环境 + 食物梯度中，**仿真虫应能"爬向食物"**；
交付：趋化仿真 + **趋化指数 vs 真实数据对照报告**（CI≈0.3–0.7，Ward 1973；Pierce-Shimomura et al. 1999）。

**Pass 标准（全部满足才进入 M5；每项可测，禁止模糊标准）**：
- [ ] **P1：ASE ON/OFF 编码（环境→感觉接口，开环）**：固定虫位，施加浓度阶跃协议——
      上升阶跃（ΔC>0）→ 响应窗 [阶跃起点, +40ms] 内 ASEL 发放 ≥1 且 ASER 静默（0 发放）；
      下降阶跃（ΔC<0）→ ASER 发放 ≥1 且 ASEL 静默；静止浓度（ΔC=0）→ 两者均静默；
      确定性（p=1/n=1）重跑逐位一致。
- [ ] **P2：回路拓扑/递质极性/链传播正确性**：CSV 读入 20 角色齐全、连接数与递质类型与规格一致（断言）；
      核心子链发放次序严格递增（t_ASEL < t_AIY < t_AVB；t_ASER < t_AIB < t_RIA）；
      ASE→AIY 感觉→中间 EPSP vs NEURON 参考 `norm_rmse < 10%`（`psp_amplitudes`/`norm_rmse` 复用）；
      核心链传导时间 vs 参考误差 < 15% 或绝对 < 2ms；确定性重跑逐位一致（`ReflexResult.__eq__` 同款）。
- [ ] **P3：二维环境与虚拟身体自洽（无梯度对照）**：均匀浓度（C ≡ C_bg）下 N=20 试次
      CI 均值与 0 无显著差异（单样本 t 检验 p>0.05，**主判据**；|CĪ| 点值 informational——
      **主 agent 裁决 2026-08-23**：N=20 有限样本下点判据不可靠，见 m4_env_notes L7）；
      运动学自洽：全程轨迹有界（不越界/不发散）、速度/转向量程在 CSV 规格内、数值稳定（无 NaN）；
      闭环 epoch 迭代可复现（同参数重跑轨迹逐位一致）。
- [ ] **P4：趋化行为（核心判据，对应设计文档 Pass）**：食物梯度下 N=20 试次（确定性神经网络，
      试次间差异来自伪随机起点）——
      (a) CI 均值**显著 > 0**（单样本 t 检验 p<0.05 且效应量 Cohen's d ≥ 0.5）；
      (b) CI 均值**与真实虫一致**：落在生物带 [0.3, 0.7] 的容差窗 [0.25, 0.75] 内，
          且与行为参考模型（同协议）CI 均值差 ≤ 0.15；
      (c) 终态偏向：终点-食物距离显著小于起点-食物距离（配对检验 p<0.05）或进入吸引圈比例 ≥ 0.5；
      (d) 无梯度对照 CI ≈ 0（与 P3 联动复核）。

      **P4 最终裁决（主 agent 2026-08-24，协议限制反证记录）**：机制 A 在**可行计算协议**
      （T≤10s、N≤20，20 神经元多隔室闭环）下的统计显著性结构性不足——理想参考模型自身
      N=10/T=10s 通过率仅 23–40%、N=20 仅 43%，稳健显著需 T≥15–25s（数千 CPU-小时，本机不可行）。
      落地：P4(b) 生物带以 numpy 参考模型全协议（T=25s、N=20、CI=0.449∈[0.3,0.7]，p=0.0002）为
      验证主体；P4(a) 显著性以 T 缩放关系（CI(T)：参考 0.219@10s→0.489@25s，Brian2 同比例）+
      实测点（T=5s: CI=0.043, p=0.83）记录；P4(c) 终态偏向以可行协议实测为准。该裁决为
      **计算可行性边界反证**（非机制失败），M5 行为层必须采用降阶模型（设计文档已预见）。
- [ ] **P5：机制消融（反证路径预演，两个子实验）**：
      5a 删除 ASE OFF 通道（ASER 静默，只剩 ON）→ 消融组 CI 均值 ≤ 0.5×完整组 或 与 0 无显著差异
        （证明 ON/OFF 时间差分编码必需——设计文档反证路径第一分支）；
      5b 破坏两侧平衡/竞争（删除 AIY→RIA 转向抑制，或静默一侧 SMDD 转向）→
        消融组 CI 均值 ≤ 0.5×完整组 或 转向失控（轨迹无定向偏置）
        （证明两侧激活的平衡/竞争机制必需——设计文档反证路径第二分支）。
      **判据预注册**：CI 是聚合量，消融后通常下降但不归零 → 主判据用相对阈值（≤0.5×），
      备选"与 0 无显著差异"；若两机制二分分离不足，**记录测量限制，不静默重试，走三态裁决**（M3 P5 教训）。
- [ ] **P6：参考解对照**：(a) NEURON 核心子链（ASEL→AIY→FWD、ASER→AIB→TURN）发放次序/EPSP 对照通过；
      (b) 行为参考模型（pirouette，同环境同协议）CI 均值 ∈ [0.3, 0.7]（校准带）且与 Brian2 虫
      CI 均值差 ≤ 0.15——两套行为统计用**同一份引擎无关代码**计算（可比性保证）。
- [ ] **P7：回归与报告**：`pytest neural_exploration/tests` 全绿（M0 4 + M1 10 + M2 11 + M3 7 + M4 新增 ≥8 = ≥40，
      以实测为准）+ `docs/m4_report.md` 写盘 + `reports/neuro/m4_validation_summary.json` 存在且各 pass_=true。
- [ ] **P8：M3 交接处置完成**：L1–L4 处置 + 实测新踩坑 L5+ 记录到 `docs/m4_env_notes.md`。

> **反证路径（设计文档 §四 M4）**：若无法趋化 → 检查 ASE 编码机制（ON/OFF 细胞对）
> → 或检查运动神经元两侧激活的平衡/竞争机制。任何 Pass 失败不得静默重试：记录缺失机制
> 与证据指向，产出反证笔记（WORKFLOW §四 三态裁决）。

> **判据可测性预注册（吸取 M3 P3/P4/P5 结构性不可达教训——判据设计时就要考虑模型结构性限制）**：
> 1. **CI 统计陷阱**：单试次 CI ∈ [−1,1] 且高方差 → 判据同时要求**显著性（t 检验 + 效应量 d≥0.5）**
>    与**效应量（均值落生物带）**，避免"仅显著但幅度微小"或"幅度大但不可重复"；
>    **无梯度对照必须纳入判据**（CI 度量本身可能系统性偏置——用对照校准）。
> 2. **爬行离散化陷阱**：环境步（行为 tick Δt_b）与神经步（dt=0.01ms）双时钟 → 运动学积分必须
>    引擎无关（numpy 精确积分，同 M3 `integrate_muscle` 哲学），两引擎共用同一运动学/CI 代码；
>    Δt_b 与 CI 测量网格分辨率定稿于 CSV，避免 CI 被离散化误差主导。
> 3. **ON/OFF 编码的可测特征**：本模型 ASE 是**电流注入的功能模型**（无真实转导/感受器动力学）——
>    P1 判据只测"阶跃响应方向与发放/静默"，**不测**真实 ASE 电生理波形（M3 同款简化：转导缺失
>    登记为简化假设，不伪造波形）。
> 4. **闭环代价**：趋化是闭环（感觉依赖位置、位置依赖运动、运动依赖感觉）→ 无法像 M3 一次性
>    预计算整试次 TimedArray → 采用 **epoch 迭代耦合**（步骤 3 §4.2），编译缓存纪律是可行性前提。
> 5. **消融二分分离不足**：CI 聚合量消融后通常"显著下降但不到 0" → 相对阈值（≤0.5×）为主判据，
>    记录测量限制（M3 P5 ×1.2 子判据教训——不设接近模型极限的阈值）。
> 6. **"与真实虫一致（统计）"的操作化**：本模型是点身体 + 简化转向，不声称复现真实虫运动学细节；
>    一致性判据 = CI 落生物带容差窗 + 与行为参考模型（同协议）均值差 ≤ 0.15。生物带为协议相关，
>    行为参考模型在**同一协议**下校准到带内，Brian2 虫与参考模型用同一度量代码，保证可比。

### 2.1 网络拓扑与递质极性（~20 神经元，双侧推-拉）

```
食物梯度 C(x,y)（L5 环境）
  → ASE 感觉对（时间差分编码，电流注入）
      ASEL（ON：浓度↑ → 去极化）──AMPA──> AIYL/AIYR（前进促进：抑制转向、保持直行）
      ASER（OFF：浓度↓ → 去极化）──AMPA──> AIBL/AIBR（转向促进：促发 pirouette）
      （可选交叉：ASER ──AMPA(弱)──> AIYL/AIYR——真实 ASE 交叉投影，Suzuki 2008）
  → AIYL/AIYR ──GABA──> RIAL/RIAR（前进促进压制转向执行——互斥：直行 vs 转向）
  → AIBL/AIBR ──AMPA──> RIAL/RIAR（转向促进驱动转向执行）
  → RIAL ──AMPA──> SMDDL/SMDVL（左摆运动）──muscle──> C_left
  → RIAR ──AMPA──> SMDDR/SMDVR（右摆运动）──muscle──> C_right
  → AVBL/AVBR ──AMPA──> VB/DB（身体运动）──muscle──> C_fwd（正弦爬行推进）
  → 虚拟身体：v = f(C_fwd)，ω = f(C_left − C_right)（两侧平衡/竞争）→ 位置更新 → 闭环
```

- 神经元花名册（20 个，规格提案；**以 `data/m4_chemotaxis_params.csv` 定稿为准**，
  名称与极性依 White 1986 / Cook 2019 连接组语义简化，同 M3 惯例）：

| 层 | 神经元 | 数量 | 功能 |
|---|---|---|---|
| 感觉 | ASEL（ON）、ASER（OFF） | 2 | 浓度时间差分上升/下降编码（转导=电流注入功能模型） |
| 中间-前进促进 | AIYL、AIYR | 2 | 上行激活 → 抑制转向、保持直行 |
| 中间-转向促进 | AIBL、AIBR | 2 | 下行激活 → 促发转向（pirouette） |

### 2.2 ASE 感觉编码（ON/OFF 细胞对，规格公式）

```
C(x, y) = C_max·exp(−((x−x_f)² + (y−y_f)²) / (2σ²)) + C_bg      # 静态食物梯度（相对浓度 0..1）
C_sensed(t) = C(x(t), y(t))                                       # 虫在当前位置的浓度采样
s(t) = (C_sensed(t) − C_sensed(t−τ_win)) / τ_win                  # 时间差分（滑窗，生物对应 ASE 感受时间常数量级）
I_ASEL(t) = g_ON · max(s(t), 0)       [µA/cm² 密度]                # ON 细胞：浓度上升 → 去极化电流
I_ASER(t) = g_OFF · max(−s(t), 0)     [µA/cm² 密度]                # OFF 细胞：浓度下降 → 去极化电流
# 注入位点：ASE 胞体（或树突端，定稿于 CSV）；nA = density_to_nA(密度, 位点)
# 离散实现：每个行为 tick Δt_b 内 s(t) 恒定 → 组帧为 epoch TimedArray（同形填充，STIM_WINDOW_MS 纪律）
# 可选加噪：s(t) + σ_noise·ξ(t)（真实感受器噪声，informational；主验证无噪确定性）
```

**P1 的可测特征**：开环阶跃协议（虫位固定）——静止基线期（≥40ms，HH 静息漂移）→
上升阶跃（ΔC=+0.5）→ 静止 → 下降阶跃（ΔC=−0.5），每段 ≥50ms；
判据：上升段 ASEL 发放、ASER 静默；下降段 ASER 发放、ASEL 静默；静止段均静默（见 §0 P1）。

### 2.3 虚拟二维环境与食物梯度（L5 环境雏形）

```
方形培养皿（drop assay 简化）：边长 L=10（cm 或相对单位，定稿于 CSV）
食物梯度：C(x,y) = C_max·exp(−r²/(2σ²)) + C_bg
  C_max = 1.0（相对浓度），C_bg = 0.0（无梯度对照时 C ≡ C_bg，即 C_max 段置 0）
  σ = 梯度长度尺度（初值 L/8；CSV 定稿）
食物滴位置 (x_f, y_f) = 右上象限中心（真实 drop assay 惯例：Ward 1973）
边界：反射或软转向（定稿于 CSV；P3 要求轨迹有界）
采样：虫位 (x(t), y(t)) 处浓度 + 时间差分（§2.2）；行为 tick Δt_b 定稿（初值 25–50ms）
```

### 2.4 趋化运动机制与 CI 定义

```
虚拟身体（点模型 + 朝向，正弦爬行雏形）：
  v(t) = v_fwd0 · clip(C_fwd(t), 0, 1)               # 前进速度 ∝ 前进肌肉收缩
  ω(t) = ω_max · (C_left(t) − C_right(t))            # 转向角速度 = 左右转向肌肉差（两侧平衡/竞争）
  dx/dt = v·cosθ；dy/dt = v·sinθ；dθ/dt = ω
  （运动学积分器引擎无关 numpy；可加小幅速度振荡模拟爬行步态，informational）

趋化机制（主用，对应设计文档"时间差分（病态运动/转向）"）：
  直行段：s(t) > 0（浓度上升）→ ASEL → AIY 激活 → 抑制转向 → 保持直行；
  s(t) < 0（浓度下降）→ ASER → AIB 激活 → 促发转向（ω 增强，pirouette）→ 有偏随机游走 → 爬向食物。
  （转向方向随机——虫在点位置无空间方向信息；与 Pierce-Shimomura 1999 pirouette 机制一致。
   可选扩展机制 B（weathervane 头摆空间比较）：若机制 A 校准不到 CI 带，引入头摆两侧采样差分
   使转向偏向浓度高侧——记录为反证扩展，见步骤 4/风险表。）

**机制 A 落地修订（主 agent 裁决 2026-08-23，m4_env_notes L4 预注册风险处置）**：
左右完全对称电路下 `ω = ω_max·(C_left − C_right) ≡ 0`（无净转向）——B1a/B1b 实测确认。
按清单 §2.4 原设计"转向方向随机（pirouette）"落地：**转向方向 = 试次种子确定性伪随机**
（每试次种子固定 → 转向方向可复现，确定性铁律不破）；s 调制转向频率（s<0 超阈值 →
ASER→AIB→RIA→SMDD 驱动转向事件；s>0 → AIY 抑制转向保持直行——偏置来自直行/转向时长不对称，
Pierce-Shimomura 1999）。试次方差来源扩展登记："伪随机起点 + 转向方向种子"。
实现位置：M4 模块内（chemotaxis_body.py 转向事件 + chemotaxis_circuit.py 左右失衡种子，B1c 定稿）。
若校准仍无法落带 → 机制 B（weathervane）→ 再失败 → 反证记录三态裁决。

趋化指数（CI，Pierce-Shimomura 1999 象限式；两引擎共用同一统计代码）：
  T_in  = 虫处于食物象限（含食物滴的象限）的时间
  T_out = 虫处于对侧象限的时间
  CI_i = (T_in − T_out) / T_total ∈ [−1, 1]     # 单试次；0=随机，>0=趋化，<0=回避
  组统计：CĪ ± SEM；单样本 t 检验（H0: μ=0）；效应量 Cohen's d；无梯度对照 CĪ_ctrl
  生物带：CI ≈ 0.3–0.7（Ward 1973；Pierce-Shimomura et al. 1999）——判据容差窗 [0.25, 0.75]

试次协议：起点 = 皿中心；食物滴 = 右上象限中心；T_total 定稿于 CSV（初值 20–30s 仿真时间）；
N = 20 试次/组（伪随机起点扰动 + 确定性神经网络）；无梯度对照组同协议（C_max 段置 0）。
```

### 4.2 实现要点（延续 M1/M2/M3 经验，SESSION_CONTEXT §四 10 条必读 + M3 踩坑）

1. **闭环 epoch 迭代（核心新机制）**：神经仿真无法一次预计算整试次输入（输入依赖位置、位置依赖神经输出）。
   协议：每 epoch ΔT（= 行为 tick Δt_b，初值 25–50ms）——(i) 由当前位姿采样 C、算 s(t)，
   组帧 epoch TimedArray（**固定 STIM_WINDOW_MS=500 形状、显式命名、pad 零**，M3 L6 编译缓存纪律——
   epoch 间仅数值变化，形状/名字不变 → 缓存命中不重编译）；(ii) 运行 Brian2 ΔT；(iii) 读肌肉
   收缩 → 运动学积分（引擎无关）更新位姿；(iv) 下一 epoch。试次间 net.store()/restore() + 重播种
   （M3 L12 语义）。**冒烟验证点**：闭环同参数重跑逐位一致（P3 判据）。
2. **ASE 转导电流**：ASEL/ASER 的 stim_var 注入 g_ON/g_OFF·max(±s,0) 密度（nA 按位点换算）；
   事件代码限制（M3 L11）：max/min 出现在**刺激数组数值**（numpy 侧），不进 on_pre；
   肌肉饱和仍用 `clip()` + namespace 常量。
3. **确定性铁律**：主验证（P1–P6）p_release=1、n_vesicles=1；试次方差来自伪随机起点（非神经噪声）；
   量子释放噪声仅作 informational 补充（P3 可选），且不与确定性参考混用（M3 L15）。
4. **record 标签**：role_ 前缀约定扩展为 asel_/aser_/aiyl_/...（`_record_spec`/`_spike_times` 模式照搬）；
   `psp_amplitudes` 本地基线内置（HH 静息漂移）。
5. **构造参数默认值必须 None**（M3 L13）：`ChemotaxisCircuit(csv_path=None, dt_ms=None, method=None,
   t_total_ms=None, seed=None)`——显式传入才覆盖 CSV。
6. **三通道肌肉**：C_fwd/C_left/C_right（§1 L1 二选一定稿）；驱动 on_pre 增量 + 指数衰减，与 M3 同 ODE。

## 8. 风险与备用方案

| 风险 | 影响 | 备用方案 |
|---|---|---|
| **闭环 epoch 迭代 × 编译缓存**（M3 L6/L12 组合，M4 最核心新机制） | 每 epoch 重建/重编译 → 验证超慢或不可行 | 固定 STIM_WINDOW_MS=500 形状 + 显式命名 + pad 零；epoch 间仅数值变（缓存命中，M3 6 档扫描实证）；冷缓存后预热 1 epoch；epoch ΔT ≥ 25ms 控制迭代数；必要时全链重建（慢但正确） |
| **CI 统计功效 / 消融二分分离不足**（M3 P5 ×1.2 教训） | P4/P5 判据不可达或误判 | N≥20 + 无梯度对照 + 效应量 d；相对阈值（≤0.5×）+ "与 0 无显著差异"备选；判据可达性在 §0 预注册；分离不足 → 三态裁决（记录测量限制），不静默重试 |
| **简化身体/转向机制达不到 CI 带**（结构性限制——M3 P3 同型风险） | P4 生物带判据不过 | 步骤 4 参数定稿扫描（校准到带内）先行；仍无解 → 引入机制 B（weathervane 头摆空间比较）重校准；再失败 → 反证记录（缺失机制清单），三态裁决 |
| **ASE 功能模型 vs 真实转导差异** | "编码正确性"被过度解读 | P1 判据限"阶跃响应方向/发放-静默"（可测特征），不测真实波形；转导缺失登记为简化假设（M3 同款，m4_report §简化假设） |
| **事件代码限制**（M3 L11：on_pre 不解析 min/max、if/else） | 肌肉饱和/转向方程生成非法代码 | 事件语句只用 clip() + namespace 常量；max(±s,0) 在 numpy 侧（刺激数组）完成 |
| **store/restore 语义**（M3 L12：restore 重置 monitor） | 试次间数据累积/污染 | 每试次 restore 后 monitor 数据即该试次完整轨迹；restore 后变量回快照（g 清零/位姿重置由运动学侧独立管理） |
| **构造参数默认值非 None 静默覆盖 CSV**（M3 L13） | 验证与定稿参数不一致 | `ChemotaxisCircuit` 构造参数一律 None 默认；验证脚本只传 csv_path，协议覆盖显式调用 |
| **量子释放语义**（M3 L15：g_max_ns 为单囊泡量子电导） | 噪声试次与确定性参考电导强度不同 | 主验证 p=1/n=1 确定性；噪声试次仅 informational，不与确定性参考混用 |
| **HH 静息瞬态漂移**（M1/M2/M3） | P1/P2 阶跃/PSP 基线污染 | 阶跃协议基线期 ≥40ms；`psp_amplitudes` 本地基线内置；行为 CI 为聚合量不受影响 |
| **NEURON 参考解坑**（温度 6.3°C、点过程 GC、cvode 近阈值挂起、gap.mod 不可用——M2/M3） | 参考子链失真/挂起 | 显式 h.celsius=6.3；IClamp/NetCon 列表持有；避免近阈值持续电流（定稿安全区）；缝隙用 scipy solve_ivp 或 Brian2 (summed) 写回 |
| **多隔室 + Synapses 事件耦合在 20 神经元链中放大**（SESSION_CONTEXT §四 #10） | 数值不稳/开发慢 | 先两条子链（各 5–6 神经元）冒烟再合并全链 + 闭环；每对突触先经子链验证；必要时 dt 降至 0.005ms |
| **计算量失控**（20s × 20 试次 × 400 epochs） | 验证耗时不可接受 | T_total/Δt_b/N 定稿于 CSV（预算记入 m4_env_notes）；epoch 缓存命中后每 epoch 仅一次 run；先校准小集（10 试次）再全量 |
| **CI 度量系统性偏置**（象限/边界定义） | 判据失真 | 无梯度对照必须通过（P3）才认可度量；两引擎共用同一 CI 代码；象限式 + 吸引圈式双指标（圈式 informational） |

## 10. M4 完成后的交接（M5 入口——核心里程碑）

M5（全连接组 302 神经元 + 行为闭环，设计文档 §四 M5）的起点：
- **接口复用**：`ChemotaxisCircuit` 的「环境→感觉」接口（ASE 时间差分注入）与虚拟身体/环境模块
  （`src/chemotaxis_env.py`/`chemotaxis_body.py`）直接成为 M5 全虫 L5 行为层雏形；
  epoch 闭环耦合器（`chemotaxis_loop.py`）是 M5 全虫-环境闭环的可复用框架；
  三通道肌肉与两侧竞争判定升级为全虫正弦爬行/转向；
- **数据**：`data/m4_chemotaxis_params.csv` 的 ~20 神经元连接权重/递质极性作为 M5 302 神经元
  连接组的**局部子图权重先验**（ASE→AIY/AIB、AIY/AIB→运动的真实极性已验证）；
- **验证目标**：M5 全虫多行为（趋化 + 逃避）统计验证（设计文档：至少 2 种行为通过 + 自发行为
  分布一致）；趋化可直接沿用本里程碑的 CI 度量与行为参考模型；
- **遗留/登记（简化假设清单，M5 行为层补齐）**：无机械转导（触刺激直接电流注入）、δ 驱动肌肉、
  点身体运动学、ASE 电流注入功能模型——M5 需补齐：机械转导延迟、连续肌肉/身体动力学、
  真实正弦爬行姿态；
- **复现入口**：`python -m neural_exploration.tools.run_m4_validation`（P1–P6 全跑）
  + `pytest neural_exploration/tests`（P7）。
