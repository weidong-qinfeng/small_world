# 生物仿真实验设计·阶段三：从生长脑到人脑功能复现

> 版本：v0.1（阶段三整体实验设计稿，承接阶段一、阶段二）
> 前置假设：**阶段一（M0–M7）与阶段二（M8–M14）全部实施并取得结果**——C. elegans 全连接组行为、果蝇幼虫/成年全脑（行为 + 扰动预测 ≥70%）、斑马鱼全脑活动金标准、小鼠皮层微环路、小鼠全脑介观、灵长类抽象架构与"最小充分大脑"、M14 离子通道→推理单链闭环均已通过；必需机制清单、缩放定律曲线、抽象登记册、扰动预测管线全部冻结复用。
> 终极目标：**人脑功能复现（可测层面）**——由发育规则生长、具身课程塑造、在人类一切可测通道（认知/影像/临床/发育轨迹）上与人脑统计不可区分的"生长脑"。
> 核心科学问题：**人脑的接线图不可下载（无突触级连接组）、全脑活动不可记录（验证通道粗粒度）、经验史不可回放（20 年具身+社会+语言）——在这三重不可测约束下，能否用"发育规则生长结构 + 具身课程塑造功能 + 人类可测层验证等价"三件事，从阶段二的"最小充分大脑"生长出在一切可测层面与人脑不可区分的类脑功能体？以及：人脑的 ~86B 神经元 / ~10¹⁴ 突触，其中多少是功能必需、多少是鲁棒性/冗余/精细感觉运动与社会化的代价？**
> 实验路线：发育连接组学（生长代替下载）→ 虚拟童年（课程代替回放）→ 人类可测层对齐（对齐代替全脑记录）→ 猕猴中间验证点 → 认知与语言落地 → 临床扰动验证 → 元认知与意识相关物 → **"生长脑"终态验收与"86B 之谜"分解**。
> 验证金标准（阶段三升级为**四通道 + 内部对照**）：认知/行为常模、影像统计、临床扰动、发育轨迹四通道同时通过（经前向模型与人类数据对照）＋ 与阶段二 M13 最小充分大脑的内部对照（生长脑 ≥ 抽象脑）。

## 二、从"大脑的神经网络"到人脑：三重不可测约束与方法学变形

M14 之后，"复现人脑"不再是一个进度问题，而是三个**原理性不可测**问题。阶段三的全部设计，就是把这三个"不可能"逐个变成"可做的等价物"：

| 不可测约束 | 细节 | 阶段三的方法学变形 |
|---|---|---|
| ① 结构不可下载 | 人脑无突触级连接组：全脑 EM 重建需 exabyte 级数据，按当前成像速率全脑取样需百年量级；且脑区间个体差异大，"一张图"也代表不了"人脑" | **生长代替下载**（M15）：从发育规则生长出结构，只要求结构与可测尺度（小鼠/猕猴）统计一致，并验证规则的必要性 |
| ② 活动不可记录 | 人脑全脑细胞分辨率活动记录原理性不可能：fMRI mm 级、EEG/MEG 粗粒度，可测通道相对 ~86B 神经元稀疏 ~6 个数量级 | **对齐代替记录**（M17/M20）：把模型状态经前向模型映射到人类可测通道（影像/认知/临床），在"可测层"上验证等价 |
| ③ 经验不可回放 | 人脑的接线与功能是 ~20 年具身经验 + 社会 + 语言的产物；语言暴露量级上 LLM 有 10¹³ token（比人多 5–6 个数量级）却无具身无结构 | **课程代替回放**（M16）：设计一段"虚拟童年"（具身 + 物理 + 社会智能体 + 多模态语言），课程设计本身成为可证伪的科学变量 |

**阶段三的方法学立场**：这不是三个"绕过"，而是三个**等价性假设**——
- 假设①：*结构的功能后果*（而非结构的逐点副本）足以承载人脑功能；
- 假设②：*可测通道上的统计不可区分*（而非逐神经元一致）足以构成"功能复现"的验证；
- 假设③：*课程的结构*（而非经验的总量）是类人认知形成的关键。

三个假设全部可证伪（见各里程碑反证路径）；任一假设被证伪，都要输出具体的"缺失机制/缺失等价物"清单。

## 三、阶段三科学命题、四条新铁律与"生长脑"操作定义

### 3.1 阶段三总命题（可证伪的核心假设）

> **人脑功能的复现不要求解剖级复现。** 若一个由"发育规则生长出结构、具身课程塑造出功能、人类可测通道验证等价"的**生长脑**，在认知/影像/临床/发育轨迹四个通道上与人脑统计不可区分，则证明：人脑功能是**结构统计 + 经验课程 + 验证约束**的函数，而不是 ~86B 神经元 / ~10¹⁴ 突触的逐点副本；"理解"依然不需要概率推理引擎（阶段一、二结论的最终推广）。

**可证伪性**：四通道中任一通道显著不符 = 反证，输出缺失机制清单；若四个通道全部长期无法同时通过，则说明"三重等价性假设"中至少一个为假，科学结论本身仍然成立（哪些等价性为假、为什么）。

### 3.2 "生长脑"操作定义（终态验收标准）

一个单一代码库内的闭环系统，同时满足：

1. **结构**：由发育规则（神经发生→迁移→分化→轴突导向→突触发生→活动依赖修剪→髓鞘化→关键期）**生长**出来，而非下载；其结构统计在小鼠/猕猴等可测尺度上与真实数据一致；
2. **经验**：由具身课程（虚拟身体 + 物理 + 社会智能体 + 多模态语言）塑造，发育里程碑的顺序与时程与人类一致；
3. **验证**：认知任务组（含 novel 新任务）、影像统计、临床扰动、发育轨迹**四通道**同时通过；
4. **机制**：确定性动力学 + 局部物理随机 + 多尺度可塑性（阶段一/二冻结件），无参数级概率推理；
5. **可追溯**：每个认知/影像/临床级结论可回放到底层机制（M14 单链的延续）；
6. **边界声明**：不宣称解剖级复现（86B/10¹⁴ 逐点），不宣称主观体验等价（意识难题划出，见 §十）。

### 3.3 阶段三四条新铁律（叠加在阶段一、二铁律之上）

| # | 铁律 | 内容 |
|---|---|---|
| D1 | **生长代替下载（发育即结构）** | 人脑接线图不可测量，结构必须由发育规则生长。规则集本身是假说：逐条可消融、逐条验证必要性（消融后哪项结构统计被破坏）。无法由任何规则复现的统计 = "发育偶然性"，在生成中以随机种子采样，不强行拟合 |
| D2 | **课程即数据（具身即训练）** | "训练数据"不是 token 池，而是一段具身课程。课程调度器（发育阶段、关键期、内禀动机、照料者脚手架）是科学变量而非工程参数：课程设计的好坏必须由"能否产生正确的发育里程碑"来判定与证伪 |
| D3 | **临床即扰动，对齐即验证** | 人脑尺度的"扰动预测"= 临床综合征（卒中病灶、神经退行、药理、精神障碍、发育障碍）。任何模型结论必须在至少一个人类可测通道（认知/影像/临床/发育）上可检验；**机制是否类人，只能由临床扰动验证给出最强证据** |
| D4 | **最小充分原则（延续）** | 一切阶段三新增（发育规则、课程模块、脑区、尺度）必须由反证驱动：能不加就不加。生长脑必须与阶段二 M13 最小充分大脑做内部对照——生长路线若不能 ≥ 抽象路线，就是发育规则或课程的失败，而不是"再长大一点"的问题 |

- **T4 具身课程系统**：阶段三的"数据生成器"。课程调度器按发育阶段编排经验（感觉运动期→前运算期→具体运算期…），含关键期窗口、内禀动机（好奇/新颖性奖励）、照料者脚手架；语言输入必须多模态落地（词↔感知↔动作），拒绝纯文本训练。
- **T5 人类对齐系统**：人脑尺度的验证基础设施。① 影像前向模型：区域活动→BOLD（血流动力学模型）、群体活动→EEG/MEG（头模型近似）；② 任务组生成器：把 M13 认知任务组升级为"人类常模版"（正确率/反应时/错误模式三分布）；③ 临床综合征生成器：病灶/退行扩散/药理/发育障碍的注入与预测；④ 发育里程碑表：把儿童发展常模编码为可自动判定的指标。

## 五、里程碑规划 M15–M22（承接 M0–M14，每个可独立交付）

> 总周期：第 73–180 月（约 9 年；需团队 + 基础设施，多轨并行可压缩）。延续阶段一/二规则：**Pass/Fail 明确，未通过不得进入下一层；失败即反证，输出"缺失机制/缺失等价物"清单。** 阶段三复用阶段二资产：扰动预测管线（→ 临床扰动）、缩放定律曲线（→ 86B 分解）、抽象登记册、必需机制清单、数字大脑接口、全脑活动金标准管线（→ 猕猴验证点）。

### M15：发育连接组学——生长代替下载（第 73–90 月）

- **背景**：人脑无突触级连接组（exabyte 级、百年取样速率），阶段二"载入连接组"路线在人脑尺度失效。M15 把结构问题从"下载"转为"生长"，并在可测尺度（小鼠/猕猴）上验证生长出来的结构。
- **数据**：小鼠介观图谱（Allen，阶段二已有）、MICrONS/NMC 局部统计（阶段二已有）、果蝇幼虫/成年连接组统计（阶段二数据管线）、发育生物学文献（神经发生时序、突触修剪速率、髓鞘化时序、关键期窗口）、猕猴/狨猴局部结构与图谱。
- **内容**：
  1. **发育规则集（假说）**：前体池 → 神经发生 → 迁移 → 分化（细胞类型 = 位置 + 时序 + 分子梯度）→ 轴突导向 → 突触发生 → 活动依赖修剪（Hebbian + 稳态）→ 髓鞘化 → 关键期固化；
  2. 在抽象基质上执行规则 → 生长出"介观图 + 局部规范微环路"（D4 粒度，登记入抽象登记册）；
  3. **消融实验（D1 的核心）**：逐条移除规则 → 记录哪些结构统计被破坏（规则→统计缺陷的完整映射）；
  4. 跨物种一致性（延伸目标）：同一规则类型、不同参数 → 同时复现果蝇与小鼠的统计特征。
- **Pass**：生长图与 Allen 图谱统计不可区分（度分布/模块度/层级/投射密度，多项图指标 KS 检验）；局部回路统计 vs MICrONS/NMC 一致；消融图谱完整（每条规则的必要性有定量结论）。
- **新增科学问题**：**"发育规则最小集"**——多少条规则足以长出真实结构统计？哪些统计是"发育偶然性"（随机 + 历史）而不可由规则复现？
- **反证路径**：统计不可复现 → 缺规则（记录入登记册）；若某统计无论加什么规则都无法复现 → 判定为发育偶然性，在生成中以随机种子采样并注明"不可约噪声"。

### M16：具身课程引擎与"虚拟童年"（第 84–108 月）

- **背景**：人脑经验史不可回放（约束③）。M16 把"训练数据"重构为一段可设计的具身课程，用发育里程碑来判定课程的好坏（D2）。
- **数据**：儿童发展数据集（客体永久性、A-not-B、心理理论任务、词汇增长曲线 [Wordbank]、亲子语料 [CHILDES]、婴儿头戴相机视觉+语音流 [SAYCam]）、运动发育常模（WHO 里程碑）、照料者互动文献。
- **内容**：
  1. 虚拟人类体（降阶：眼/耳/手/姿态，精细度按 D4 最小充分原则）＋ 物理引擎 + 多模态感觉流；
  2. **课程调度器**：按发育阶段编排经验（感觉运动→前运算→具体运算…），含关键期窗口、内禀动机（好奇/新颖性奖励）、照料者脚手架；
  3. 语言输入：多模态落地（词↔感知↔动作），非纯文本；
  4. 课程扰动实验：剥夺/延迟特定输入（语言、视觉、社会）→ 观察发育轨迹偏移。
- **Pass**：里程碑按顺序 + 大致时程涌现（客体永久性 ≈8–12 月等效；词汇增长曲线形状 vs Wordbank 不可区分；心理理论任务按童年顺序通过）；运动学习曲线（够物/爬行/行走）vs 常模；课程扰动产生类似"野孩"效应的发育延迟。
- **新增科学问题**：**"经验最小课程集"**——token 数量不是关键，课程结构才是；一段多短/多省的课程足以长出类人发育轨迹？
- **反证路径**：里程碑不涌现 → 课程结构/奖励/身体缺失 → 调整并记录；若某里程碑无论如何无法产生 → 列入**诚实边界清单**（如"依赖真实身体/真实社会他人"），不强行凑数。

### M17：人类可测层对齐引擎（第 96–120 月，与 M16 并行）

- **背景**：人脑全脑活动不可记录（约束②），验证只能通过"可测层"。M17 先把"模型状态→人类可测通道"的映射建好、校准好，作为 M19–M22 全部验证的基础设施。
- **数据**：HCP（静息态 + 任务 fMRI + 弥散）、公开 EEG/MEG 数据集、任务行为常模（正确率/反应时/错误模式/测验分布）、Neurosynth 任务激活先验、Yeo 静息态网络分区。
- **内容**：
  1. 影像前向模型：区域活动 → BOLD（血流动力学模型）、群体活动 → EEG/MEG（头模型近似）；
  2. 任务组生成器：把 M13 认知任务组升级为"人类常模版"（正确率/RT/错误模式三分布）；
  3. **校准与自检**：用已知认知任务（n-back、Stroop、运动知觉）运行模型 → 激活图与文献对照；校准管线本身用人类数据验证（人类被试数据过同一管线 → 必须回放常模）。
- **Pass**：前向模型在独立数据集上定量一致（任务激活图相关性达阈值、静息态 FC 矩阵相关性达阈值）；任务组常模管线通过（人类数据→常模回放无偏）。
- **反证路径**：前向模型错误 → 映射本身是假说，在独立数据集上检验并修正；不做"校准到像"的过拟合（保留 held-out 数据）。

### M18：猕猴中间验证点（第 108–132 月）

- **背景**：猕猴是"接近人脑但可侵入验证"的唯一阶梯（Neuropixels 深部记录 + 认知任务 + 部分结构数据）。这是在人脑声明之前，阶段二"活动金标准 + 扰动预测"铁律 B 的最后一次完整落地——**准人脑外推的唯一校验点**。
- **数据**：猕猴 Neuropixels 公开记录、经典感知决策范式（运动方向判别 + LIP 证据累积，Roitman & Shadlen 2002）、猕猴/狨猴 MRI 图谱、猕猴局部 EM 连接组（陆续发表）。
- **内容**：
  1. 把 M15 生长的结构 + M16 的课程**参数化迁移**到"猕猴约束"（身体尺寸、脑尺寸、寿命、感官带宽）；
  2. 在经典猕猴任务上运行 → 复现：LIP 样证据累积 ramping、选择概率（choice probability）、反应时分布、γ 振荡；
  3. 猕猴尺度扰动预测：局部失活 → 行为缺陷，与文献对照。
- **Pass**：感知决策任务的行为与神经动力学（ramping 斜率、choice probability、RT 分布）与公开数据不可区分；失活扰动预测命中 ≥70%。
- **反证路径**：猕猴任务动力学复现失败 → 结构与经验的参数化错误 → 回 M15/M16 修正；**若猕猴尺度无法通过，则"生长 + 课程"路线不足以支撑灵长类声明，阶段三在此终止并定稿反证结论**（不带着未验证的外推继续）。

### M19：认知与语言落地（第 120–144 月）

- **背景**：关闭认知差（阶段二 §2.4）：机制层表征 ↔ 数字大脑符号层的对接，以及人脑最具标志性的功能——语言。
- **数据**：语言习得语料（CHILDES）、心理语言学常模（启动效应/反应时）、推理任务组常模（瑞文/三段论/工作记忆广度）、数字大脑原有应用题测试。
- **内容**：
  1. 具身语言：词↔感知↔动作接地 + 组合性（递归/语法）的涌现；
  2. **符号落地**：把数字大脑的符号操作符映射到机制层表征（表征对齐，接口假设记录入登记册）；
  3. 全任务组验证：认知任务组 + novel held-out 任务 + 数字大脑应用题；
  4. 语言习得轨迹对照（词汇/语法里程碑 vs 人类曲线）。
- **Pass**：全任务组以人类常模可比水平通过（含 RT 分布）；语言习得轨迹与人类曲线不可区分；对 novel 任务的泛化成立（不依赖记忆训练集）。
- **反证路径**：语言/推理失败 → 接地/课程/接口缺陷 → 记录缺失机制；若组合性无法从具身基础涌现 → 需要在数字大脑层显式加入组合算子，并记录为"符号-机制接口假设"（若最终必须如此，则写清它替代了什么生物机制）。

### M20：临床扰动验证——人脑尺度的"扰动预测"（第 132–156 月）

- **背景**：D3——人脑的"扰动预测"只能借道临床：病灶、退行、药理、精神障碍、发育障碍都是天然扰动实验。**这是机制是否类人的最强证据通道。**
- **数据**：卒中病变-症状数据集（PLORAS：病变→语言缺陷/恢复预测）、ADNI（AD 认知 + 影像纵向）、药理学研究（多巴胺/胆碱能调制 → 认知/影像）、精神疾病表型（精神分裂认知、抑郁、ADHD）、神经发育障碍（自闭症——与 M16 发育扰动衔接）。
- **内容**：
  1. **病灶模拟**：沉默区域/切断长程投射 → 预测行为/影像缺陷 → vs 病变-症状图谱；
  2. **退行模拟**：沿连接组扩散的"损伤波"（AD 样 tau/淀粉样传播）→ 认知衰退曲线 + 影像 → vs ADNI；
  3. **药理模拟**：调质水平改变（T2）→ 认知/影像 → vs 文献；
  4. **发育障碍模拟**：扰动 M15 规则 / M16 课程 → 表型 → vs 临床（自闭症样、ADHD 样）。
- **Pass**：病变-症状映射一致（如左半球语言区病变→失语、顶叶→忽视）；AD 衰退轨迹 + 影像模式一致；药理效应一致；发育扰动产生与临床相似的表型。
- **反证路径**：临床扰动验证失败 = 机制不类人的最强证据 → 缺失机制清单（如特定调质系统、特定区域动力学）→ 反哺 M12/M15 的生物建模。**若全部通过，则是比任何行为对照都强的"机制类人性"证据。**

### M21：元认知与意识相关物（第 144–168 月）

- **背景**：意识的可测相关物（置信度、错误监测、内省报告、错觉敏感性、自由意志时序现象）。**意识难题明确划出边界**（见 §十）：只验证可测相关物，不宣称主观体验等价。
- **数据**：置信度校准实验、感知决策报告范式、视觉错觉实验（人猴共感/不共感错觉清单）、Libet 类自由意志时序实验、安慰剂/反安慰剂。
- **内容**：
  1. **置信度信号**：由群体动力学（如确定性读出）生成 → 校准曲线 vs 人类（含任务难度相关的过度自信模式）；
  2. **错觉敏感性作为表征结构探针**：模型是否"中招"经典错觉（如埃宾豪斯）——表征压缩方式的签名；
  3. **报告/内省**：模型对歧义刺激的"报告" + "我不知道"模式 vs 人类；
  4. 元认知训练效应（减少过度自信）。
- **Pass**：置信度校准曲线与人类模式一致；≥2 种经典视觉错觉的敏感性一致；歧义刺激下的报告模式一致。
- **反证路径**：置信度/错觉/报告对不上 → 表征结构或读出机制缺陷 → 回 M19/M12 修正；**若"报告"始终无法与人一致，则把"可测相关物不一致"如实定稿为阶段三的边界结论**（比强行声称更有科学价值）。

### M22（终局）：生长脑终态验收与"86B 之谜"分解（第 156–180 月）

- **内容**：
  1. **全链集成与回归**：M0→M22 全链（离子通道 → 发育 → 童年 → 认知 → 临床 → 元认知）端到端回归，阶段一/二全部冻结件保持通过；
  2. **四通道终验**：认知任务组（含 novel）+ 影像 + 临床 + 发育轨迹同时通过；
  3. **内部对照**：生长脑 vs M13 最小充分大脑——生长脑必须 ≥ 抽象脑（性能持平或更好、且多出"可解释的结构与经验史"），否则生长路线判定失败（D4）；
  4. **"86B 之谜"分解实验**：对终态生长脑做压力测试——鲁棒性（噪声/损伤容忍 → 冗余需求）、精细感觉运动（手部灵巧/发音/中央凹视觉 → 尺度需求）、社会多体（→ 尺度需求）、任务广度 vs 专业化——结合缩放定律曲线，输出 **"~86B 神经元 / ~10¹⁴ 突触的功能构成分解"**（功能必需 / 鲁棒性 / 冗余 / 精细感觉运动 / 社会化的代价，各带置信区间）。
- **交付物**：① 可运行"生长脑"（§3.2 六条操作定义全部满足）；② "人脑为什么需要 86B"分解报告；③ 临床扰动验证报告（机制类人性最强证据）；④ 发育规则最小集 + 经验课程最小集 + 抽象登记册终版（阶段三"必需机制清单"）；⑤ "从离子通道到人类认知"完整单链；⑥ 与数字大脑合并的最终形态。
- **验收（终极金标准）**：四通道同时通过 + 全链回归绿 + 内部对照成立 + 86B 分解给出可复现、可检验的数值区间。

## 六、验证标准总则（阶段三升级版）

### 6.1 四通道验证

| 通道 | 对照 | 指标 | 通过线 |
|---|---|---|---|
| A 认知/行为 | 人类任务常模（正确率/RT/错误模式/测验分布） | 三分布 + 泛化（novel 任务） | p>0.05 或落于常模 CI；novel 任务不靠记忆 |
| B 影像 | HCP/EEG/MEG 公开数据（经 T5 前向模型） | rs-FC 矩阵、任务激活图、频谱 | 定量一致（预设相关性阈值） |
| C 临床扰动 | 卒中/ADNI/药理/精神/发育障碍数据 | 病变-症状映射、衰退曲线、药理效应、表型 | 统计一致 |
| D 发育轨迹 | 儿童发展常模（里程碑/词汇曲线/运动） | 顺序 + 时程 | 里程碑序一致、曲线不可区分 |

### 6.2 数据隔离与防过拟合

- 拟合用数据集 A（如小鼠结构统计、儿童发展数据 A）；held-out 用 B（成人任务常模）+ C（临床数据集）+ D（猕猴记录）；
- 四通道互证：单通道通过不算数，**必须多通道同时成立**（一个机制解释多个通道，而不是每个通道一个专用补丁）；
- 与 M13 的内部对照贯穿全程（D4）。

### 6.3 失败即反证（延续并强化）

阶段三的反证输出是：**① 具体缺什么（规则/课程/机制/等价物）② 证据指向哪里（哪条通道、哪个指标）③ 下一步假设**。M15–M21 的反证汇总为终版"必需机制清单"（M22 交付物④）；每一类反证都可能反哺阶段二（如 M20 发现调质机制不足 → 回 M12 修正小鼠全脑模型），形成跨阶段的循环价值。

## 七、技术选型与计算预算

| 系统 | 技术 | 说明 |
|---|---|---|
| D 发育系统 | 图生长 + 局部规则模拟（HPC/GPU 并行） | 生长"介观图 + 局部微环路统计"，不生长 10¹⁴ 突触副本（D4，登记入抽象登记册） |
| T4 课程引擎 | 降阶虚拟身体 + 物理引擎 + 多模态感觉流（GPU 集群） | 虚拟童年按阶段压缩时间；身体精细度由 D4 决定 |
| T5 对齐引擎 | BOLD 血流动力学模型、EEG/MEG 头模型近似、统计比较管线 | 前向模型是假说，独立数据集校准 |
| 仿真引擎 | 阶段二 GPU 引擎（Brian2CUDA/NEST GPU/PyTorch 内核）继续复用 | 无新引擎引入，除非被反证驱动（D4） |
| 计算预算 | HPC/集群级 | **明确不做**：实时人脑级突触仿真（神经形态外推需 10²–10³ MW 量级）；阶段三按 D4 只需功能等价，不需要解剖级/实时级——此决策记录入抽象登记册 |

> 原则：阶段三的计算策略是"**功能等价优先于解剖保真**"——实时、全尺度、逐突触的仿真既不必要（无法验证）也不可行（能量量级），它们是抽象登记册里被 D4 明确豁免的项目。

## 九、风险、假设与反证路径总表

| 假设 | 风险 | 缓解/反证 |
|---|---|---|
| 发育规则可长出功能承载的结构 | 规则集不完备；无直接人脑结构数据可对照 | 小鼠+猕猴结构统计对照 + 功能后果间接验证（结构差异必须体现为功能差异）；不可复现统计标记为发育偶然性 |
| 虚拟童年课程可塑造类人认知 | 课程依赖真实身体/真实社会他人 | 课程设计是科学变量（可证伪）；无法产生的里程碑列入诚实边界清单 |
| 可测层等价足以构成"复现" | 前向模型模糊（fMRI mm 级） | 只承诺区域级/网络级统计；四通道互证；前向模型独立校准 |
| 临床扰动通过 = 机制类人 | 表型可能只是表面相似（过拟合常模） | held-out 临床数据 + novel 病变 + 跨通道一致性 |
| 生长脑 ≥ 抽象脑 | 生长路线性能倒退 | 内部对照实验；倒退 = 规则/课程失败，不是"再长大一点" |
| 语言/符号落地 | 机制层表征与符号层不对齐 | 接地学习 + 接口假设记录；必要时显式组合算子并写明替代机制 |
| 计算成本 | 虚拟童年 + 发育 + 临床模拟 | 降阶身体/压缩时间/抽象基质（D4）；实时人脑级仿真明确豁免 |
| 猕猴验证点 | 灵长类外推失败 | 若猕猴尺度不过 → 阶段三在此定稿反证结论，不继续未验证的外推 |

## 十、伦理与边界声明（阶段三新增）

1. **无主观体验声明**：生长脑是验证工具，不宣称"意识"或主观体验等价；所有"报告/内省"输出标注为行为报告模型，对应意识科学的可测相关物（GNW/IIT 等理论提供相关物清单），意识难题本身不在本实验范围（延续"只为可验证而精细"）；
2. **临床与发育障碍模拟的边界**：M20 的病灶/退行/精神/发育障碍模拟仅用于验证机制的类人性，**不是诊断工具**，不产生任何临床用途声明；
3. **伦理审查**：阶段三涉及人脑功能模拟与人类数据对照，实验方案（数据使用、公开范围、报告发布）须在启动前过伦理审查；所有产出标注"仿真"；
4. **比较的边界**：与人类数据的比较限于统计等价，不替代、不减少人类实验（阶段三的对照数据全部来自既有公开数据集）。

## 十一、与数字大脑的终极合并

| 维度 | 数字大脑（认知层 L8） | 生长脑（机制层 D + L0–L7） | 阶段三合并点 |
|---|---|---|---|
| 层次 | 认知（推理/评测/程序性记忆） | 生理（发育→结构→行为→功能） | M19 符号落地 + M22 单链 |
| 输入 | 应用题文本 | 具身课程（感觉流/社会/语言） | 同一虚拟生态 |
| 输出 | 数学答案 + 推理链 | 行为/认知/影像/临床可测输出 | 推理链可追溯至发育与机制 |
| 关系 | 上层认知 | 下层机制（先天硬件 + 后天课程） | **"从离子通道到人类认知"单链终态** |

**衔接点**：数字大脑提供认知任务组作为生长脑的验证输入（M19/M22），生长脑提供机制层表征（空间地图、工作记忆缓冲、状态变量、语言接地）作为数字大脑推理的可追溯底座。M22 的"86B 之谜"分解同时反哺数字大脑的架构决策——**哪些认知功能需要多大尺度、哪些机制**——把阶段一"先天机制从哪来"的答案延伸为"先天机制与后天课程如何分工"。

### 13.2 内部对照实验设计（D4，M22 主实验之一）

- 对照组：阶段二 M13 最小充分大脑（抽象架构，冻结件）；
- 实验组：M15 生长结构 + M16 课程塑造的生长脑；
- 对照指标：同一认知任务组的性能 + 影像/临床/发育三通道表现 + 能耗/参数规模；
- 判定：生长脑必须 ≥ 对照组（性能持平或更好），且提供对照组没有的"可解释的结构与经验史"；否则判定生长路线失败，输出规则/课程缺失清单。

### 13.3 "86B 之谜"分解实验设计（M22 主实验之二）

对终态生长脑逐项做压力测试，输出每个功能构成的尺度需求区间：

| 功能构成 | 实验 | 输出 |
|---|---|---|
| 功能必需 | 最小充分脑 + 生长脑的最小功能集（M13 方法延续） | 必需尺度下界 |
| 鲁棒性 | 噪声/损伤梯度注入（白噪声→细胞死亡→连接破坏）→ 性能退化曲线 | 冗余需求曲线 |
| 精细感觉运动 | 手部灵巧/发音/中央凹视觉任务的精度-尺度曲线 | 感觉运动尺度需求 |
| 社会化 | 多体社会生态（N 个智能体）→ 认知性能 vs N | 社会化尺度需求 |
| 任务广度 | 任务组规模 vs 泛化性能（缩放定律曲线外推） | 广度-尺度权衡 |

结合阶段二缩放定律曲线，最终输出"~86B 神经元 / ~10¹⁴ 突触的功能构成分解"（各构成带置信区间），并明确哪些构成是"人脑之所以这么大"的解释、哪些是历史/鲁棒性偶然。
