## 3. 步骤 2：引擎选型基准（1–2 天）

### 3.1 统一基准实验：同一 HH 单神经元，三引擎各跑一遍

**实验规格（固定，保证可比）**：
- HH 模型（M1 标准参数：gNa=120, gK=36, gL=0.3, ENa=+50, EK=-77, EL=-54.4, Cm=1.0）
- 注入电流：阶跃 10nA，持续 50ms
- 采样：0.01ms 步长，输出 100ms 膜电位轨迹

**每引擎输出**：
1. `V(t)` 轨迹（numpy 数组）
2. 发放次数、首个动作电位时间
3. 仿真耗时（`time.perf_counter`，同机同条件）

### 3.2 扩展性探测（为 M5 全虫预留）
- 同一引擎上跑一个 ~20 神经元随机小网络，记录耗时/内存
- 目的：确认"302 神经元全虫"在该引擎上的数量级是否可行（不必现在跑 302）

### 3.3 基准表模板（写入 `neural_exploration/docs/m0_engine_benchmark.md`）

| 维度 | Brian2 | NEURON | NEST | 权重 |
|---|---|---|---|---|
| 安装难度（M0 实测） |  |  |  | 40% |
| HH 波形正确性（与手工 RK4 参考解比对误差） |  |  |  | 30% |
| 20 神经元网络耗时 |  |  |  | 20% |
| API 表达力（多隔室/突触/STDP 支持） |  |  |  | 10% |

**评分**：每格 1–5 分，加权总分定主线引擎。**决策模板**：总分第一 = 主线；同时写一句"M5 前若遇性能墙，切换引擎的代价评估"。

> **预期结论（写理由用）**：Brian2 安装最顺、语法声明式适合 M1–M4 快速迭代；NEURON 多隔室/突触最完整，M5 全虫性能更稳。若两者差距 <0.3 分，**推荐 Brian2 为主线**（开发速度快，M5 再评估是否迁 NEURON）。

- 用**主线引擎**（§3 决策结果）实现

### 6.3 断言（`tests/neuro/test_smoke.py`）
```python
def test_stimulus_produces_response():
    """注入刺激 → 运动神经元发放 → 肌肉收缩量 > 0"""
    result = run_smoke_loop(stimulus_amp=10.0)
    assert result.motor_spikes > 0
    assert result.muscle_contraction > 0

def test_response_reproducible():
    """同参数重跑 → 结果一致（确定性验证，本实验铁律之一）"""
    r1 = run_smoke_loop(stimulus_amp=10.0)
    r2 = run_smoke_loop(stimulus_amp=10.0)
    assert r1 == r2

def test_no_stimulus_no_response():
    """无刺激 → 无发放、无收缩（对照）"""
    result = run_smoke_loop(stimulus_amp=0.0)
    assert result.motor_spikes == 0
```

### 6.4 运行

```bash
pytest neural_exploration/tests -v
```

## 8. 风险与备用方案

| 风险 | 影响 | 备用方案 |
|---|---|---|
| pypi 不可达（网络问题） | 步骤 1 阻塞 | ① 换镜像源 `-i https://pypi.tuna.tsinghua.edu.cn/simple` ② 离线 wheel：`pip download` 到目录后 `pip install --no-index --find-links` |
| 系统 Python 权限问题 | venv 建失败 | 用 `python3 -m venv` 失败则 `pip install --user virtualenv` 后 `virtualenv .venv-neuro` |
| NEURON 编译失败（macOS） | 基准表缺一格 | 不阻塞：Brian2 先行，NEURON 标"待 M5 评估"，理由写入报告 |
| NEST 安装过久 | M0 超时 | NEST 只做"安装可行性"评估（10 分钟超时即放弃，打 1 分），不跑基准 |
| 引擎间数值差异 | 基准表误差大 | 统一步长/解法器（都要求 RK4、dt=0.01ms），差异记录为参考 |
