## 二、强制裁决（RF-M11-1..6）

### RF-M11-1（判据级，G2 前）§0.7 #2 的**理由已失效**，禁令保留但依据必须改写
- 清单写："M9 全规模数值 **+28% 不可复现** ⇒ 禁止移植绝对数值"。
- **该理由已被主agent 独立探针否证**（`tools/verify_m9_path_attribution.py`，`docs/m9_report.md` §11）：
  M9 冻结引擎走**其自身的 `run_resting` 入口**重跑 = **4.678288 Hz** vs 记录 4.6783 Hz
  （相对偏差 **2.6×10⁻⁶**）⇒ **完全可复现**；"+28%"是复核工具的口径缺陷（settle 窗计入分子仍除以 1.0 s）。
- **改写要求**：把禁令依据换成**两条仍然成立**的事实：
  1. **"可复现 ≠ 正确"**：同口径下**只修 CSR 投递公式**即得 3.5225 Hz（**−24.7%**），静默 0.585→0.762
     ⇒ **M9 的绝对值是"缺陷档"**，且两个独立修正实现交叉一致到 1.7%；
  2. **跨物种/跨制备/跨口径**：M9（果蝇）/M10（斑马鱼）/M11（小鼠 V1）的绝对速率、相关、dwell **均不可互移植**。
- **禁令本身保留**：M11 判据带**只能**来自 (a) MICrONS/Allen **同口径实测量** 或 (b) 逐条 provenance 化的文献。

### RF-M11-2（判据级，G2 前）dwell "同阶窗 [0.3,3]" 必须先过**边界可达性自检**，否则按实测放宽
- 实测（B4，`data/m10_imaging_dwell_reference.*`）：**同数据同序列**下 Q 法与 H 法的低态 dwell 中位比 =
  **3.87×**（未平滑时 **13.0×**）；**跨条件** dwell 中位 max/min = **6.9×**（等长控制 **26.2×**）、IQR/中位 = **1.49**。
- ⇒ **[0.3,3] 即 10× 窗口，比目标数据自身的离散度还窄**，存在"**判据严格到目标自己都不达标**"的结构性风险。
- **要求**：M11 在 G2 定稿 dwell 带时，**必须**执行 §0.7 #4③（目标数据劈半 + 同协议等价检验）**专门作用于 dwell 带**；
  若劈半不通过 ⇒ **按实测倍数放宽并预注册**（写明放宽依据的数字），**不得**事后调。
  同时在报告里**并列**：口径差倍数、跨条件离散度、劈半可达性三项实测值。

### RF-M11-3（判据级，G2 前）自持比（门 3）必须**统计可判**：给 CI + 零驱动臂样本量下限
- M10 实测（主agent 复核，RF-11）：同族配置自持比在 **0.0000（n=300）/ 0.0980（P5 配置）/ 0.1082（n=1000）/
  0.1110（M-2）/ 0.3078（indegree=5）** 间来回跨越 0.10 门限；且 P5 配置的零驱动臂**只有 60 个脉冲**
  ⇒ 比值相对不确定度 **≈13%**，**95% 区间跨越门限**。
- **要求**：① 零驱动臂与基准臂各 **≥3 seed、T ≥ 10 s**，使零驱动臂总脉冲 **≥300**（相对不确定度 ≤6%）；
  ② 判据写为"**点估计 ≤ 上限 且 CI 上界 ≤ 上限×1.2**"（预注册于 `m11_*_targets.csv`）；
  ③ 若无法满足样本量 ⇒ 该子判据标 `unavailable`，**不得**记为 pass（沿用"未测 ≠ 未命中"）。

### RF-M11-4（判据级，G2 前）"dwell 非零"必须升级为**状态结构四要素**（防指标退化）
- M10 的教训：`bout_fraction` 在"群体从不完全静默"的工况下**构造性恒为 0**（D2）；
  反过来，一个几乎恒处单态的网络也能给出"非零 dwell"——**非零 ≠ 有意义**。
- **要求**：§4.2 #5 的门改为**四要素全过**：
  ① **占用非退化**：两状态占用均 ≥ **5%** 帧数（且给出占用差）；
  ② **存在转换**：转换率 > 0（并报每状态 bout 数 ≥ **10**，否则 `unavailable`）；
  ③ **分布形状**：低态 dwell 的 **p90/中位 ≥ 2** 且**拒绝指数/几何**（KS p < 0.05）——与目标数据**同算法同参数**判形状；
  ④ **消融致其消失**（关闭该机制 → 回到单态/退化）。
  另：**bout 类指标只作描述性输出**，不得进任何 Pass 语义。

### RF-M11-5（门级，机制门前）C-5（丘脑-皮层慢输入）当前**构造性必然通过**，必须加"内源自持"要求
- 清单对 C-5 的判据写"慢涨落直接给皮层 0.1–1.5 Hz 慢输入 ⇒ dwell 由 f 决定（**物理上必定同阶**）"
  ——这是**注入一个慢信号就必然得到慢 dwell**，与"网络自身产生慢状态"是两回事（M10 D3 同类：判据若对
  所有参数必然通过，则它不是判据）。
- **要求**：C-5 的通过条件追加：**① 回路必须闭合**（皮层→丘脑/慢源的反馈项存在且非零，read-back 断言）；
  **② 慢结构必须在慢源幅度渐减（→0）时按预注册函数关系退化**，且**在中间幅度下**仍满足 RF-M11-4 四要素；
  **③** 报告必须区分"**注入的慢结构**"与"**涌现的慢结构**"，并在判决表里用**独立列**标注；
  **④** 若唯一奏效级是 C-5，则 P6 结论只能写"**外部慢输入可产生慢 dwell**"，**不得**写"网络产生了慢状态"。

### RF-M11-6（预算级，机制门前）NG 裁决必须在**机制门之前**做，且预算包络硬约束
- 清单自估最坏 **≈300–380 GPU-h vs 上限 138**，已触发 NG 门预案（降 N / 降保真 / 降试次 / 云 GPU）。
- **要求**：① **在 C-1..C-9 机制阶梯启动前**完成 NG 裁决并落盘（`data/m11_ng_decision.csv`），
  按**默认 8k/31k 档**做规划（75,909 档仅在"扫描证明状态结构随 N 显著变化且 8k/31k 不可用"时才进）；
  ② 给出**分阶段预算包络**（G2/G0/G1+S/结构/功能/活动/扰动各上限），**任一段超包络即停并三态裁决**；
  ③ **C-9 组合级只在最便宜的 N 档跑**；
  ④ 每轮机制臂**先落盘 ms/step 与 RSS 探针**再决定 T；
  ⑤ 本机**MPS 作业串行**、**CPU 作业 `OMP_NUM_THREADS=1`**（主agent 实测：MPS 并发 6× 退化、
  CPU 未限线程 4–5× 退化）——这两条已在 M10 付过学费，写进 `m11_env_notes.md`。
