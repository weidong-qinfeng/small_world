## 0. M3 目标与验收标准（Pass 定义）

**目标**：搭建 C. elegans 触觉逃避最小反射弧（3–5 神经元：感觉 → 中间 → 运动 → 肌肉），
施加机械刺激 → 产生**定向**（后退）反应，强度-潜伏期曲线与行为学数据一致
（触觉逃避潜伏期 30–50 ms，Chalfie et al. 1985）。

**Pass 标准（全部满足才进入 M4；每项可测，禁止模糊标准）**：
- [ ] P1：**定向反应（方向性）**：基准强度 I0 后部触刺激 → 后退通道激活、前进通道被抑制；
      方向判定 D = C_back − C_fwd 峰值 > 0.3；5 次重复（量子释放噪声 p=0.95/n=2，失败试次剔除并计数）
      方向判定全部正确（5/5）
- [ ] P2：**多神经元链传播正确性**：发放次序严格递增（t_PLM < t_AVM < t_DA）；
      感觉→中间 EPSP 与 NEURON 参考链归一化 RMSE < 10%（`norm_rmse`/`psp_amplitudes` 复用）；
      链传导时间（PLM 首发放 → DA 首发放）与参考链误差 < 15% 或绝对 < 2 ms；
      拓扑/极性断言（链连接数与递质类型与规格一致）
- [ ] P3：**潜伏期对照行为学**：神经潜伏期（触刺激开始 → DA 首发放）与 NEURON 参考链误差 < 15%；
      行为潜伏期（触刺激开始 → C_back ≥ 0.3·C_back_peak）中位数 ∈ [25, 60] ms
      （Chalfie 1985 报 30–50 ms，留 ±5–10 ms 测量容差）；20 试次（量子释放噪声，失败剔除）潜伏期 SD < 5 ms
- [ ] P4：**强度-响应曲线单调**：6 档强度 {0, 0.5, 1, 2, 4, 8}×I0 → 强度 0 时全链静默（无发放、C_back=0）；
      潜伏期 vs 强度 Spearman ρ ≤ −0.9（单调非增）；响应幅度 vs 强度 Spearman ρ ≥ 0.9（单调非减）
- [ ] P5：**方向机制消融（反证路径预演）**：删除中间→前进的 GABA 抑制连接 → 前进通道不再被抑制
      （C_fwd 峰值 > 0.3）**或** D 峰值衰减 > 50% → 证明互斥方向由抑制连接实现
      （对应设计文档 M3 反证路径："检查中间神经元抑制连接"）
- [ ] P6：`pytest neural_exploration/tests` 全绿（M0 4 + M1 10 + M2 11 + M3 新增 ≥6 = ≥31）
      + `docs/m3_report.md` 写盘 + `reports/neuro/m3_validation_summary.json` 存在且各 pass_=true
- [ ] P7：M2 交接处置完成（L1–L4 处置记录到 `docs/m3_env_notes.md`，含实测新踩坑 L5+）

> **反证路径（设计文档 §四 M3）**：若反应方向错误 → 检查缝隙连接极性/递质类型
> → 或检查中间神经元抑制连接。任何 Pass 失败不得静默重试：记录缺失机制与证据指向，
> 产出反证笔记（WORKFLOW §四 三态裁决）。

## 2. 步骤 1：反射弧规格（1 天，纯文档 + 数据）

### 2.1 网络拓扑与递质极性（主链：4 神经元 + 2 肌肉，双方向通道）

```
后部触刺激 S(t)（机械刺激，注入 PLM 树突端）
  → PLM（感觉神经元，多隔室 HH）
      → AMPA 兴奋（谷氨酸）→ AVM（中间神经元，多隔室 HH）
          → AMPA 兴奋 → DA（后退运动神经元，多隔室 HH）→ 腹侧肌肉（后退收缩 C_back）
          → GABA 抑制 → VB（前进运动神经元，多隔室 HH）→ 背侧肌肉（前进收缩 C_fwd）
```

- 静息态：VB 有**张力注入**（tonic drive，保持前进基线收缩 ≈0.2）；DA 静默（C_back=0）。
- 触刺激后：PLM→AVM→DA 兴奋链发放 → C_back 上升；同时 AVM→VB 的 GABA 抑制压过张力 → C_fwd 回落 → 净方向 = 后退（D = C_back − C_fwd > 0）。
- 生物对应（报告引用，非硬性）：PLM≈后部机械感觉神经元；AVM≈感觉/中间传递；DA/VB≈后退/前进运动神经元（设计文档 §二 L3 的"背/腹运动神经元 → 后退/前进"）。
- **最小链冒烟基线**：先 3 神经元（PLM→AVM→DA）+ 1 肌肉跑通，再上双通道（4 神经元 + 2 肌肉）。

### 2.2 机械刺激建模（规格公式）

```
方案 A（主用）：触电流 I_touch(t) = I0·s_i · 1[t0, t0+dur]      # µA/cm² 密度，注入 PLM 树突端
  档位 s_i ∈ {0, 0.5, 1, 2, 4, 8}；I0 定稿为使感觉神经元可靠发放
  （M2 实测参考起点：20 µA/cm² × 1 ms @ t=50 ms 可靠发放，build_synapse_ref PULSE_*）
方案 B（可选扩展）：I_touch = g_touch·S(t)·(V − E_touch)，E_touch ≈ 0 mV（去极化），
  g_touch 点电导按胞体面积换算（与突触方程同机制）——机械转导门控的替代建模
触刺激时程：5–10 ms；刺激开始必须 ≥ t=40 ms（HH 静息瞬态漂移，M1 env_notes §L3）
```

### 2.3 肌肉耦合（M0 smoke_loop 升级规格）

```
dC/dt = −C/TAU_MUSCLE + Σ_k w_k·δ(t − t_k)      # 每运动神经元发放 → 收缩增量 w_k
C ∈ [0, 1]（可选饱和）；双通道：C_back（DA 驱动）、C_fwd（VB 驱动）
方向判定：D(t) = C_back(t) − C_fwd(t)；D 峰值 > 0.3 → 后退
TAU_MUSCLE 初值沿用 M0 的 20 ms；定稿目标：行为潜伏期落 [30, 50] ms 窗（参数扫描见步骤 3）
```

### 2.4 参数数据文件

`data/m3_reflex_params.csv`（每行：role, neuron_class, synapse_from, synapse_to, synapse_type,
g_max_ns, delay_ms, tonic_uA_cm2, ...）——**唯一定稿源**，可修改复现；
CSV 注释含文献依据（参照 `m2_synapse_params.csv` 惯例）。

**验收**：CSV 存在且含完整链定义（拓扑/极性/刺激档位/肌肉参数/潜伏期目标窗）。


### 4.2 实现要点（延续 M1/M2 经验，SESSION_CONTEXT §四 10 条必读）

1. **链组装**：`ReflexArc` 按 `m3_reflex_params.csv` 构建 N 个 `MultiCompartmentNeuron`
   （唯一 name；`extra_eqs`/`extra_im_terms` 挂突触方程片段，`stim_var` 逐神经元命名——M2 已实证防 stim 串扰）
   + `ChemicalSynapse`/`GapJunction` 逐对连接（pre_site="node3"、post_site="soma" 沿用 M2 默认）；
   GABA 抑制用 gaba 行（E=−70 mV，Cl⁻ 超极化）。
2. **触刺激**：TimedArray 按 PLM 树突端注入（`density_to_nA` 换算），档位 s_i 为数组幅度；
   **固定 STIM_WINDOW_MS 形状 + 显式命名 + namespace 传参**（M2 L6 编译缓存纪律——6 档扫描共用同形数组）。
3. **张力注入**：VB 的 tonic drive 用恒定 TimedArray（幅度定稿于 CSV，静息前进基线 ≈0.2）。
4. **肌肉**：`dC/dt = −C/TAU + Σ w·δ(t_spike)` 双通道；运动神经元 → 肌肉的 Synapses on_pre 增量
   （M0 smoke_loop 同款，升级为多神经元驱动 + 方向）。
5. **确定性**：主验证（P1/P2/P4）p_release=1、n_vesicles=1（确定性铁律——同参数逐位一致）；
   P3/P1 的可重复性实验开启量子释放噪声（p=0.95、n=2，失败试次剔除并计数——M2 `run_trials` 机制复用）。
6. **record 标签**：沿用 pre_/post_ 约定扩展为 plm_/avm_/da_/vb_ 前缀；`psp_amplitudes` 直接复用（本地基线已内置）。

### 4.3 冒烟测试 `tests/neuro/test_reflex_smoke.py`（≥4 断言）

- 触刺激 → PLM/AVM/DA 依次发放（各 ≥1 spike）、C_back > 0；
- 无刺激 → 全链静默、C_back = 0（对照）；
- 方向：C_back 峰值 > C_fwd 峰值（后退，D_peak > 0.3）；
- 确定性：同参数重跑结果逐位一致（`__eq__` 数值比较，M0 `SmokeResult` 同款）。

**验收**：冒烟测试绿 + `reports/neuro/m3_smoke.png`（链各级 V + 双肌肉收缩叠加图）。

## 5. 步骤 4：逐项验证（2–3 天）

### 5.1 P1 定向反应 → `tools/validate_p1_direction.py`
- 协议：基准强度 I0 触刺激，5 次重复（量子释放噪声 p=0.95/n=2，失败试次剔除并计数）；
  每次记录 D_peak = (C_back − C_fwd).max()。
- 判据：D_peak > 0.3 且 5/5 方向正确；无刺激对照 C_back=0、前进基线 ≈0.2（P1 判定一并核验）。
- 输出：`reports/neuro/m3_p1_direction.png` + `data/m3_p1_direction.csv`。

### 5.2 P2 链传播正确性 → `tools/validate_p2_chain.py`
- 判据：t_PLM < t_AVM < t_DA（严格递增）；感觉→中间 EPSP vs NEURON 参考链
  `norm_rmse < 10%`（`psp_amplitudes` 提取 + `norm_rmse` 复用，对齐方式沿用 M2 P1 的发放归零 + 峰值对齐）；
  链传导时间（PLM 首发放 → DA 首发放）与参考链误差 < 15% 或绝对 < 2 ms；
  拓扑/极性断言：从 CSV 读入的连接数/递质类型与规格一致（测试断言）。
- 输出：`reports/neuro/m3_p2_chain.png`（各级 V 时间轴堆叠 + NEURON 参考对比）+ `data/m3_p2_chain.csv`。

### 5.3 P3 潜伏期 → `tools/validate_p3_latency.py`
- 定义：神经潜伏期 = t_DA首发放 − t_touch_start；行为潜伏期 = 首个 C_back ≥ 0.3·C_back_peak 的时刻 − t_touch_start。
- 判据：神经潜伏期 vs NEURON 参考链误差 < 15%；行为潜伏期中位数 ∈ [25, 60] ms
  （Chalfie 1985：30–50 ms）；20 试次（量子释放噪声，失败剔除并计数）潜伏期 SD < 5 ms。
- 输出：`reports/neuro/m3_p3_latency.png`（潜伏期分布直方图 + 30–50 ms 参考窗标注）+ `data/m3_p3_latency.csv`。

### 5.4 P4 强度-响应 → `tools/validate_p4_intensity.py`
- 协议：6 档强度 {0, 0.5, 1, 2, 4, 8}×I0 各跑一次；记录每档潜伏期与 C_back 峰值（或 DA 发放数）。
- 判据：强度 0 → 全链无发放、C_back=0；Spearman ρ(潜伏期, 强度) ≤ −0.9（单调非增）；
  Spearman ρ(响应幅度, 强度) ≥ 0.9（单调非减）。
- 输出：`reports/neuro/m3_p4_intensity.png`（强度-潜伏期 + 强度-响应双子图）+ `data/m3_p4_intensity.csv`。

### 5.5 P5 方向机制消融 → `tools/validate_p5_ablation.py`
- 协议：删除 AVM→VB 的 GABA 抑制连接（同参数重跑，确定性 p=1）；记录 D_peak 与 C_fwd 峰值。
- 判据：C_fwd > 0.3（前进不再被抑制）**或** D_peak < 完整链 D_peak × 0.5 →
  证明互斥方向由抑制连接实现（对应设计文档反证路径"中间神经元抑制连接"）。
- 输出：`reports/neuro/m3_p5_ablation.png`（完整链 vs 消融链对比）+ `data/m3_p5_ablation.csv`。

**验收**：P1–P5 五个验证脚本 + `tools/run_m3_validation.py`（顺序运行，汇总 →
`reports/neuro/m3_validation_summary.json`，各 pass_=true；结构沿用 `run_m2_validation.py`）。

| 反应方向错误（设计文档反证路径） | P1 不过 | 检查递质极性（AMPA/GABA 配置）/缝隙连接极性（若用）/抑制连接存在性 → 产出反证笔记（缺失机制清单），不静默重试 |
| 强度-响应不单调 | P4 不过 | 确认链中无 STP（保持关闭）；检查肌肉饱和/积分器上限；调 I0 基准或档位范围 |
| NEURON 参考链点过程被 GC 回收（M2 L8） | 参考链只剩末级脉冲 | IClamp/NetCon 等点过程列表持有 |

## 9. M3 完成后的交接（M4 入口）

M4（嗅觉趋化回路，~20 神经元：ASE 感觉 → AIY/AIB 中间 → 运动，设计文档 §四 M4）的起点：
- **接口复用**：`ReflexArc` 的多神经元角色/位点命名 + 刺激协议扩展为"环境→感觉"接口
  （M3 的触刺激 TimedArray 注入模式 → M4 的食物梯度场输入）；肌肉双通道/方向判定升级为趋化运动
  （正弦爬行雏形）；多神经元链组装模式与验证报告结构沿用；
- **新建**：ASE 感觉神经元（ON/OFF 细胞对编码）→ AIY/AIB 中间 → 运动，~20 神经元链；
  虚拟二维环境 + 食物梯度（L5 环境雏形）；
- **验证目标**：趋化指数 CI 显著 >0 且与真实虫一致（统计；Ward 1973; Pierce-Shimomura et al. 1999，
  CI≈0.3–0.7）；
- **反证路径（M4）**：若无法趋化 → 检查 ASE 编码机制（ON/OFF 细胞对）→ 或检查运动神经元两侧
  激活的平衡/竞争机制；
- **复现入口**：`python -m neural_exploration.tools.run_m3_validation`（P1–P5 全跑）
  + `pytest neural_exploration/tests`（P6）。
