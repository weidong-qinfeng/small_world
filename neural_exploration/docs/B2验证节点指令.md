## 交付物（P1–P5 各一个验证脚本 + 汇总器 + 报告生成器 + 报告）
- `tools/validate_p1_direction.py`：I0 档 5 次重复（量子噪声 p=0.95/n=2，失败试次剔除并计数）D_peak>0.3 且 5/5 方向正确；无刺激对照 C_back=0、C_fwd 基线≈0.2 → `reports/neuro/m3_p1_direction.png` + `data/m3_p1_direction.csv`
- `tools/validate_p2_chain.py`：t_PLM<t_AVM<t_DA 严格递增；感觉→中间 EPSP vs NEURON 参考链 norm_rmse<10%（对齐：PLM 发放归零+峰值对齐）；链传导时间（PLM→DA）误差<15% 或 <2ms；拓扑/极性断言（3 化学突触+2 肌肉驱动+VB 张力）→ `reports/neuro/m3_p2_chain.png` + `data/m3_p2_chain.csv`
- `tools/validate_p3_latency.py`：神经潜伏期 vs 参考链<15%；生理窗 [5,20]ms；强度-潜伏期 Spearman ρ≤−0.9；20 试次（量子噪声）潜伏期 SD<5ms；行为潜伏期差异归因说明（转导/肌肉动力学缺失 → M5）→ `reports/neuro/m3_p3_latency.png` + `data/m3_p3_latency.csv`
- `tools/validate_p4_intensity.py`：6 档 {0,0.5,1,2,4,8}×I0；0 档静默；Spearman ρ(潜伏期)≤−0.9；8×I0 延长刺激 20ms → DA≥2 发放 且 C_back 峰值>w_back → `reports/neuro/m3_p4_intensity.png` + `data/m3_p4_intensity.csv`
- `tools/validate_p5_ablation.py`：remove_synapse("AVM","VB") vs 完整链；响应窗 [50,90]ms 内 VB 发放数增加≥1 且 C_fwd 均值>完整链×1.2 → `reports/neuro/m3_p5_ablation.png` + `data/m3_p5_ablation.csv`
- `tools/run_m3_validation.py`：顺序跑 P1–P5 → `reports/neuro/m3_validation_summary.json`（各 pass_=true；结构沿用 run_m2_validation）
- `tools/gen_m3_report.py` → `docs/m3_report.md`（P1–P7 对照表 + 参数定稿 + 踩坑 + M4 交接；结构沿用 gen_m2_report）
