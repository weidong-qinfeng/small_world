并以 `build_laminar_probe_column(n, seed=…, delay_bins=bins, **net_kw)`（**L134**）装配 ⇒ **白名单之外的一切夹具参数被静默丢弃**。本节点 `grep -rn "gmax_band\|inh_frac\|sub_frac\|layer_frac" tools/*.py` ⇒ **在 P5 生产者链上零命中**（仅 M10 族工具命中）。

⇒ ⇒ 🔴 **这是一条在此之前未被登记的结构性事实**：`docs/m11_b3_g1_design.md` **L140–141** 登记的 **L0 主杠杆**是
> "**压自持**：**抑制权重/亚型比例**、阈值分布、**E/I 相对强度**"，作用点 = **递归环路增益**

而 L0 实际执行的是 `bias_scale ∈ {1.0, 0.70, 0.50}`（**全局兴奋性**，不是 E/I 构成）与 `gmax_scale ∈ {1,2,4}`（**统一**缩放，**E/I 比逐位不变**）⇒ **登记杠杆族里的"抑制权重 / 亚型比例 / E/I 相对强度"三项，一项都没被执行过 —— 因为生产者根本透传不了它们。**
⇒ **`gmax_scale` 的统一缩放不改变 E/I 比值**（L114 对所有类乘同一个因子）⇒ **它无法触及"E/I 相对强度"这一维**。

### 2.6 【判定性】`gmax_scale` 的**未测半空间**：只测过 `{1.0, 2.0, 4.0}`

来源：`data/m11_p5_plan_l0.json`（42 臂的 `gmax_scale` 直方图 = `{1.0: 26, 2.0: 8, 4.0: 8}`）、`m11_p5_plan_l1.json` / `l3*.json`（**全部 `gmax_scale = 1.0`**）。本节点遍历 `data/m11_p5_plan_*.json` 全部 17 份计划文件确认。
⇒ **`gmax_scale < 1.0` 从未被测** —— 这正是 **R110 §③「单侧扫描」** 的形态，而且是**第五个**未测半空间。
⇒ **`gmax > 1` 侧有一条实测（T=10 s、4 实现）**：

| `gmax_scale`（bias=1.0, σ=0.30, `dose=0`, T=10 s）| 零驱动 `spikes`（4 实现）| 逐实现 |
|---|---|---|
| 1.0 | **35,053** | 8,591 / 8,585 / 9,802 / 8,075 |
| **2.0** | **244,742** | 60,815 / 60,854 / 61,941 / 61,132 |

⇒ **×2 的 `gmax` 使零驱动自发活动 ×6.98**（逐实现比 7.08 / 7.09 / 6.32 / 7.57）。
⇒ ⇒ **零驱动自发活动对递归增益极度敏感（描述性弹性 ≈ log₂6.98 = 2.80；⚠️ 这是 2 点描述性拟合，不是定律）**。
⇒ 🔴 **同格的 `gmax=2.0` 基准臂在盘上不存在**（`data/m11_p5_l0_runs/` 仅 4 个 `g2.00` 零驱动臂，无基准臂；`g4.00` 臂全缺）⇒ **`gmax` 轴 >1 侧的选择性（(c) 是否比 (a) 掉得多）也是 `unmeasured`**。**这条缺口很关键**：没有它就无法从既有数据判断 `gmax↓` 会不会只是"把两者等比例缩小"。

### 2.7 结论：候选空间的三分

由 §2.1–§2.6，M11 当前可达的候选分成互不重叠的三类：

| 类 | 是否改夹具 | 是否改生产者 | 是否改变 E/I 构成 | 候选 |
|---|---|---|---|---|
| **① 活动依赖的递归压制** | 否 | **是**（极小）| 否（但**使用依赖** ⇒ 等效非均匀）| **N3 = C2 STP depress** |
| **② 静态的递归/抑制侧缩放** | 否 | **否**（`gmax_scale`）/ **是**（`gmax_band`）| 否 / **是** | **N2 = `gmax<1`**、**N1 = 类级抑制增益** |
| **③ 夹具级回路改动** | **是** | 是 | 是 | **N4 = C-4 VIP/SST**、homeostatic 摊平（N5）|

### N2（**第一优先**）`gmax_scale < 1.0` —— 统一递归增益下调

**① 如何可能同时改善 (a) 与 (c)？（直接分量 / 间接分量）**
- **直接分量（逐位可判定）**：`gmax_scale` 在夹具里**逐边**乘到 `gmax`（`mouse_cortex_circuit.py` **L114**：`gmax = (lo + (hi−lo)·rand) * gmax_scale`），而**外部驱动事件的幅度是 `rng.uniform(17,23)`（`run_m11_p5_arms.py` L148），不经过该乘子** ⇒ **递归电导被缩放、外部驱动电导逐位不变**。这是与 §2.1 同一条楔子，且**比 STP 更干净**（纯乘性、无状态）。
- **间接分量（未测）**：被驱动响应中的递归放大份额同时被压 ⇒ `(a)` 会掉多少**待测**；且 E 与 I 被**等比例**缩放 ⇒ **E/I 比不变**（这是它作为"机制"的天花板，见 §3 排序理由）。

**② (a) 侧：它会提高 `active_frac` 还是只提高已活跃神经元的率？**
> **答：两者都不会 —— 它的直接分量只能"降低"兴奋性，不可能招募静默神经元。**
> 但**这在工作点格上不构成障碍**：C2/C3 的 `cfg_a_active_frac` 实测为 **1.000000**（3 实现）⇒ **静默神经元问题在该工作点上不存在**；需要的是"**不要丢掉**"，而不是"抬上去"。⇒ 满足 (a) 的判据退化为 `A ≥ 0.5 Hz` 且 `F ≥ 0.8`（反平凡性）。

**③ (c) 侧：是否**选择性**压制自发播种/往复放电而保留被驱动响应？给出可测选择比定义**
- **结构性理由**：零驱动臂的自发活动**100% 是递归产物**（无外部事件）；基准臂的响应含一个**逐位不变的外部驱动分量** ⇒ **同一个乘子对两者的作用必然不等**。
- **可测选择比（三条，全部并报）**：
  > `Sel   = (1 − R/R₀) / (1 − A/A₀)`   ← **R110 §② 要求的字面形式**（R 相对下降 ÷ (a) 相对下降）
  > `Sel_B = (1 − Z/Z₀) / (1 − B/B₀)`   ← 分子分母都用**合池绝对计数**（避免 `R` 的比值伪影）
  > `Sel_Z = (1 − Z/Z₀) / (1 − F/F₀)`   ← `active_frac` 版本（R114 要求的自变量）
  > 🔴 **`Sel_Z` 在工作点格上退化**：`F₀ = 1.0000` ⇒ 只要 `F` 不下降，分母为 0 ⇒ **该量在该格上构造性不可用，不得作为主判据**（这是 R115 §② 那类"构造性不可判定"的同族，必须预注册以免被当成"选择比无穷大"）。主判据 = **`Sel`**。
- **基准阈值（必须给依据，见 F-1）**：`Sel ≥ 3.0` 判"**具备选择性**"；`Sel ≥ 5.2`（C2 格）判"**够用**（工作点阈值）"。
  **唯一 T=10 s 实测锚** = L0 的 `bias 1.00 → 0.70`（全局兴奋性型杠杆）：`Z: 35,053 → 1,007`（−97.13%）、`B: 121,060 → 34,366`（−71.61%）⇒ **`Sel = 0.97127/0.71612 = 1.356`**。
  ⇒ **阈值 3.0 = 设计选择（derived），依据是"必须比已测的增益型杠杆（1.36）高 >2×"**。⚠️ **不得**拿 σ↓ 探针的 4.5 作依据 —— 那是 **T=1 s**，已被 R130 判为伪影并作废。

**④ 预注册证伪式**（见 §6 **F-1**，逐字）——**可判定、非构造性**。

**⑤ 成本与是否已接线**
- **已接线 ✅（本节点读码 + 产物双重确认）**：
  - 计划级 / 逐臂级 `gmax_scale` 均被 `run_m11_p5_arms.py` 继承并下传：**L562–565**（`for k in ("indegree","gmax_scale",…)`）→ 落 `.spec.json`（**L567–569**）→ 逐臂子进程（**L572–574**）；

> **C2 格锚点（实测）**：`Z₀ = 115,338`、`B₀ = 157,522`、`R₀ = 0.732202`、`A₀ = 0.6`、`F₀ = 1.0000`、`E₀ = 2.597024`。

### F-0（全局可判定性前置；**任一不满足即该格判 `unavailable`，不得判 pass 也不得判 fail**）
1. 每臂 `n_steps = 210,000` 且 `T_ms = 10000`（逐臂断言）；
2. `role = "zero_drive"` 且 `0 < Z < 300` ⇒ **(c) `unavailable`**（**R115 §② 陷阱：`R` 再好也不得判 pass**）；
3. `Z = 0` ⇒ 走 `zero_activity` 显式分支（R116/R134 已验收），落盘 `zero_activity=true`，`(c) unavailable`；
4. `triviality_flag = True`（基准臂 `F` 塌陷）⇒ **不得记为工作点命中**（R118 §④4）；本计划进一步要求 **`F ≥ 0.8`**；
5. **只许用 T=10 s 的读数做率/比值/阈值判定**（R130 第六十七条）；T≤1 s 的读数**只能**用于定价/稳定性。

### F-1（N2 / L4-0：`gmax<1` 天梯 —— 天花板证伪式）
> **(i)** 若梯级中**存在一点**满足 `A ∈ [0.5, 2.0] ∧ Z ∈ W ∧ E ∈ [0.5, 3.0] ∧ F ≥ 0.8` ⇒ **命中** ⇒
> **R140 的前提（"静态参数空间内无同时满足的工作点"）在 `gmax` 轴上被推翻** ⇒ L4 的结论句须重述为
> "在 `(bias, σ)` 二维内无解；在**递归增益轴**上存在工作点" ⇒ 扩网格确认 + 进 G1 定稿（并挂 **P-DEC**）。
> **(ii)** 否则，记 **`Sel_max` = 天梯上 `Sel` 的最大值**（`Sel = (1 − R/R₀)/(1 − A/A₀)`）：
> - **若 `Sel_max < 3.0`** ⇒ **判"递归靶向类机制在当前工作点上不能提供所需选择性"** ——
>   该判据**对 N1 / N3 / 慢适应 / C-4 全体同类机制构成否证**，L4 直接转夹具级改动（**省下 N1+N3 的 ~1.5–3.1 GPU-h**）。
> - **若 `Sel_max ≥ 3.0` 但无工作点** ⇒ **只否证"静态统一递归增益"这一个实现**，**不**否证同类机制 ⇒ 继续 L4-1 / L4-2。
> - **若 `Sel_max ≥ 5.2 且 `A` 已跌破 0.5** ⇒ 登记"**选择性足够但余量不足**" ⇒ 允许把工作点移到 C3 格（`A₀=0.8`，余量 1.6×）**重测**（预注册的**允许**迁移，因为 C3 的 `A₀` 更大而要求的选择性相同量级）。
>
> **阈值依据（必须逐字登记）**：`Sel = 3.0` 是 **设计选择（derived）**，依据 = **唯一 T=10 s 实测的增益型杠杆锚 `bias 1.00→0.70` 的 `Sel = 0.97127/0.71612 = 1.356`** ⇒ 要求 >2×。⚠️ **不得**用 σ↓ 探针的 4.5（**T=1 s，已被 R130 判为伪影并作废**）。
> **非构造性自检**：分支 (i) 与 (ii) 都**未被实测排除** —— C2/C3 在 `gmax=1.0` 实测 `R = 0.732 / 0.909`（离窗口远）⇒ 不会必然通过；而 `gmax↓` 有**实测**的强方向（×2 ⇒ 零驱动 ×6.98）⇒ 不会必然失败 ✓。

### F-2（N1 / L4-1：类级抑制增益）
> **(i) 命中**：存在一级使 `A ∈ [0.5,2.0] ∧ Z ∈ W ∧ E ∈ [0.5,3.0] ∧ F ≥ 0.8` ⇒ 命中（同 F-1(i)）。
> **(ii) 机制被否证**：若**每一级**都 `Sel ≤ 1.5` ⇒ 判"**该机制等价于全局增益型杠杆**"（与实测的 gain 型 `Sel = 1.36` 同族）⇒ **C-类级抑制被否证**。
> **(iii) 过冲判据（不是失败、也不是命中）**：若 `E < 0.5`（抑制压过头 ⇒ **(e)** 出带下界）⇒ 判**过冲** ⇒ 回退上一级，该级**不得**计入命中，且**必须报** `E` 的逐级值（因为 (e) 在 C2 格偏高 2.597 ⇒ **本候选是唯一可能同时改善 (c) 与 (e) 的**，(e) 沿梯级的走向本身就是结论）。
> **(iv) 逐类归因限制**：因 `syn_class` 是逐突触随机标签（§2.4），**只允许**报"该随机类槽权重 ↑"，**不得**写成"PV 细胞介导"；`subtype_*` 四列必须并报但**仅作描述**。
> **非构造性自检**：`Sel ≤ 1.5` 与 `E < 0.5` 与命中三者都是可发生的真实结局（C2 格 `E₀ = 2.597` 距下界 0.5 有 5.2× 的余量、距上界 3.0 只有 1.16× 的余量）⇒ 三个分支都活 ✓。

### F-3（N3 / L4-2：STP depress —— **两条可被判死的预测 + 含"我的预测可能被证伪"的良性分支**）
> **P1（不依赖弹性的强预测）**：引擎**默认档**（`u0 = 0.5`、`tau_fac_ms = 50`、`tau_rec_ms = 500`、`mode = "depress"`）在 C2 格（逐边平均 ISI = 2,131 ms）给出投递因子 **≈1.7e-19** ⇒ **预测 `Z ≈ 0`（`< 300`）⇒ `(c)` 判 `unavailable`，且基准臂 `(a)` 同时塌陷 ⇒ 该档命中「过压」，既不是命中工作点、也不是"机制太弱"**。
> 依据：`mouse_cortex_engine.py` **L943–946**（投递取更新前的 `u·x`）+ `larval_zf_engine.py` **L492**（`u` 按 `tau_fac` 衰减到 0）。**该预测与 2.80 弹性无关。**
> **P2（依赖弹性 2.80 的描述性拟合）**：可用窗口预测落在 **`tau_fac ≈ 5,000 ms`**（预测 `R = 0.0934`，恰好压线）；达标需 **`tau_fac ≳ 5,200 ms`** = 引擎默认的 ~104×、生理易化时常数（~50–500 ms）之上 ≥10× ⇒ **预测"生理 STP 不足以实现该机制"**；且**控制旋钮是 `tau_fac_ms`，不是 `tau_rec_ms`**。
> **判据（对 P1；三分支，全部可发生）**：
> - **若实测默认档 `Z < 300`（`(c) unavailable`）且基准 `A` 显著塌陷 ⇒ P1 成立** ⇒ 判该档为**过压**（记 `invalid`/`unavailable`，**不得记为命中**）；**唯一**允许的继续方式 = **只上调 `tau_fac`（至 {2000, 5000}）重测，不许下调**；
> - **若实测默认档 `Z ≥ 300` 且 `R ≤ 0.10` ⇒ P1 被证伪（良性：均值场估计过强）** ⇒ 直接以实测为准并扩网格；
> - **若实测默认档 `Z ≥ 300` 但 `R > 0.10` ⇒ P1 部分证伪**（未消融到不可判定、也未命中）⇒ 用实测的 (`tau_fac`, `R`) 两点斜率外推到 P2 的窗口，并**检查外推档落在哪一侧**：`tau_fac ≤ 2000 ms` ⇒ **机制可用**；`tau_fac > 5000 ms` ⇒ **判"需非生理参数 ⇒ C2 = no-go（附实测斜率）"**，并登记为"已实测排除，非未测"。
> **判据（对 P2）**：**必须至少测 `tau_fac ∈ {50, 2000, 5000}` 三档**才能判 P2（窗口预测在 5,000 附近）⇒ 这就是 L4-2 为何定 18 臂而非 12 臂。
> **附加强制条款**：`mode != "depress"` 的臂 ⇒ `invalid`；`stp_readback` 缺失 ⇒ `invalid`（§2.2）；**必须报 `Sel` 与 `Sel_B`**（R110 §② 的"必须显式测选择比"）；**`Sel_Z` 在该格退化，不得作为主判据**。
> **非构造性自检**：P1 的三个分支都对应数值上可发生的结局（因子从 1.7e-19 到 0.81 连续可变；`Z` 的判定门 300 是硬门）；P2 的窗口位置依赖弹性，而弹性本身只有 **2 个测点**支撑 ⇒ 窗口可能整体移动 ✓。**两者都不会构造性恒真或恒假。**

### F-4（跨候选停点规则）
1. 任一阶段 **`Sel_max < 3.0` 且无命中** ⇒ **停该阶段**，**不得自动扩网格**（防止"没效果就加档"式烧预算）；
