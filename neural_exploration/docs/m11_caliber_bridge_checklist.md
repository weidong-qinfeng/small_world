## §1 问题定义

### 1.1 为什么 `(b)` 现在**不可判**（而不是"失败"）

`(b)` = 判据带 `silent_frac_calcium_band_lo|hi`（`data/m11_p5_targets.csv` **L115 = 0.101852**、**L116 = 0.229885**，两行 `final=1`、`evidence_level=measured`）与统计量 `silent_frac_zero_count`（`tools/validate_p11_resting.py` **L369** `float(np.mean(c == 0.0))`，`c` = **逐神经元脉冲计数**）**之间有三重不齐**（R183 只登记了第①重）：

| # | 不齐的维 | 表述 | 已登记？ | 出处 |
|---|---|---|---|---|
| ① | **口径（域）** | 带 = 「dF/F 越 `中位+3·MAD` 记 1 次事件，`count==0` 即静默」（**钙事件检测域**）；统计量 = **脉冲计数域** | ✅ **已登记，且项目自己已把它写成禁令** | 带的口径：`data/m11_calcium_silent.json` L63（`event_detection`）/L80；禁令：判据表 **L100** `calcium_vs_spike_caliber_gap`「把钙静默带套到 spike 工作点 ⇒ 把合规配置判成失败（**假阴性**）」；不可混比：同 JSON L64（`ephys_incomparable`）；接线是刻意的：`validate_p11_resting.py` **L727** + **L735** |

### 1.2 「桥」的精确技术定义（8 层，逐层给"同款"出处）

桥 = 把**仿真侧已有的量**（逐神经元脉冲）搬到**带所属口径**上的**唯一**管线：

| # | 层 | 定义（必须逐字照抄数据侧） | 出处（同款依据） |
|---|---|---|---|
| L0 | **输入** | 逐神经元**脉冲时刻**（spike times）或可导出的活动轨迹，**协议窗 T = 10 s**（`±` 时长阶梯 10/20/40 s） | 判据表 L16/L17；`src/mouse_cortex_engine.py` L551–556 |
| L1 | **核** | 脉冲→荧光冲激响应 `h(t)`，`h` **非负**且 `max h = 1`（归一化约定，见 §2.4 的尺度规范不变性） | 登记档：`tools/validate_p10_equivalence.py` L104（`k = exp(-arange(...)*dt/tau)`） |
| L2 | **卷积** | `ΔF/F(t) = A·(h ∗ spikes)(t)` | 同处 **L97–106**（`calcium_forward`，docstring L99「核尾补零后卷积（M9 L42 语义）」） |
| L3 | **采样** | 帧化到数据侧帧率 **6.300006 Hz / 帧间隔 0.15873 s**（帧平均，非点采样） | `m11_calcium_silent.json` L10–12；数据侧帧化口径：`validate_p10_equivalence.py` L109–113 |
| L4 | **基线（逐单元 20 分位）** | `F0 = percentile(F, 20, axis=time)`；`dF/F = (F − F0)/F0`；`F0 ≤ 0 ⇒ NaN ⇒ 0` | `tools/build_m11_calcium_silence.py` **L112–115**；`tools/m12_b5_roi_mask_audit.py` **L340–343**（L338 自述"与 M11 逐行同口径"） |
| L5 | **事件阈值** | **`thr = median(dF/F) + 3·MAD(dF/F)`**，`MAD = median(|x − median|)`；**阈值本身是口径的一部分** | `build_m11_calcium_silence.py` **L116–117**（`EVENT_SIGMA = 3.0` L63）；口径声明：`m11_calcium_silent.json` **L63** |
| L6 | **池化域（决定 L5 分子）** | 数据侧 `thr` 由**逐像素** dF/F 池化算出、**施加于单元自身时间轨迹** | `m11_calcium_silent.json` **L80**（"阈值（像素级 dF/F 中位+3·MAD）施加于**代理单元自身时间轨迹**"）；`m12_b5_roi_mask_audit.py` **L344** vs **L376** |
| L7 | **静默判定** | `count_i = #帧 满足 trace_i > thr`（**越阈帧数，不做去重/合并**）；`silent_i ⇔ count_i == 0`；**静默比例 = mean(silent)** | `build_m11_calcium_silence.py` **L125–126**；`m12_b5_roi_mask_audit.py` **L376**；`m11_calcium_silent.json` L80；判据表 L24 `silent_def_primary=zero_count` |
| L8 | **输出与比较** | 钙域静默比例（逐 seed → 逐臂 → 取中位，与评估器 L720–726 的聚合方式一致） | `validate_p11_resting.py` L720–726、L732–742 |

**L6 的实现选择必须在预注册里显式写死**（仿真侧"像素池化"的对应物 = **逐神经元轨迹池化**：`thr` 由「所有单元 × 所有帧」的单元级 dF/F 池化算出、施加于单元自身轨迹）。这是**口径选择**（不是数值自由参数），但**必须先写死**，否则同一份脉冲可以给出两个不同的静默比例。

### 1.3 为什么必须**预先**注册桥的参数（本文件的核心纪律）

1. **项目自己的纪律第八十四条**（R183 §⑤，`m11_acceptance_master.md` L5311–5317）：不同口径 ⇒ **必须同时登记"口径桥"（且桥本身有依据、有量级），或把该判据判 `unavailable`；绝不允许静默跨口径比较**。
2. **项目的禁令**：判据表 **L100** 已把"把钙静默带套到 spike 工作点"定性为**假阴性来源**；**L99** 已把"模型侧与数据侧静默口径天然不同"写成常数行的 note。
3. **`τ_ca` 在判据表里是"未定稿"项**：`silent_frac_lo` 行（L36）的 provenance 原文写着「钙域静默比例带走查依赖口径定稿（清单 §0.7 #9：**帧率 / τ_ca / 神经域须读回断言**）⇒ 未定稿」。⇒ **τ_ca 是项目自己点名的未决口径项** ⇒ 桥若用它而**不预先冻结**，就是把"未定稿的口径常数"偷偷变成"事后可调的旋钮"。
4. **交接件已把它写成头号风险**（`m11_g1_resume_v2.md` **L142**）：「凡'为了让 `(b)` 落进带'而试出来的参数，**一律不得用于判定**」。
5. **§3.6 的实测事实（本次新增）**：在 G1 工作点上，`(b)` 的落带与否**恰好被一个整数决定**（`K = 5` 落带、`K = 4`/`K = 6` 都落带外，三 seed 一致）⇒ **一个旋钮就能把 `(b)` 从 fail 拧成 pass**。这正是"必须事前冻结、且必须做敏感性全报"的**定量理由**。

### 2.4 尺度规范不变性（**A 不是自由参数**，附强制自检）

因为 L5 的阈值**由被测轨迹自己算出**（`thr = f(同一批 dF/F)`），把 `ΔF/F` 整体乘正数 `α` 会让 `median/MAD/thr/轨迹` **同倍缩放** ⇒ `count_i` 不变。故：

> **断言（尺度不变性）**：对桥-B1（无噪、线性），`CaSilent` 与 `A` 无关。
> **强制自检（0/1）**：以 `A = 0.15` 与 `A = 0.30` 各跑一遍，**逐单元 `count_i` 必须逐位相同**（`np.array_equal`）。若不同 ⇒ 实现有错（例如把 `thr` 写成了外部常数）⇒ 该步判 `invalid`。

**推论**：`A = 0.15` 的"0.15"这一数值**不参与判定**；真正的决断量是**无量纲比** `ρ := thr / A`（§3.2）。⇒ 桥-B1 的"幅度"争议被**完全消掉**。

### 2.5 观测窗与协议窗（⚠️ 与 §1.1② 联动）

## §3 无参数 / 弱参数路径（**本节是全篇第二重点**）

> 目标：能否**不建整条正演**就判 `(b)`？结论先说：**能给出一个严格的两侧边界与一张决断地图（ρ 三区），但中间区（ρ∈(0.925, 5]）仍然需要时刻模型 ⇒ 不能只靠边界判完。** 下面逐条给证明、给假设、并**如实报告攻不动的地方**。

### 3.1 探测器的两个结构性质（前置）

**(P1) `thr` 是自洽量、不是外部常数。** `thr = median(y) + 3·MAD(y)`，`y` = 被测 dF/F 池化的样本（数据侧：逐像素；见 §1.2 L6）。
**(P2) 核非负 ⇒ 单帧上界。** 若 `h ≥ 0` 且 `max h = 1`（归一化约定），则任何时刻 `y_i(t) = A·Σ_{k∈spikes_i} h(t − t_k) ≤ A·k_i`，其中 `k_i` = 窗内脉冲数。（帧平均是线性算子，故对**观测到的帧平均轨迹**同样成立。）
**推论 (P3)**：`k_i = 0 ⇒ y_i ≡ 0`。若还满足 **`thr > 0`**（可数值核验的 0/1 断言），则 `y_i ≡ 0` 不越阈 ⇒ **零脉冲 ⇒ 必零事件**（**这就是 R184 §③ 的包含关系，此处给出更完整的假设清单**）。

### 3.2 定理 1（严格、**不需要任何时刻模型**）：下界 `CaSilent ≥ frac(c_i < ρ)`

> **设** (P2) 成立、(P3) 的 `thr > 0` 成立，并**设探测器对"真静默"单元无误报**（即 `y ≡ 0` 的单元必被记为 0 事件）。记 **`ρ := thr / A`**（无量纲）。
> **则**：若 `k_i < ρ`，有 `y_i(t) ≤ A·k_i < A·ρ = thr`（∀t）⇒ `count_i = 0` ⇒ **单元 `i` 属钙域静默集**。
> **⇒ `钙域静默比例 ≥ frac{c_i < ρ}`**（严格）。

- **取 `ρ = 1` 立即退化为 R184 §③ 的 `≥ frac(c_i = 0)`**（`m11_acceptance_master.md` L5367–5377）⇒ 本定理是它的**推广**（把"零脉冲"放宽到"脉冲数不足 `ρ` 个"）。
- **注意**：`frac(c_i < ρ)` **不需要时刻** ⇒ 只要 `ρ` 已知，就能**在已落盘的 `_counts.csv` 上直接算**（§3.6 已算）。
- ⚠️ **攻不动的地方**：**`ρ` 本身需要桥**（`thr` 是仿真轨迹的池化统计量）⇒ 定理 1 是"**给定的桥 ⇒ 免费的更强下界**"，不是"无需桥"。

### 3.3 定理 2（**等价性**）：`ρ ≤ s(Δ)` ⇒ 两口径**恒等**

> **额外设**：单脉冲在其**归属帧**上的帧平均取值 `≥ A·s(Δ)`，其中 `s(Δ) := (1 − e^{−Δ/τ})/(Δ/τ)` 为帧平均衰减因子（`Δ` = 帧间隔）。**若 `A·s(Δ) ≥ thr`（即 `ρ_s := thr/(A·s) ≤ 1`）**，则任何 `k_i ≥ 1` 的单元在其**首个脉冲所在帧**上 `y ≥ A·s ≥ thr` ⇒ 必被记为 ≥1 事件 ⇒ **该单元必属钙域活跃集**。
> **⇒ 结合定理 1 的 `ρ=1` 版：`钙域静默比例 ≡ frac(c_i = 0)`（与 spike 域零计数比例**恒等**）。**

- 数值：登记档 `τ = 1.0 s`、`Δ = 0.15873 s` ⇒ **`s(Δ) = 0.92472`**（本节点用 `python3` 直算：`1−e^{−0.15873}=0.146783`，`/0.15873=0.92472`）。
- ⇒ **`ρ_s ≤ 1（即 `thr ≲ 0.925 A`）时，桥**根本不需要时刻模型**，`(b)` 直接可判**：取值 = spike 域零计数比例 = **0.000122**（§3.6 实测，G1 工作点）⇒ **落在带外（< 下界 0.101852）⇒ `(b)` = `fail`（严格）**。
- ⚠️ 该等价性**依赖"无噪"**：一旦加噪声，`y ≡ 0` 的单元可能被噪声抬过 `thr`（误报）⇒ 等价性退化为"近似"（R184 原文 L5374 已把这一点登记为"唯一外部依赖"）。

### 3.4 定理 3（**反向严格界**：`ρ > 5` ⇒ `(b)` 严格 `fail`）

由定理 1，**`ρ ∈ (K−1, K]` ⇒ `CaSilent ≥ frac(c_i < K)`**。把 §3.6 的**实测**计数分布代入（G1 工作点、三 seed）：

| `ρ` 区间 | 严格下界 `frac(c_i < ρ)` | 与带 `[0.101852, 0.229885]` 的关系 | 结论 |
|---|---|---|---|
| `ρ ∈ (0, 1]`（且满足 `ρ_s ≤ 1`） | 0.000122（**恒等**，定理 2） | **低于下界** | **`fail`（严格）** |
| `ρ ∈ (1, 4]` | ≤ 0.076294 | 低于下界 | 未定（需把值抬 1.3–800×，靠时刻） |
| `ρ ∈ (4, 5]` | **0.222412** | **在带内**（距上界余量 **3.25%**） | 未定（窄窗，见 §3.5） |
| **`ρ > 5`** | **0.453003** | **高于上界 0.229885** | **`fail`（严格，不需时刻模型）** |

> **⇒ 严格边界（本次的核心交付之一）**
> **① `ρ ≤ s(Δ)=0.925` ⇒ `钙域静默比例 ≡ 0.000122` ⇒ `(b)` 严格 `fail`。**
> **② `ρ > 5` ⇒ `钙域静默比例 ≥ 0.453003 > 0.229885` ⇒ `(b)` 严格 `fail`。**
> **③ `ρ ∈ (0.925, 5]` ⇒ 严格界**不足以判定**，必须有时刻模型（或必须实测）。**

⇒ **这条边界直接回答任务书的问法**：`钙域静默比例 ≥ spike 域零计数比例` **可严格成立**（假设：非负核 + `max h = 1` + `thr > 0` + 检测器对真静默无误报；R184 已用较弱的形式登记），**但它的方向只给"下界"⇒ 不能单独判 `(b)`**；**真正有判定力的是定理 2 的"恒等"与定理 3 的"上界反证"**，二者合起来把 `ρ` 轴切成 **严格 fail / 未定 / 严格 fail** 三段。

### 3.5 决断地图（给主 agent 的一页结论）


⇒ **⇒ 若预注册档给出的 `ρ` 落在两侧严格区（ρ ≤ 0.925 或 ρ > 5），`(b)` **可判 `fail`**，且**该结论对时刻模型完全不敏感**（这是"已测且可判定"的少数情形）。
⇒ **⇒ 若 `ρ ∈ (0.925, 5]`，则 `(b)` 的判定**依赖时刻模型**：按 §6 的规则，若扫描显示"能撞进也能撞出" ⇒ **`(b)` 判 `unavailable`（口径不稳）**。
