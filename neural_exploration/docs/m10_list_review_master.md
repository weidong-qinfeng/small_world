## 二、主agent裁决的 3 项判据补强（规划节点提出，全部采纳）

### 裁决 1：连接组可得性 → **实施节点第一件事**
**采纳**。斑马鱼全脑 EM 重建为"进行中"资源（不同于 M9 的已发布事实），故：
1. **第一任务是数据源可达性探针**（`tools/fetch_m10_*`），逐源实测并登记（**已知：本机 `zebrafishbrain.org` 可达 / `zenodo.org` 超时**）；
2. **必须先裁决 `full` / `partial` / `none` 三态**，再定 P6 机制归属强度：
   - `full` → P6 可按结构归属断言；
   - `partial` → 判据带**运行前按子集重定稿**，消融归属降级；
   - `none` → 显式降级为"M5/M9 式可验证抽象"，报告**前置声明"结构证据级别 = 抽象"**，**禁止把抽象当连接组**。

### 裁决 2：P6 慢变量硬判据（防"扫参数直到 bout 出现"）
**采纳补强**。P6 除三级自检门（不自持 / 驱动弹性 / bout>0）外，**新增一条硬判据**：
> **慢变量的时间常数须落在生理范围且与 bout 时长分布的时间尺度同阶**（否则 bout 来自慢变量之外的机制）。

并同时施加：**全局参数总数 ≤8** + **参数范围预注册** + **直接读出慢变量轨迹**（STP u/x、GABA_B 电导、g_mod）与群率慢涨落的相关性 + **关闭态等价**（STP 关 / GABA 亚型归一 / 调质增益=1 → 必须退化回 M9 语义逐 spike 一致）。

### 裁决 3：P7 等价检验口径（**最关键**，决定核心判据的证据力）
**采纳补强**：
1. **"不可区分"必须操作化为等价检验**（**TOST 类两单侧检验**）+ **预注册等价边界**，而非"数值接近"；
2. **预注册 2 Hz 采样混淆的量化**：先算出 1–2 Hz 采样对 1–2 Hz 发放率估计的**衰减因子**，否则 KS 不能跨口径比较；
3. 沿用：同管线反演 + **同管线代理零分布**（零假设地板）+ **窗内/全尾双口径并列** + 理想上限制声明 + session 级隔离 + **不声称逐神经元对应**（只到区域级）+ 证据级别标注（L1/L2/L3）。
