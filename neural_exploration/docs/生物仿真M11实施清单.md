## §0 总则

### 0.1 里程碑目标与交付物

**一句话目标：在哺乳动物皮层微环路上，把 M9/M10 未解决的"慢状态结构"当作开放输入正面攻克，并用
"结构与功能同源"（MICrONS 同一动物的 EM 重建 + 双光子钙成像）这一 M10 不具备的金标准，检验
层流结构 + PV/SST/VIP 抑制亚型 + 慢状态变量三者齐备时，单细胞/群体反应性质、γ 谱与决策动力学能否被
确定性动力学复现。**

设计文档 §五 M11 的四条内容（逐条落地为判据）：

1. **皮层模板**：层流结构、兴奋/抑制平衡、PV/SST/VIP 亚型配置（权重与连接规则来自 MICrONS/NMC 统计）
   → §3（结构装配）+ §1.1（结构数据门）；
2. **验证单元从"行为"细化为"单细胞/群体反应性质"**：方向/取向调谐、对比度-反应曲线、γ 振荡谱、
   视觉刺激的群体解码 → §5.1–§5.5（P7–P11）；
3. **IBL 任务复刻**：视觉决策中的证据累积动力学（ramping）、选择解码、反应时分布 → §5.6（P12）；
4. **反证路径（设计文档原文）**："若 γ/兴奋-抑制平衡对不上 → 抑制性亚型比例与连接权重 → 增加细胞类型多样性；
   若决策累积动力学缺失 → 检查突触后整合时间常数/循环连接 → **增加时间常数多样性（T1 可塑性的时间尺度）**"
   → §4（慢状态机制门 C-1..C-8）+ §8（反证路径）。

**Pass（设计文档 §6.3 M11 行）**：V1 调谐与层流反应模式 vs Neuropixels/双光子数据**分布一致（统计）**；
γ 振荡谱一致；IBL 行为（正确率/反应时/策略）复现；任务相关群体动力学（解码准确率曲线）一致。
**设计文档未给出 M11 的数值通过线** → 本清单**必须把"分布一致"操作化为可测的等价检验/优越性检验**
（§0.7 #4、§5.2），并在数据门后用 `m11_equivalence_protocol.csv` **运行前定稿**（禁止"看起来接近"类判据）。

**交付**：① 小鼠皮层微环路仿真（层流 + 三类抑制亚型 + 慢状态变量）；② **慢状态机制阶梯判决表**
（M11 首要科学产出，逐候选登记"奏效/无效"）；③ 同源结构-功能对照报告（MICrONS，`measured` 级）；

### 0.6 科学假设（预注册，可检验；每条配反证路径）

- **H1（M11 总命题，铁律 A+B+C 的检验）**：在哺乳动物皮层微环路的**同源结构-功能**数据约束下，
  **层流结构 + PV/SST/VIP 抑制亚型 + 慢状态变量 + 视觉前端**四者齐备时，单细胞/群体反应性质、γ 谱、
  决策动力学与全脑（皮层）活动统计可被确定性动力学同时复现（任一通道失败即反证）。
- **H2（M11 的首要命题，A5 的正面承接）**：**慢状态结构需要"皮层回路级慢变量"，而非单突触快慢时间常数**——
  M10 已在斑马鱼抽象网络上排除后者（STP τ_rec≤2 s / GABA_B τ≤0.4 s 全阶 bout=0）；
  M11 的判定形式：**存在至少一个回路级候选（C-4..C-8）在预注册范围内使 dwell 结构在目标工况密度下成立**。
  **H2 的否定形式（全候选无效）= "慢状态结构不是时间常数问题而是结构问题"的最强加固** → 缺失机制清单。
- **H3（抑制亚型的必需性）**：PV 介导的**快抑制**是 γ 谱（30–80 Hz 峰）与调谐锐度的必需条件；
  消融 PV 槽（或把 PV 抑制慢化到 SST 时间常数）→ γ 峰功率显著下降且调谐宽度增加
  （方向与 Cardin 2009 一致：驱动 FS 细胞诱导 γ 并控制感觉反应；PMID 19396156）。
- **H4（结构-功能映射的必需性，M11 独有）**：**E→E 连接概率与功能相关性的映射**在模型内成立
  （MICrONS 论文 principle：结构连接概率与功能相似性同向）→ 若模型在"给定真实结构 → 功能相关"上不成立，
  则**权重/动力学规则**而非结构是缺失项（可定位反证）。
- **H5（慢变量是决策 ramping 的必需条件）**：慢变量（C-1/C-7 类）是 IBL 证据累积（ramping）
  与反应时分布的必需条件——**慢变量消融 → ramping 斜率显著下降**（设计文档 §五 M11 反证路径：
  "增加时间常数多样性（T1 可塑性的时间尺度）"的直接检验）。
- **H6（E/I 平衡是对比度增益控制的必需条件）**：抑制电流/兴奋电流比落带同时给出 contrast-invariant
  tuning 与对比度-反应饱和曲线；**抑制阻断消融 → 增益控制消失 + 反应发散**。
- **H7（负向假设，诚实性）**：点神经元 + 群体尺度**足以**支撑分布级调谐/γ 谱/解码判据，**不足以**支撑
  逐细胞波形与树突计算声称（本清单明确不声称，§0.3 #5）；违反 → P-EXT1 回归。
- **H8（负向假设，诚实性）**：IBL 复现只承诺**试次级分布统计**（正确率/RT 分布/psychometric），
  **不声称逐试次预测**、不声称训练史/侧偏等行为装置细节。

### 0.7 判据可测性预注册（结构性限制——判据设计时就要考虑；M3–M10 全部教训的强制落地）

1. **目标工况密度复测（M9 §10 新增铁律）**：对齐与判据**必须在目标发放密度下复测**（"稀疏工况通过"
   ≠ "密集工况正确"）。M11 预注册两种密度锚：**MICrONS 钙域推断密度**（由成像参考量反演）+
   **Allen Neuropixels 电生理密度**（`measured`，运行前读回断言）。**禁止**只用稀疏链式网络作对齐。
2. **绝对数值不可跨里程碑移植（E-M9-1 依据改写 + RF-M11-1）**：禁令依据换成**两条仍然成立**的实测事实
   （原依据"M9 全规模数值 +28% 不可复现"**已被主agent 独立探针否证**，见 `docs/m9_report.md` §11.1）：
   ① **"可复现 ≠ 正确"**——M9 冻结引擎走其自身 `run_resting` 入口重跑 = **4.678288 Hz** vs 记录 4.6783 Hz
   （相对偏差 **2.6×10⁻⁶**，完全可复现；"+28%" 是复核工具的 settle 窗口径缺陷），但**同口径下只修 CSR
   投递公式**即得 **3.5225 Hz（−24.7%）**、静默比例 **0.585→0.762**，且两个独立修正实现交叉一致到 **1.7%**
   ⇒ **M9 的绝对值是"缺陷档"**（§11.1b）；② **跨物种/跨制备/跨口径不可移植**——M9（果蝇）/M10（斑马鱼）/
   M11（小鼠 V1）的绝对速率、相关、dwell 及其量纲口径均不同（M9 教训 B2 口径纪律）。
   ⇒ **禁止**把 M9/M10 的任何绝对速率/相关/dwell 数值作 M11 判据带；M11 的带**只能**来自
   （a）MICrONS/Allen **同口径实测量**，或（b）**逐条 provenance 化的文献**（每行带 DOI/PMID）。
3. **口径核对（M9 B2）**：跨脚本/跨版本/跨里程碑比较前核对**全部口径**（物理档、T/settle、帧率、
   反演口径、参数形式、反转电位、内核版本）；M11 特有：**钙成像口径（τ_ca/帧率/神经域）**、
   **电生理口径（spike sorting 质量/层归属）**、**瞳孔/运动校正口径**。
4. **"分布一致"必须操作化为检验（A10）**：① 结构性指标 → **TOST 等价检验**（预注册 margin，给 margin+CI95+p，
   等价 ⟺ `max(p_low,p_high)<0.05`）；② 信息性指标（解码）→ **优越性检验**（> 置换零分布上界 且 ≥ 下限）；
   ③ **边界可达性自检**：把目标数据随机劈两半，用同一协议判等价 → **必须通过**，否则边界须重定稿（M10 L20.3）。
5. **判据必须先用"应当给 0 的负对照"自检（A9）**：M11 的负对照清单（§5.7 聚合）：
   ① 恒定高活动网络（bout/dwell 判据必须给 0 或退化）；② 恒定静默网络（率分布判据必须给 0）；
   ③ 打乱标签解码臂（准确率必须 ≈ 置换地板）；④ sham 零臂（逐位无变化）；⑤ 随机连接对照臂（结构类判据）；
   ⑥ **M10 失效级皮层复现臂（必须仍 bout=0）**（A5）。负对照不过 → 该判据 `invalid`。
6. **静默失效分级（A7 + M9 B3）**：`invalid`（异常被吞/编码路径未生效）/ `unavailable`（预算/环境未测）/
   `fail`（真反证）/ `pass` 四态；**禁止**把 `invalid` 或 `unavailable` 计为 `fail` 或 `pass`。
   **编码路径前置断言**：任何抑制/亚型/慢变量实验前断言槽计数 + 状态张量变化 + 读回值一致。
7. **机制级阴性结论的前置断言（§0.3 #15）**：报"机制无效"前必须断言实施与参数活性（读回 + 非零变化 +
   作用域守卫）；**字段存在 ≠ 生效**（M10 L21 教训）。
8. **时间尺度与协议窗匹配**：**T ≥ 3× 目标 dwell**（先由 §1.5 定稿 dwell，再定 T）；若目标 dwell 为
   数十秒级 → T ≥ 120 s 级协议，须先过 §10.1 预算探针；**不得**用 2 s 窗去判 26 s 级结构（M10 L19.3 教训）。
9. **钙成像口径限制**：MICrONS 为钙成像（帧率/神经域口径须**读回断言**）→ 只承诺**钙域统计级**；
   **不声称单峰时序**；报告必须并列"窗内反演 / 全尾反演"双口径；正向模型为无噪声理想上限。
10. **电生理口径限制**：Allen Neuropixels 的层归属/细胞类型标签来自估计（非同一细胞转录组）→
    类型级判据用**分布带 + 方向**，不声称逐细胞类型身份。
11. **权重不可辨识性**：MICrONS 连接组给出**结构**（连接有无/概率/可能权重代理）但**不给出功能权重**→
    类级缩放 + 文献先验 + 少量全局参数（**≤40 个**）；**不做逐突触拟合**；逐突触拟合/过拟合 → 反证记录。
12. **数据可比性（设计文档 §九）**：品系（C57BL/6J 等，逐源登记）/ 龄期 / 麻醉 vs 清醒 / 刺激集
    （自然电影 vs 参数化光栅）/ 眼动与运动状态 —— **凡跨源比较必须登记差异**；MICrONS 为**清醒 + 自然与
    参数化刺激**（Nature 2025 摘要，本轮实测抓取），Allen 视觉编码为清醒被动观看 → 两者不同，
    **不得混用为同一带**。
13. **长任务纪律**：分段调用 + 段间 RSS/ms-step 落盘 + 增量日志 + 完成标记；**终止前必须查进度**；
    逐目标/逐试次**全新子进程**（显式 venv 解释器，禁 `sys.executable` 会丢 venv 与项目根 sys.path）。
14. **同一全规模任务禁止并行（MPS 争用）**：开跑前 `ps aux | grep <task>`；违规 → 该轮 `invalid`。
15. **长测退化两类**：① 长单次调用退化（分段绕）；② **同进程跨试次退化**（逐试次新进程绕）；
    另：**多延迟组 >30× 慢**（M10 L18.1）→ M11 的层间延迟必须**打包分组**（§2.2 E3b）。
16. **判据带定稿纪律**：全部带在协议运行前定稿 CSV，**不事后调**；交付物审计（§10.2）逐行核对。

### 0.9 计算预算先例与纪律（M9/M10 实测锚 → M11 预注册）

- **M9 实测锚**：139,255 神经元 point 档 **0.42–1.02 ms/step**（静息定稿 0.898）→ 30 s 单试次 **0.15 GPU-h**；
  规模分解 `t = a + b·N`（a = 0.29–0.07 ms 固定项、b = 3.3–5.2e-6 ms/神经元/步）。
- **M10 实测锚**：100,000 神经元 / 2M 边 → **1.4285 / 1.4258 ms/step**（两独立新进程），
  30 s 单试次 **0.238 GPU-h**，RSS **2,212–2,238 MB**；但该探针活动水平偏高（147.7 Hz/神经元）⇒
  **ms/step 偏保守**（"墙钟混入发放密度"——M10 L18.4 教训：探针网络必须标定到生理活动区才可与锚比较）。
- **M11 预算推算（预注册，G0 探针实测修正）**：
  - **规模三档**（铁律 C 决策，见 §2.4）：`N_small = 8,000`（分层柱简化）/ `N_mid = 31,000`（NMC 等价）/
    `N_full = 75,909`（MICrONS 功能神经元数，`measured`：Nature 2025 摘要"~75,909 pyramidal cells L2–L5"）。
  - **单步成本预推**（线性项按 N，固定项按 M10 锚；M11 机制开销因子 **1.5–2.5×**，因四亚型槽 + 慢变量
    状态张量 + 层间延迟分组）：
    N_small ≈ **0.15–0.45 ms/step**；N_mid ≈ **0.3–0.9 ms/step**；N_full ≈ **0.6–1.8 ms/step**。
  - **单试次（T=30 s, dt=0.05 ms ⇒ 600,000 步）**：N_small **0.025–0.075 GPU-h**；N_mid **0.05–0.15**；
    N_full **0.10–0.30**（预注册上限 **≤0.5 GPU-h**，与 M10 同档）。
  - **长协议（T=120 s，dwell 判据必需）**：单试次 = 4× 上一行 → N_mid **0.2–0.6**、N_full **0.4–1.2 GPU-h**
    → **预注册 T=120 s 只允许在 S 门的关键条件上跑**（≤6 条件 × 3 试次）。
  - **真正的压力仍在条件数 × 试次数**：功能判据（调谐/层流/对比度/γ/解码）需**大量刺激条件**（设计文档
    "视觉刺激的群体解码"），预注册预算模型 = `Σ 条件数 × 试次数 × T × 单步成本 × (1 + 消融臂数)`。
- **纪律清单（全部为 M9/M10 实测教训的强制落地）**：
  1. **长协议一律分段调用** + 段间记 RSS 与 ms/step（落盘为回归基线表）；
  2. **逐目标/逐试次全新子进程**（显式 venv 解释器）+ 单池硬超时 + 基线计数跨进程复用；
  3. **禁止以"每次调用的动态规模"为缓存键**（M9 真 bug）；新内核过**无泄漏自检**（连续 ≥20 万步
     `current_allocated`/`driver_allocated`/对象数恒定）；
  4. **`torch.mps.empty_cache()` 禁用**（M9 实测否决）；
  5. **预算判定用稳态 ms/step**（禁用试次 0 的预热值）；
  6. **探针网络必须标定到生理活动区**（M10 L18.4），否则墙钟不可与锚比较；
  7. **先探针 → 裁决 → 再烧**（§10.1）。

- 状态转换：**2 状态 HMM（同算法同参数）** → 占用比例 + 转换率 + **dwell 中位/p90/max**；

### 2.3 引擎正确性验证（G0 门——**对齐门必须在目标工况的发放密度下通过**）

- **参考模型**：① M9 冻结 **300 two_comp 定稿配置**（CPU Brian2；**稀疏工况**，验证"非投递语义不动"）；

  ③ **M10 T4 全规模锚**（`data/m10_engine_probe*.json`：1.43 ms/step 与三进程脉冲一致）。
- **对齐判据（预注册；(a)–(f) 沿 M9/M10，(g)(h) 为 M11 新增）**：
  - (a) **逐神经元 spike 时间对齐**：≥99% spike 时间差 <0.1 ms（GPU 浮点重排为测量限制，**逐位不承诺**）；
  - (b) **状态比例**：静默比例差 <1 pp；发放率分布 KS p>0.05；
  - (c) **机制指标**：在同一输入/seed 下，亚型级电导积分与 PSTH 形状一致（Δ < 带）；
  - (d) **确定性**：同引擎同参数重跑逐位/统计级一致（固定 kernel/seed）；
  - (e) **分段可组合性**：k=1/2/5 分段 → **总脉冲与逐神经元计数逐位相同（0.0%）**；
    对照物 = M10 `m10_stage23_summary.json::t3`（0.0%）与对照臂（−0.091%/−0.039%）→ **M11 必须给 0.0%**；

    （M9 冻结内核在此**必须报错/异常**，作为判别对照；M10 已建判别范式）；
  - **(g) 目标密度复测（M9 §10 铁律落地）**：在**两档密度锚**（MICrONS 钙域推断密度、Allen 电生理密度）

  - **(h) 跨进程一致性（M10 T4 升级为硬判据）**：≥3 个**独立新进程**、同一网络/事件表/seed →
    **脉冲总数逐位相同**（M10 实测 14,771,593 ×3）。
- **扩展的语义等价性附加判据（M11 特有）**：

## §4 机制门（P5 = G1 生理工作点门；**P6 = S 慢状态门（M11 首要）**；10–16 天）

> **本节是 M11 的科学核心**。§0.2 A5 已说明：M10 的慢状态结构**未解决**（T=60 s 全阶 bout=0），
> 且 M10 预注册的机制上界（STP τ_rec ≤2 s、GABA_B τ_slow ≤0.4 s、调质 τ_mod ≤10 s **但未接线**）
> 并未覆盖成像 dwell 尺度。**M11 必须把这一族结论当作开放输入，把候选集升级到"皮层回路级慢变量"。**

### 4.0 关于"是否沿用 M10 较小预注册范围"的正面答复（本清单的显式裁决）

M10 实测"预注册机制上界低于目标 dwell 尺度"。M11 **不沿用**该范围，改为**双组预注册**，
并给出三条理由（可复核）：

1. **M10 的 dwell 目标（26.5 s）不是跨物种可移植的判据带**：它来自 **ZAPBench（斑马鱼幼鱼**，
  `m10_imaging_reference.csv::p7_state_transition_rate_hz/f①③`）；皮层的慢状态尺度量级不同
  （文献：up/down dwell **0.3–3 s**，PMID 11017176；清醒态抑制主导，PMID 17507551）⇒
  **M11 的 dwell 目标必须由 MICrONS 功能数据同口径重建**（§1.5 C3），**不得**沿用 26.5 s；
2. **M10 的机制上界是"预注册草案 + M2 STP 语义复用"，不是生理上界**：
   `data/m10_mechanism_ladder.csv` 中 `τ_rec ∈[0.1,2.0] s`、`τ_B∈[80,400] ms` 来自 M10 清单 §4.1.1 的
   预注册；皮层抑制性突触的恢复可跨类达到**数秒**量级（Campagnola 2022，PMID 35271334）⇒
   M11 把 **C-2 的 τ_rec 上界扩到 10 s**，并**逐类**（PV/SST/VIP）分别预注册；
3. **M10 真正缺的不是"时间常数"，而是"回路级慢结构"**：M10 的 M-1..M-4 全是**单突触/单受体/全局增益**
   级机制；皮层特有的慢结构（去抑制门控 C-4、丘脑-皮层慢涨落 C-5、代谢反馈 C-6、慢调质状态 C-7、
   稳态可塑性 C-8）**在 M10 的候选集中完全缺席** ⇒ M11 的候选集是**新族**，不是"把 M10 的参数放大"。

⇒ **M11 的预注册时间尺度分两组**：
**G-fast τ ∈ [0.1, 3] s**（覆盖皮层 up/down dwell 与 γ 包络/慢涨落，最可能命中）
＋ **G-slow τ ∈ [3, 60] s**（覆盖觉醒/调质/代谢状态，用于解释 G-fast 之外的慢结构）。
**两组都必须给"与目标 dwell 同阶"的判定**，且目标 dwell 在 G2 后**运行前定稿**。

1. **机制确已实施（§0.3 #15，M11 硬条款）**：① 参数**读回断言**（写入值 == 读回值）；
   ② **作用域守卫**（该参数在目标档/目标类生效）；③ **状态张量变化非零**（`std(s_i(t)) > 0`）；
   ④ **关闭臂差异 > 0**（机制开 vs 关**必须可测地不同**；若为 0 → `invalid`）。

4. **驱动弹性**：驱动倍数 {0, 0.5, 1, 2, 4, 8} 群率**单调不减** + 4× 增幅 ≥ 下限（草案 ≥0.30）
   + 输出有界（无 NaN/发散）。

   > ⇒ 门 3/4 通过**不能**作为"机制有效"的证据；机制有效性**只能**由门 5/6 判定。
5. **dwell 结构非零 + 与目标同阶（M11 核心自检）**：
   ① 用**与目标数据同一算法同一参数**的 2 状态 HMM 得到**非零**的 dwell；

6. **no-go 对照（A5/A8 硬条款）**：把 **M10 的 M-1（STP 抑制型，τ_rec=1 s）与 M-3（GABA 亚型 A/B）

7. **基线负对照（A8）**：每轮必须跑"基线臂（无任何 C 机制）"并**断言基线不达标**；

### 5.4 P10：γ 振荡与谱（核心判据③）

- **科学问题**：PV 快抑制是否产生并控制 γ？（H3，机制归属锚 = PMID 19396156）
- **协议**：T ≥ 5 s 的持续刺激段（γ 需足够窗做 Welch PSD）；采样率 ≥ 1 kHz（模型侧 spike → 群体
  LFP 代理：突触电流求和或 PSTH 滤波，**口径预注册并落盘**）；≥30 重复；
- **判据（预注册）**：(a) **谱峰频率 ∈ [30, 80] Hz**（峰值位置 + 峰宽）；
  (b) **峰功率相对 1/f 基线的信噪比（SNR）落带**；(c) **层间差异**（与目标数据方向一致）；
  (d) **刺激/对比度依赖**（γ 功率随对比度/刺激强度变化的方向正确）。
- **机制归属（消融，预注册三臂）**：① **PV 槽关闭**（→ γ 峰功率必须显著下降）；② **PV τ 慢化到 SST 量级**
  （→ 峰频率必须下移/消失）；③ **SST 槽关闭**（→ 主要影响率与调谐，γ 变化应小于臂 ①）。
- **负对照**：**无抑制臂**（γ 必须消失或非 30–80 Hz 峰）；**白噪声替代刺激**（峰必须不存在）；
  **相位随机化代理**（谱 SNR 地板）。
- **工具/交付**：`tools/validate_p11_gamma.py` → `data/m11_p10_gamma.csv` + `reports/neuro/m11_gamma.png`。
- **限制（如实）**：LFP 为**代理信号**（非真实电流源密度）→ 只承诺**谱形/峰值/相对功率**，不声称幅度绝对值。

## §6 活动金标准与扰动预测（P14/P13 验证对象；8–14 天）

### 6.1 P14：活动金标准（**MICrONS 同源对照——M11 的方法学升级**）

> **与 M10 的根本差别**：M10 的活动与结构来自**不同动物**（无细胞级对应）；M11 的 MICrONS
> **结构与功能同源 co-registered** ⇒ 可以做"给定真实结构的功能预测"（H4），这是全项目首次。

- **正向模型（`src/mouse_cortex_activity.py`，复用 M10/M9 语义）**：
  `F_i(t) = Σ_k exp(−(t−t_ik)/τ_ca)·1[t−t_ik>0]`；`ΔF/F = A·(h∗spikes)`；**帧化到目标帧率**
  （**帧率必须读回断言**，§1.1.2 风险项；未读回 → 不得做钙域判据）。
- **可逆性自检（管线正确性前置门）**：单脉冲/规则发放自检误差 <1e−9；全规模
  **ρ(重建率, 真率) ≥ 0.99**（M9 L42 实测 0.9997 为参考）；**不达 → 判为管线错误，不得下模型结论**。
- **双口径（强制）**：窗内反演 / 全尾反演并列（M9 L42 与 L25 的量纲定义与修正因子表沿用）。
- **理想上限制声明**：模型 ΔF/F 无噪声/无运动伪影 → **不可与真实成像数值直接等价比较**；
  对照必须用**同管线代理零分布**（相位随机化）作零假设地板，**M11 自建**（不得引用 M9 的 −0.07 或
  M10 的 0.00013）。
- **四指标（判据带定稿于 `data/m11_activity_reference.csv`）**：

| 指标 | 判据 | Pass 语义 | 负对照 / 口径 |
|---|---|---|---|
| **① 率分布** | KS / 分布带（同管线反演） | `D < d_eq` 或 KS p>0.05 | 相位随机化代理；**钙域/电生理域两带并列不混用** |
| **② 群体相关** | 平均成对相关 + 特征值谱 + 有效维度 | TOST 落带（margin 预注册）**且**显著 > 代理地板 | 代理地板同管线自建 |
| **③ 状态转换** | 占转 + **转换率** + **dwell 中位/p90** | TOST 落带（margin 预注册） | **与 P6 同算法同参数**；**不得**用 M10 的 26.5 s |
| **④ 调谐分布** | OSI/DSI 分布（同 P7 口径） | TOST 或 `D<d_eq` | 与 P7 的分工：**P7 = 反应性质面**（刺激诱发）；**P14④ = 与成像同口径的分布面**（触发条件不同，**禁止双重计分**，须在 CSV 中显式标注触发协议） |

- **P14 判定（预注册）**：**四指标中 ≥3 项过 + ① 与 ② 必须含通过项**（结构性指标）；
- **证据级别标注（强制）**：`measured`（MICrONS 真数据）→ 判 PASS；`derived` → PASS(derived)；
  `literature` → **降级通过**，且 P14 标记"未用真数据验证"；`unverified`（采集参数未读回）→ **不得判定**。

### 6.2 P13：扰动预测

- **预注册清单（`data/m11_perturbation_plan.csv`，N=50，确定性选取 + 固定 seed，不事后改名单）**：
  ① **PV/SST/VIP 类消融/激活**（类型级，机制锚最强，对应 H3/H6）；② **层特异消融**（L4 vs L2/3 vs L5）；

- **四项前置门（M9/M10 教训）**：① **操作有效性**（激活臂中目标自身/池发放率必须显著上升，

- **交付**：`tools/validate_p11_perturbation.py` + `src/mouse_cortex_perturb.py` →
  `data/m11_p13_perturbation.csv` + `m11_p13_target_mapping.csv` + `reports/neuro/m11_perturbation_hitrate.png`。

### 6.3 失败归因路径（设计文档 §五 M11 反证路径的落地）

活动/反应性质对不上 → **逐项对照数据定位（不是猜测）**：
① **调质/慢变量**（C-4..C-7 是否真的在起作用——先查 §4.2 实施断言）；

## §8 反证路径（结构 + 活动同源仍不涌现 → 逐级排查）

### 8.1 前置门失败（最先处理，避免浪费）

### 8.2 功能不涌现（P7–P12/P14 任一不达）——逐级排查（**每级 = 显式消融/替换实验，不猜测**）

① **突触权重**（自由参数 → 类级缩放 ≤40 全局参数，**不做逐突触拟合**）；
② **抑制亚型比例与连接权重**（设计文档 §五 M11 反证路径首项："增加细胞类型多样性"）；
③ **视觉前端**（刺激统计/LGN 滤波/输入增益/眼动与运动状态）；
④ **层流结构**（层间投射方向与延迟档——E3b 打包是否引入偏差）；
⑤ **慢变量与时间常数多样性**（设计文档 §五 M11 反证路径第二项："增加时间常数多样性（T1 时间尺度）"）；
⑥ **结构来源等级**（连接概率为 `literature` 时，**不得**把失败归因于"真实结构不足"——归因必须与证据等级匹配）；
→ 输出"缺失机制清单"逐条入档（M14 交付物②组成部分）。

### 8.3 活动统计对不上（P14）

① **先排管线**（可逆性 ρ<0.99 → 管线错误，不得下模型结论）；② **口径失配**（帧率/τ_ca/反演/地垫/
神经域——**必须与目标数据同管线**）；③ **慢状态结构**（回 S 门）；④ **亚型比例与时间常数**；
⑤ **视觉前端**；⑥ **结构来源等级**。每项写出**具体可分辨的差异方向**（例："模型相关偏高 + 静默偏低 →
tonic 偏置仍主导"）。

### 8.4 扰动预测 <70%（P13）

前置门（操作有效性/sham/随机对照/S 门前置）→ 注入语义与幅度 → 权重 → 活动耦合 → 慢状态（回 S 门）
→ 逐项排查；**锚级 vs 池级口径差异必须显式报告**；**`injection_ineffective` 与 `unavailable` 不入分母**。

### 8.5 三态裁决

✅ 通过（进入 M12）/ ❌ 反证（缺失机制清单累积——**"哪些结构/机制在皮层微环路尺度上必不可少"
是科学产出**）/ ↩️ 打回（仅清单/报告不完整）。**"结构 + 功能同源齐备仍不涌现"本身 = 决定性反证结论**。

| 报告 + 回归（P15） | 3–5 天 | ≤10 CPU-h | ≤2 GPU-h（复跑关键图） | 回归失败 → 冻结件违规排查 |
| 交接处置（P16） | 1–2 天 | ≤2 CPU-h | 0 | 反证/限制逐条入档 |

> **总预算草案**：**CPU ≤ 163 CPU-h + GPU ≤ 138 GPU-h**（= 上表逐行求和；以 G0 探针实测修正）。
> **实测锚对照**：M9 实际 **CPU 9.7 / 12、GPU 11.8 / 24**；M10 实际 **CPU ≈1.7 / 40、GPU ≈1.2 / 12**
> （M10 未收尾，故实际远低于上限）。⇒ M11 的 GPU 上限按 M10 草案（170）的 **0.8×** 预注册（M11 通过
> 三档 N 降低单试次成本，但**刺激条件数显著更多**，二者相抵）；CPU 上限略增（150 → 163，多出的是
> 数据门与引擎门的元数据/断言成本）。
> **预估方法（必须写在报告中）**：`GPU-h = Σ_条件 Σ_试次 [ N_steps(T, dt) × ms_per_step(实测) × 3.6e-6 × (1+消融臂数) ]`，
> 其中 `ms_per_step = a + b·N`（M9 锚 a=0.29–0.07 ms、b=3.3–5.2e-6 ms/neuron/step）×
> **机制开销因子（M11 预注册 1.5–2.5×）**；**探针实测替换预估值后才烧协议预算**。
> **最坏情况（必须预注册）**：① 本机负载病态 **10–30× 减速**；② 候选机制需要更长 T（dwell 落在 G-slow）
> ⇒ 长协议成本 ×4；③ 两档密度复测使引擎门成本 ×2。**最坏叠加 ≈ GPU 300–380 h / CPU 400 h**
> ⇒ **触发 NG 门三态裁决**：降 N 档（75,909 → 31k → 8k，判据带运行前重定稿）→ 降保真度 → 降试次 +
> 最短协议 → 云 GPU（主 agent 裁决成本/配额）。**绝不允许静默超支**。
