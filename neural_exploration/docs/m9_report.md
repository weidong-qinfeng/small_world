## 3. 引擎（P2，G0 门）

### 3.1 选型与对齐

- **路线**：本机 Apple M1 Pro + **PyTorch MPS 自研点神经元内核**（`src/adult_engine.py`）——选型判据"**正确性对齐 > 速度**"。
- **对齐验证**（§2.3，300 two_comp 冻结网络 vs CPU Brian2）：

| 变体 | spike 对齐 | 静默 |
|---|---|---|
| torch-CPU-f32 step / chunk | **100.00% / 100.00%**（636/636，gpu-only=0） | 0.8167 |
| **MPS-f32 step / chunk** | **100.00% / 100.00%** | 0.8167 |
| 静默差 / step↔chunk 一致性 / 确定性 | **0.00 pp / 逐 spike 一致（Δt=0.000ms）/ 100%** | — |

- **性能**：全规模 point 档 **0.42–1.02 ms/step**（视活跃度）→ 30s 单试次 **0.069–0.169 GPU-h**；
  **全规模 139,255 隔室直接实测 3.341 ms/step**（非外推）→ 0.557 GPU-h ✓（≤1 GPU-h 预算）。
- **物理档隔离**：定稿档 = `ahp_form=conductance`（钾电导 AHP）+ `e_inh=-80 / ek=-77`；
  legacy 档（恒定电流 AHP + `e_inh=-75`）已备份隔离（**两档不可混用**）。

### 3.2 引擎层关键发现与教训

1. **Python launch 开销主导**：MPS 每步成本 = 固定开销（~2 ms，60-70 个 kernel launch + 每步
   `bool(spk.any())` 同步）+ 规模线性项 → **小规模时 CPU 更快，全规模时 GPU 反超**（交叉点 N≈30-40k）。
   **纪律：禁止用隔离吞吐基准推断逐步依赖内核墙钟**（`torch.compile` 隔离 35.8× 在真实循环中反而是负优化 2.3–2.9×）。
2. **长试次退化**（实测曲线）：ms/step 4.33 → 12.07（**2.8× 退化**）、RSS 6.06 → 15.41 GB（平台）；
   `torch.mps.empty_cache()` 缓解手段**实测否决**（同步昂贵反而更糟）→ **分段调用**（`segment_steps`）绕过。
3. **分段调度 NON_COMPOSABLE**：同一事件表只改 `run()` 切分 → 总脉冲 0.2–0.7% 依赖（17.5% 神经元计数不同）；
   **远小于判据带容差窗，不改变任何判定**（诚实量化）；修法（延迟槽改绝对步号）交 M10。
4. **对齐门捕获真实 bug**：融合内核首版 v 闭式漏 `·Cm` → 网络全静默（spike=0）；等价性门 4 档 100% 捕获。

4. **扰动**：锚为**类型级**（root-id 级映射需 Schlegel 表）→ 命中率分母口径已预注册。
5. **引擎**：torch/MPS 版本绑定 2.8.0；分段 NON_COMPOSABLE 0.2–0.7%。

## 9. 结论与 M10 交接

### 9.1 结论

1. **结构完备性假设的分层检验**：M9 证明**完整连接组 + 生理自洽的点神经元动力学足以支撑
   行为级功能（联想泛化 / 航向地图 / 价效决策）与部分静息统计**，但**不足以自发产生状态切换动力学**
   （bout / 昼夜差异 / 生理活动统计）。
2. **缺失机制已具体化**（M9 最有价值的产出）：不是"权重不对"，而是 **tonic 偏置主导、输入通路增益过低**
   → **必须引入新的状态变量**（短时程可塑性 / 抑制亚型异质 / 调质增益）。这为 M10 提供了**可操作的修复方向**。
3. **M8 的关键反证（缺 GABA）被彻底解决**：数据侧（真实标注）+ 模型侧（AHP 物理修复）双解除，
   **真实抑制平衡首次在 139,255 全脑点神经元上成立**。
4. **单机可行性确立**：自研 torch-MPS 内核（逐 spike 100% 等价）+ 分段调用 → 全规模静息 **0.15–0.38 GPU-h/试次**，
   **无需云 GPU**。

### 9.2 M10 交接（斑马鱼幼鱼全脑——"记录一切"的第二金标准）

**A. 必须承接的缺失机制（按优先级）**
1. **状态切换变量**：STP（突触短期动态）/ GABA 亚型异质（GABA_A vs GABA_B 时间常数）/ 调质增益
   —— 目标：产生 bout/双状态、昼夜调制、生理活动统计（对应 R1/R2/R3/R7）。
2. **tonic 偏置与输入增益的重新标定**：当前 `bias_mv_s=355`（默认）/ `bias_cv=0.60` 使网络自持；
   需降低 tonic 占比、提高感觉输入增益（否则驱动改变无效）。
3. **延迟槽改绝对步号驱动**（修 NON_COMPOSABLE）。
4. 发放率量级下调（4.77 → 1–2 Hz 文献量级）。

**B. 必须继承的方法学纪律**
1. **自检式判据设计**（"无学习臂必须为 0"、"无输入必须自持"）；
2. **判据口径/物理档可比性核对**（跨脚本比较前核对背景驱动、参数形式、反转电位——曾致主agent错误结论）；
3. **参数读回断言 + 作用域守卫**（参数名变更致静默失效，比字段消失更隐蔽）；
4. **长任务直写日志 + 增量行 + 完成标记**；终止前**必须查进度**（"耗时长"≠"卡死"）；
5. **长协议一律分段调用** + 段间记录 RSS/ms-step；
6. **引擎改动必须重过对齐门**；point/two_comp 档改动需显式范围论证；
7. **否定结果必须落盘**（如 v_floor 钳制被证伪 → 才定位到 AHP 物理形式）。
8. **试次/进程隔离**：同一 GPU 进程内连续长试次会**跨试次退化**（L40）→ 逐目标全新子进程 + 单池硬超时 + 基线计数落盘跨进程复用；**子进程必须显式用 venv 解释器**（`sys.executable` 会丢失 venv 包与项目根 sys.path）；
9. **未测 ≠ 未命中**：预算/环境导致的未运行目标必须逐条登记 `unavailable` 并**排除出分母**，禁止把「未测」写成「未命中」（P9 的 CSV 与三态判定均按此实现）；
10. **扰动实验最低配置**：预注册方向预测（先于运行落盘）+ sham 零臂（必须逐位无变化）+ 同规模随机对照 + 操作有效性前置（注入必须有效）+ 未命中项逐条留档。
