   **① 口径一致才可比；② 可复现 ≠ 正确；③ 同一量的两个独立估计器必须断言一致。**
2. **双估计器断言已固化**：`run_protocol` 内 `|pop_rate_hz − pop_trace_mean_hz|/pop_rate_hz ≤ 0.02` 硬断言
   （修复前 13–15% 长期无断言 ⇒ 本可当天抓错）。
3. **自检式判据**：判据先用"应给 0 的负对照"自检（bout 判据首版把记录起止算分隔 ⇒ 饱和网络给 1.0，**不可证伪** → 改 interior 后给 0）；
   **机制级阴性结论必须先断言"机制已被实施、参数是活的"**（D1：接线/实现/**动态范围量级门**三重）。

5. **并发编辑协议**（L42/L45）与 **长作业流程**（>10 min 交主agent 托管；MPS 串行；CPU `OMP_NUM_THREADS=1`）。
