- [ ] P1：**EPSP/IPSP 波形误差 <10%**（对高精度参考解，波形幅度/时间常数）
- [ ] P2：**突触失败（release failure）**：同参数重复运行，失败率与量子释放模型一致（泊松/二项分布拟合）

- [ ] P5：**受体亚型区分**：AMPA（快、短）vs NMDA（慢、Mg²⁺ 阻断、电压依赖）至少各复现一个特征

## 2. 步骤 1：突触模型规格（1 天，纯文档 + 数据）

### 2.1 化学突触（递质释放 + 受体）

**突触前（量子释放）**：
```
动作电位到达末梢 → Ca²⁺ 内流 → 囊泡融合释放
释放概率 p，可用囊泡数 n → 释放量子数 k ~ Binomial(n, p)
（简化：k = Bernoulli(p) 单囊泡，或 n=3–5 多囊泡）
释放失败：k=0 → 无 PSP（release failure）
```

**突触后（受体动力学，二态模型）**：
```
AMPA（快兴奋）：
  dg/dt = -g/τ_AMPA + g_max·δ(t_release)
  τ_AMPA ≈ 2–5 ms
NMDA（慢兴奋，Mg²⁺ 阻断）：
  dg/dt = -g/τ_NMDA + g_max·B(V)·δ(t_release)
  τ_NMDA ≈ 80–150 ms
  B(V) = 1/(1+[Mg²⁺]·exp(-0.062·V)/3.57)   # 电压依赖去阻断
GABA_A（快抑制）：
  同 AMPA 动力学，但 E_rev ≈ -70 mV（Cl⁻）
```

### 2.2 电突触（缝隙连接）

```
I_gap = g_gap·(V_pre - V_post)
g_gap ≈ 0.1–1 nS（C. elegans 缝隙连接典型值）
无延迟、双向、整流可选（C. elegans 部分缝隙连接单向/整流）
```

### 2.3 短期可塑性（STP，Tsodyks–Markram 模型）

```
每次释放后：可利用性 u → u + Δu（易化，τ_fac≈100–500ms）
              资源 R → R·(1-u)（耗竭→抑制，τ_rec≈500ms–1s）
EPSP ∝ u·R
```

**数据文件**：`data/m2_synapse_params.csv`（每行：synapse_type, g_max, tau, E_rev, p_release, n_vesicles…）

## 4. 步骤 3：Brian2 突触实现（2–3 天）

### 4.1 代码结构

```
neural_exploration/src/
  synapse_model.py     # M2 正式实现：ChemicalSynapse / GapJunction / STP
  neuron_pair.py       # 组装：pre(multi-comp) → synapse → post(multi-comp)
```

### 4.2 实现要点（延续 M1 经验）

1. **突触前触发**：Brian2 `Synapses` 的 `on_pre` 事件 —— node3 隔室膜电位跨阈值（如 -20mV）触发 `on_pre` 回调
2. **释放随机性**：`on_pre` 中 `rand() < p_release` 决定是否释放（每次 `network.run` 前固定种子，保证 P2 可复现统计）
3. **受体状态**：`dg/dt` 在突触后方程里，用 `Synapses` 的 `linked_variables` 或直接对 post 组加 `g_ampa : siemens` 变量
4. **NMDA 电压依赖**：`B(V)` 中 V 取突触后隔室实时膜电位 —— 需要 `post.v` 引用，注意 Brian2 变量作用域
5. **缝隙连接**：`g_gap*(v_pre - v_post)` 双向，Brian2 可直接写成电流项
6. **STP**：Tsodyks–Markram 三变量（u/R/E）在 Synapses 内部更新，`on_pre` 前后更新

### 4.3 冒烟测试

- pre 刺激 → post 出现 EPSP（幅度 0.5–2 mV 量级）
- 无刺激 → 无 PSP；释放失败（p_release=0.2 时多次运行出现"无响应"试次）

**验收**：`tests/neuro/test_synapse_smoke.py` 3 断言绿。

## 5. 步骤 4：逐项验证（2–3 天）

### 5.1 P1 波形误差
- `waveform_rmse(v_brian, v_ref)` vs NEURON 参考 → <10%

### 5.2 P2 释放失败统计
- 固定 p_release=0.3，跑 100 次单刺激 → 统计"无 PSP"比例 ≈ 0.3
- 二项检验（或比例置信区间）通过 → P2

### 5.3 P3 短期可塑性
- 50Hz×10 脉冲刺激 → EPSP 序列幅度
- 复现 facilitation（幅度递增）或 depression（幅度递减）至少一种，与文献趋势一致
- 输出：`reports/neuro/m2_stp.png`

### 5.4 P4 电突触
- 缝隙连接两个神经元：pre 发放 → post 近即时耦合（延迟 < 0.1ms 量级）、双向
- 输出：`reports/neuro/m2_gap.png`

### 5.5 P5 受体亚型
- AMPA：快速 EPSP（τ≈2–5ms）
- NMDA：慢 EPSP（τ≈80–150ms）+ 去极化时 B(V) 增大（Mg²⁺ 去阻断）
- 输出：`reports/neuro/m2_receptor_subtypes.png`

**验收**：P1–P5 五个验证脚本 + 判定记录 `docs/m2_report.md`。
