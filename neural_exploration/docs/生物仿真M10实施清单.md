## §0 总则

### 0.1 里程碑目标与交付物

**一句话目标：把 M9 定位到的缺失机制（状态切换变量）在斑马鱼幼鱼全脑上显式修复，并用"全脑活动逐神经元
对照"这一第二金标准检验——结构 + 活动 + 行为三者齐备时，双状态动力学、行为序列与全脑活动统计能否被
确定性动力学复现。**

设计文档 §五 M10：斑马鱼幼鱼是**唯一能在行为发生的同时以细胞分辨率记录全脑活动的脊椎动物**（光片显微镜，
~10 万神经元，~1–2 Hz 体成像），且全脑 EM 连接组正在重建（含神经调质类型标注）——**"结构 + 活动 + 行为"
三者齐备的验证平台，本实验的验证方法学主战场**。**内容**（设计文档四条）：
① 降阶动力学校准（验证目标是**群体活动**而非单神经元波形 → L0 抽象为经校准的点神经元，除某行为需要 HH）；
② **双金标准管线**：行为复现 + 全脑活动逐神经元预测（发放率分布、相关性矩阵、行为状态解码、状态转换时序）；
③ **神经调质系统显式建模（T2）**：DA/5HT 等对全局活动的调制，对照成像中的调质相关信号；
④ 扰动预测：模型预测光遗传扰动后的全脑活动 + 行为变化 vs 实验。
**Pass**（设计文档 §6.3）：**全脑活动统计与成像数据不可区分（分布/相关性/解码准确率三指标）**；行为
（捕食成功率、OMR/OKR、惊吓潜伏期）一致；**扰动预测命中率 ≥70%**。
**反证路径**（设计文档 §五 M10）：全脑活动统计对不上 = **最强反证信号**：缺调质系统？缺抑制性中间神经元
亚型？缺感觉运动耦合细节？逐项对照成像数据定位——**活动数据把"缺什么"变成了可定位的问题**。

**M10 与 M9 的关系（本清单的第一设计原则）**：M9 的核心产出不是"通过"，而是**把结构完备性不足具体化为
机制清单**：状态切换动力学不涌现（bout=0 / 昼夜无差异 / 活动统计不符文献）**三者同根**，
诊断指向"**活动自主自持 + 输入通路增益过低**"（零背景驱动仍保留 98.5% 群率；4× 驱动仅 +7.2%）
→ **放大驱动无效，必须引入状态切换变量**（STP / GABA 亚型异质 / 调质增益）。
**因此 M10 的第一件事不是跑功能判据，而是在 P6（前置机制门）上把状态切换变量装进去并证明其工作**
（§0.2 R1/R3 + §4.1）。**若不前置 P6，M10 必然重演 M9 的 P4(d)/P7/P10 失败模式**——这是本清单最重要的一条纪律。

**交付**：斑马鱼幼鱼全脑仿真（结构 + 行为 + 活动 + 扰动四通道验证报告）+ 状态切换机制升级的判决实验报告
（机制级 + 现象级）+ 全脑活动金标准对照报告（真数据，非文献回退）+ 引擎复用对齐报告 + 必需机制清单追加
（M9/M10 反证累积，M14 交付物②组成部分）。

### 0.3 铁律落地（M10 版，叠加阶段一/阶段二全部铁律）

1. **自底向上逐层验证（不跳层）**：**G2 数据门**（斑马鱼连接组 + 全脑成像 + 行为带）→ **G0 引擎门**
   （MPS 内核重过对齐门，含新增 (e) 分段可组合性）→ **G1 机制门（M10 新增，前置）**：P5 静息标定（含自持/弹性
   双硬判据）→ **P6 状态切换机制升级门** → 身体（P4）→ 机制升级后的功能（P7–P11）→ 扰动（P12）→ 活动（P13）。
   **G1 不过（自持/弹性不达）→ P6 不得启动**；**P6 不过 → P7–P13 协议不得定稿**（避免在未修复的动力学上烧计算，
   M9 教训的直接落地）。
2. **活动与行为双金标准（铁律 B）**：M10 起活动通道**与行为并列**，且**斑马鱼成像数据可得** →
   **活动判据不得默认回退到文献**；任何回退必须在报告中标注"证据级别"（§0.7 #4）。
3. **只为可验证而精细（铁律 A）**：点神经元为主（设计文档 §五 M10 第 1 条：**验证目标是群体活动而非单神经元
   波形**）；HH 仅在某行为明确需要时按需回归（抽象登记册登记，§0.3.5）。
4. **失败即反证（沿用）**：任何 Pass 失败 → 反证路径（§8）+ 缺失机制清单逐条入档 + 三态裁决
   （✅ / ❌ 反证+缺失机制清单 / ↩️ 打回），**绝不静默重试**。
5. **确定性 + 局部物理随机**：p=1/n=1；固定 seed；`PYTHONHASHSEED=0`；新建网络定义**一律确定性哈希**
   （禁 Python `hash()`，M9 R8 教训）；随机仅限突触量子释放/通道噪声；浮点重排**只承诺统计级**
   （§0.7 #3），但**分段可组合性要求逐位**（§0.2 R6）。
6. **判据带定稿纪律**：行为/成像/扰动/标定带**协议运行前定稿于 CSV**（`data/m10_behavior_reference.csv` /
   `m10_imaging_reference.csv` / `m10_perturbation_plan.csv` / `m10_calibration_targets.csv`），**不事后调带**。
7. **数据隔离预注册（设计文档 §6.2）**：拟合集 A（静息/发放率标定——权重与偏置校准）vs
   held-out B（行为）/ C（**活动成像**）/ D（扰动）——**四通道必须同时成立**（§0.8）。
8. **计算预算先例**：**先探针测墙钟 → 再裁决 → 再烧协议预算**；每步骤标注墙钟/预算上限（§0.9/§10.1）；
   超出 → 最短协议 + 测量限制 + 三态裁决。
9. **冻结基线保护（组合不修改）**：M0–M9 全部冻结件（`src/` 下 M0–M9 交付含 `adult_engine.py`/`adult_circuit.py`、
   `tests/`、`tools/validate_p*`、`data/m9_*` 定稿 CSV 与 `m9_network.npz`）**零修改**；M10 **只新建**
   （§0.10 L1）；确需 API 兼容微调 → 逐条登记 `m10_env_notes.md`。
10. **引擎改动的范围论证（M9 §2.5）**：内核任何改动必须重过对齐门；若改动仅影响 point 档而不影响 two_comp 档，
    必须给出**显式范围论证**（M9 验收记录 §六.6 纪律）。
11. **未测 ≠ 未命中（M9 教训 B9）**：预算/环境导致的未运行目标逐条登记 `unavailable` 并排除出分母；
    **禁止把"未测"写成"未命中"**。

| **压缩时间尺度（若涉昼夜/发育）** | 真实 24h 节律 / 5–7 dpf 发育 | 状态切换统计级一致；逐时刻相位不声称 | 节律/发育相位动力学不可压缩（差异消失） |
| **VR/fictive 游泳范式** | 自由游泳 + 完整自然刺激 | 与真实实验协议同构（fictive 游泳/虚拟视觉流），自由空间生态行为不声称 | 某行为需自由探索空间结构 |

### 0.6 科学假设（预注册，可检验）

- **H1（M10 总命题，铁律 B 的检验）**：在斑马鱼幼鱼全脑尺度上，**结构（连接组或子集）+ 状态切换机制
  （STP/GABA 亚型/调质增益）+ 身体-环境闭环**三者齐备时，行为与**全脑活动统计**可被确定性动力学同时复现
  （任一通道失败即反证）。
- **H2（M10 的首要命题，直接承接 M9 R1/R3）**：**引入状态切换变量是产生 bout/双状态与生理活动统计的
  充分必要条件**——存在一种（或多种）候选机制使 (i) 无输入时不自持、(ii) 对驱动呈弹性响应、(iii) bout 非零；
  **H2 的否定形式（任何候选机制都无法同时满足三条）= M9 "结构完备性不足"结论的最强加固**。
- **H3**：**GABA 亚型异质（快 GABA_A + 慢 GABA_B）**是双状态时长的必需条件（仅统一时间常数 →
  bout 时长分布单峰、无法复现成像中的 ON/OFF 双态时长分布）。
- **H4**：**Mauthner 细胞 + 脊髓逃逸回路**是逃逸行为潜伏期（4–10 ms 量级）与逃逸序列的必需结构
  （Mauthner 消融 → 逃逸潜伏期显著延长/消失）。
- **H5**：**视网膜→顶盖（tectum）视觉通路**是 OKR/OMR 与光趋性的必需通路（视网膜输入消融 → 反应消失）。
- **H6**：**调质系统（T2）的显式建模**是**活动统计（群体相关/状态转换）**的必需条件——M9 R7 的直接检验：
  M9 群体相关 0.6220 偏高（自持主导）→ M10 若在调质增益下落到成像带内，则 H6 成立。
- **H7（负向假设，诚实性）**：**纯点神经元 + 群体尺度验证**足以支撑发率分布与解码判据，但**不足以**支撑
  逐神经元波形的声称（本清单明确不声称，§0.7 #5）。

### 0.7 判据可测性预注册（结构性限制——判据设计时就要考虑，M3–M9 全部教训）

1. **时间尺度压缩**：全规模活动匹配需大量试次（设计文档 §7.2）→ 昼夜/发育协议**不可全跑** →
   预注册压缩语义（调制周期压缩到协议窗内，状态切换统计级判据）；逐时刻相位/逐神经元波形不声称。
2. **全规模协议预算上限**：单试次 ≤0.5 GPU-h、单协议 ≤40 GPU-h（草案，G0 探针实测修正）；
   协议 T 取「参考模型通过率 ≥80% 最短 T」× 墙钟 ≤ 预算（M5 §3.5 公式沿用）；超出 → 最短协议 +
   测量限制 + 三态裁决；**先探针 → 再裁决 → 再烧**。
3. **浮点重排 vs 分段逐位（M9 口径必须区分）**：① **GPU vs CPU 逐位一致不承诺**（浮点重排）→ 统计级判据
   （spike 时间差 <0.1ms 比例 ≥99%、静默比例差 <1pp）；② **同引擎同参数、仅改分段切分 → 要求逐位相同**（(e) 判据）；
   ③ 同引擎同参数不同 seed → 统计级一致。
4. **成像分辨率与对比口径限制（设计文档 §九 + M9 L42）**：光片钙成像采样 ~1–2 Hz、群体信号、分辨率有限 →
   **只承诺统计级**；**逐神经元身份对应不声称**（无共同坐标系/无单细胞配准）；**区域级配准对照**若 ZBB 参考脑
   配准图谱可用则纳入（预注册尝试）；报告**必须同时给出"窗内重建/全尾重建"两口径**（M9 L42 教训：τ/T 效应
   约 −14%）；正向模型为无噪声理想模型 → **数值不可与文献成像直接等价**，必须用**同一管线的代理对照**（相位
   随机化零分布，M9 L42 实测 ≈−0.07）作为零假设地板。
5. **扰动预测锚可用性（P12 判据可测性前提）**：**有锚下限 ≥20/50 预注册**（M9 R5 教训沿用于 M10）；
   锚来源见 §1.4；锚缺失神经元预注册 `no-experiment`（不入分母、不静默剔除）；**未测（`unavailable`）
   同样不入分母**（M9 教训 B9）。
6. **连接组完整度分级（M10 特有）**：斑马鱼全脑 EM 重建**是否达到逐突触 + 递质/调质类型标注的完整度
   须在 G2 实测判定** → 三级路径预注册（§1.1.3）：`full`（全脑逐突触）→ `partial`（区域子集/连通性矩阵）→
   `none`（无可用的结构化连接组 → 必须显式降级：用 M9/M5 式"可验证抽象 + 行为反推"，并在报告中标"结构
   证据级别 = 抽象"，**不得把抽象当连接组**）。
7. **权重不可辨识性**：全脑权重是自由参数 → **类级缩放 + M5/M9 先验 + 行为/活动学反推少量全局参数
   （≤40 个）**（沿 M9 §0.7 #7）；**不做逐突触拟合**；逐突触拟合/过拟合 → 反证记录。
8. **判据带定稿于 CSV，不事后调**：发放率带、静默带、自持上限、驱动弹性下限、bout 时长带、三模态频率带、
   OKR 增益带、逃逸潜伏期带、活动四指标带、解码下限、命中率下限——**全部运行前定稿**。
9. **读出灵敏度双轨（M6/M8/M9 教训）**：行为/活动级读出与**机制级判据**（Δw、增益参数、bout 分布形状、
   池级注入有效率）**双轨**；网络级读出不可见 → 子图机制验证 + 测量限制记录（不伪造）。
10. **参数读回断言 + 作用域守卫（M9 教训 B3）**：任何标定参数（bias/tonic 占比/STP u0/GABA 时间常数/

### 0.9 计算预算先例与纪律（M9 实测锚 → M10 预注册）

- **M9 实测锚（冻结，`docs/m9_report.md` §3 + `docs/m9_env_notes.md` L20.5/L34）**：
  - 引擎：Point 档全规模 N=139,255 实测 **0.42–1.02 ms/step**（视活跃度；低活动下界 0.20），
    静息定稿档 **0.898 ms/step** → 30s 单试次 **0.15 GPU-h**；规模分解 **t = a + b·N**
    （a = 0.29–0.07 ms 固定项、b = 3.3–5.2e-6 ms/神经元/步）；
  - 装配：139,255 神经元 + 15.09M 边 / 54.49M 突触 → **分段装配 0.8–2.2 s**、**MPS 显存 1.05–1.33 GB**；
  - 两类退化（**必须按纪律规避**）：① 长单次调用 ms/step 退化 2.8×、RSS → 15.4 GB 后平台；
    ② 同进程跨试次退化 35→>1000 s（**逐目标全新子进程**）；
  - 环境：本机共享高负载可致 **10–30× 减速**；`.venv-m9`（torch 2.8.0 + MPS）为引擎环境基线。
- **M10 预算推算（预注册，G0 探针实测修正）**：
  - **网络规模**：~10 万点神经元（0.72× M9 神经元）→ 单步固定项不变、线性项 ×0.72
    → **预计 0.35–0.9 ms/step**；30s 单试次 **≈0.03–0.08 GPU-h**（**比 M9 更轻**）。
  - **真正的预算压力在"试次数"**（设计文档 §7.2："活动匹配需大量 trial 统计"）：
    预注册活动匹配预算模型 = `试次数 × 协议 T × 条件数 × (1 + 消融数)`。
    草案：活动匹配（4 条件 × 20 试次 × 30s）≈ **2.4–6.4 GPU-h**；行为判据（6 功能 × 3 条件 × 10 试次）≈ **1–3 GPU-h**；
    机制阶梯（3 候选 × 5 档 × 3 试次 × 20s）≈ **0.5–1.5 GPU-h**；扰动（50 目标 × 2 臂 × 3 试次 × 20s）≈ **1–3 GPU-h**。
    **全 M10 草案总预算：GPU ≤ 40 GPU-h + CPU ≤ 60 CPU-h**（以 G0 探针实测修正；超支 → 裁决）。
  - **内存**：M9 网络 npz 仅 **79.8 MB**（15.09M 边）→ 斑马鱼按突触量线性外推
    （若 ~10–30M 边）**~150–300 MB npz**；连接组原始 CSV 若为 10–15 GB 级 → **必须流式解析**
    （pyarrow 列选择，M9 L20.4 惯例：10.2s 解析 / 31.9s 落盘）→ 32GB 统一内存**可行**（预注册硬上限：常驻 ≤8 GB）。
- **纪律清单（全部为 M9 实测教训的强制落地）**：
  1. **长协议一律分段调用**（`segment_steps`）+ **段间记录 RSS 与 ms/step**（落盘为回归基线表）；
  2. **逐目标/逐试次全新子进程**（显式 venv 解释器路径，禁 `sys.executable`）+ 单池硬超时 + 基线计数跨进程复用；
  3. **禁止以"每次调用的动态规模"为缓存键**（M9 真 bug：`_arange` 缓存无界增长）；
  4. **`torch.mps.empty_cache()` 禁用**（M9 实测否决：同步开销反而更糟）；
  5. **预算判定必须用稳态 ms/step**（M9：试次 0 含 MPS 预热 4.09 ms/step，不可用于预算判定）；
  6. **长任务直写日志 + 增量行 + 完成标记**；**终止前必须查进度**（M9：主agent 曾误杀 82% 全绿的回归进程，
     "耗时长" ≠ "卡死"）；
  7. **先探针 → 裁决 → 再烧**；每步骤标注墙钟/预算上限（§10.1）。

### 3.2 游泳三模态（escape / struggling / swimming）

- **模态定义（预注册协议）**：由**刺激条件 + 运动学**联合判定（非单一阈值）：
  - `swim`：自发/温和驱动 → 低幅高频弯曲波、近似周期性、可持续数十周期（**bout 结构**）；
  - `struggle`：强持续刺激 → 高幅爆发、节律不规则、快速疲劳（幅度递减）；
  - `escape`：突发刺激（听觉/触觉类）→ **短潜伏期 C 形起始弯曲** + 高频大角度弯曲波 + 快速定向位移。
- **CPG 层**：段间相位耦合（前→后相位延迟）生成**脊柱弯曲波**；复用时序/肌肉语义
  （`src/muscle.py` 的 `integrate_muscle`/`Muscle` + `src/virtual_body.py` 的 `classify_state`/`StateThresholds` 范式，
  新建 zf 版）。频率梯度与幅度梯度**由驱动参数决定**，不硬编码模态（否则判据自证）。
- **判据落带**：三模态的**频率带 / 幅度带 / 序列统计（模态停留时长、切换概率矩阵）**落带（§1.3 表）。

### 3.3 视动反应（OKR/OMR）与光趋性

- **视觉输入**：光流场（条纹/光栅运动）→ 视网膜局部运动编码 → 顶盖/视动通路输入通道；
  参数（条纹空间频率、光流速度、对比度、暗/亮背景）与真实协议同一口径（§1.3 表）。
- **OKR 闭环**：光流 → 模型输出转向/眼动补偿 → 虚拟环境光流更新（**闭环**，沿 M9 VR 球协议范式）。
- **判据落带**：**OKR 增益 vs 光流速度曲线**（<1，分档）+ **相位滞后**；**OMR** 方向正确性/游泳方向统计；
  **光趋性**（向光/避光）方向正确 + 转弯速率带；**视网膜输入消融 → 反应消失**（H5 机制归属）。

### 3.4 水动力学简化（抽象登记 §0.3.5）

- **抽象**：段级阻力/阻尼模型（各向异性阻力：轴向低阻、侧向高阻）+ 惯性项；**不求解 Navier–Stokes**；
- **承诺**：**只承诺运动学统计**（弯曲波频率/幅度/位移方向/转弯率）；**不声称力/涡度精确值**；
- **回归条件**：某行为需要真实流体反馈（逃逸推力、转向效率、捕食加速）且运动学统计不达 → 回归精细流体模型。

#### 4.1.2 机制自检门（**每个候选级都要独立通过，才允许进入功能评价**）

**自检式判据（M9 教训 B1：判据必须原则上可证伪）**——三条全过才算该级"生效"：

1. **无输入不得自持**：零外部驱动 + 零背景率的群率 / 基准群率 **≤ 预注册上限（草案 ≤0.10）**

2. **驱动弹性**：驱动倍数 {0, 0.5, 1, 2, 4, 8} 下**群率单调递增** + **4× 驱动增幅 ≥ 预注册下限（草案 ≥30%）**

3. **双态存在**：活动 bout 占比 **> 0**（**M9 实测 0.0000 → 反证基线**）+ bout 起始率非零。

#### 4.1.3 现象级判据（该级通过自检门后评价）

- **双态**：活动态/静息态**占用比例差显著**；**bout 停留时长分布**呈**长尾/双峰**（而非指数单峰）；

### 6.1 活动正向模型（`src/larval_zf_activity.py`，**复用 M9 `src/adult_activity.py`**）

```
F_i(t) = Σ_k exp(−(t−t_ik)/τ_ca)·1[t−t_ik>0]      # 发放 → 荧光卷积（τ_ca 预注册，沿 M9 L42：1.0 s）
ΔF/F_i(t) = A·(h ∗ spikes_i)(t)                    # 核归一化语义：Σ_i k_i = A·τ_s/bin_s（无 Δ 因子）
F_i^img(t) = 帧化至成像采样（~1–2 Hz，窗口平均，帧边界口径与数据一致）
```

- **可逆性自检（**管线正确性的前置门，M9 L42 实测 ρ=0.9997**）**：由 ΔF/F 积分反演发放率
  （`N = ∫ΔF/F dt /(A·τ_ca)`）→ ① 单脉冲/规则发放自检精确（误差 <1e−9）② 全规模
  **ρ(重建率, 真率) ≥ 0.99**。**不达 → 判为管线错误，不得用模型活动统计做任何结论**（M9 教训：
  先排除管线错误，再归因模型）。
- **双口径报告（强制）**：**窗内重建 / 全尾重建**（M9 L42：窗内反演系统性偏低，τ/T 效应约 −14%）；
  报告必须并列两口径，**不得只报有利口径**。
- **理想上限制声明**：模型 ΔF/F 无噪声/无运动伪影/无神经域污染 → **数值为理想上限**，**不可与文献成像数值
  直接等价比较**；因此对照必须用**同管线代理零分布**（相位随机化，M9 L42 实测代理由 ≈−0.07 → **M10 须重建
  自己的代理**，不得引用 M9 数值）。

### 6.2 P7 四指标（**真数据对照**，判据带定稿于 `data/m10_imaging_reference.csv`）

| 指标 | 判据（可测） | Pass 语义 | 对照口径 |
|---|---|---|---|
| **① 发放率分布** | KS 检验 / 分布带 | **KS p>0.05**（或 D < 预注册带；两口径并列）——**M9 实测 D=0.6728/p=0** 为对照基线 | 同管线反演（模型 vs 成像），**不跨口径比**（M9 L42/§0.7 #11） |
| **② 群体相关性** | 平均成对相关 + 特征值谱（前几阶）+ 有效维度 | 落带（±预注册容差）**且**显著高于同管线代理零分布地板——**M9 实测 0.6220（代理 −0.07）为对照基线** | 同帧率（~1–2 Hz）同窗长；**慢钙核/短窗混淆必须显式讨论** |
| **③ 状态转换时序** | 状态占用比例 + 转换率 + 停留时长分布 | 占转差 < 预注册容差（草案 ≤20 pp）；**转换率落带**（M10 相对 M9 的关键增量——M9 bout=0 时该指标不可算） | 2–3 状态 HMM（或全局分位法），**模型与数据同一算法同一参数** |
| **④ 刺激解码** | 线性分类器交叉验证准确率（刺激条件标签） | **准确率 ≥ 预注册下限**（草案 ≥0.60）**且显著 > 置换零分布上界** | **session 级隔离**（训练/测试不同 session，§1.2.2）；模型侧同协议重排标签 |

- **附加（诊断，不计入 P7 判定但必须落盘）**：**Fano 因子**（若可算；M9 为 nan → M10 需修复口径，
  否则登记测量限制）、静默比例、群体率时间序列的自相关时间尺度、**模型-数据的状态序列对齐（区域级）**。
- **P7 判定（预注册）**：**四指标中 ≥3 项过 + ① 与 ② 必须包含通过项**（活动统计的两大结构性指标）；
  ④ 单独作为"信息内容"指标（可与 ①/② 互补但不替代）。
- **证据级别标注（强制）**：L1 → `measured`（判 PASS）；L2 → `derived`（判 PASS(derived)）；L3 →
  `literature`（判**降级通过**，且 P7 在总结中标记为"未用真数据验证"）。

### 6.3 活动-行为联合面（与 P13 的分工）

- **P7 = 活动统计面**（不涉行为的活动结构：分布/相关/状态/解码）；
- **P13 = 活动-行为耦合面**（活动与行为状态/事件的联合统计，§4.7）；
- 两者**必须同源网络、同协议窗**计算，但**判据独立**（禁止用结合指标双重计数）。

### 6.4 失败归因路径（设计文档 §五 M10 反证路径落地）

活动统计对不上 → **逐项对照成像数据定位**（不是猜测）：
① **调质系统缺失**（H6：先看 P6 的 M-4 级是否生效 + 调质增益是否被打开）；
② **抑制性中间神经元亚型**（GABA_A/B 比例与时间常数是否与数据一致——P6 的 M-3 级）；
③ **感觉运动耦合细节**（体感/侧线/视觉输入的时延与增益——§3.3/§3.5）；
④ **钙正向模型口径**（先过可逆性自检排除管线）；
⑤ **状态切换机制整体失效**（P6 不过 → 活动统计不可能对上，回到 P6）。
**每项 = 一个显式消融实验**（不猜测）；结论入缺失机制清单。

**验收（P7）**：`larval_zf_activity.py` 冒烟（无 NaN、确定性、可逆性自检 ≥0.99）+ 统计对照落盘
（`data/m10_p7_activity.csv` + `reports/neuro/m10_activity_stats.png` + 四指标图）+ 证据级别标注；
不通过 → §6.4 归因路径 → 反证记录（**活动数据把"缺什么"变成可定位问题**——这是 M10 的方法学价值）。

## §8 反证路径（连接组 + 成像齐备仍不涌现 → 逐级排查）

设计文档 §五 M10 反证路径的落地（每个 Pass 失败走此路径 + 三态裁决，**不静默重试**）：

### 8.1 前置门失败（最先处理，避免浪费）

- **G2 失败（数据侧）**：连接组/成像任一不可得 → §1.5/§1.2.3 降级 + 证据级别标注 + 三态裁决；
  **降级不得静默**（M9 的核心流程纪律）。
- **G0 失败（引擎侧）**：对齐 (a)–(e) 任一不达 → 排查浮点/语义（E1–E4 扩展的**关闭态等价**是最先检查项）→
  仍不达 → 换路线/降档 + 记录；**协议不得定稿**。
- **G1 失败（自持/弹性）**：P5 (c)(d) 不达 → 排查顺序：tonic 占比（降）→ 背景率 λ（降）→ 感觉输入增益（升）→
  类级权重；**仍不达 → "输入通路增益无法在不自持的前提下提升"本身 = 强反证**（入缺失机制清单）。
- **P6 失败（状态切换机制）**：**这是 M10 最关键的反证位置**——逐级排查：
  ① **升级到组合级（M-5）**；② **检查连接组子集/权重标定**（是否因 `partial` 或标定过弱致机制无效）；
  ③ **检查机制参数是否落在生理范围**（读回断言 + 作用域守卫，M9 教训 B3）；
  ④ **检查时间尺度**（STP/GABA_B 的时间常数是否与协议 T 匹配——协议窗太短则慢变量来不及表现）；
  **全阶无效 → "任何候选状态切换机制都无法同时满足不自持/有弹性/有双态" = M9 结论的最强加固**
  （写出反证 + 必需机制清单追加 + 三态裁决）。**P6 不过时 P7–P13 判 `blocked_by_p6`（诚实，不静默跑）**。

### 8.2 功能不涌现（P8–P11/P13 任一不达）——逐级排查（每级 = 显式消融/替换实验，不猜测）

① **突触权重**（自由参数——类级缩放 ≤40 全局参数行为/活动反推，**不做逐突触拟合**）；
② **递质/受体映射**（真实 GABA_A/B 与调质受体语义；标注缺失 → 显式测量限制）；
③ **神经调质缺失/无效**（T2 是否真正作用于状态变量，而非仅背景率——M9 R2 教训）；
④ **身体反馈缺失**（感觉运动耦合/水动力学/闭环——§3）；
⑤ **可塑性/STP 规则**（形式/时间常数/门控；习惯化机制检验）；
⑥ **感觉通道编码**（视网膜/侧线/听觉输入的时延与增益——M8 教训：缺失感觉通道编码）；
→ 输出"缺失机制清单"逐条入档（M14 交付物②组成部分）。

### 8.3 活动统计对不上（P7，**最强反证信号**）

**逐项对照成像数据定位**（设计文档 §五 M10："活动数据把'缺什么'变成了可定位的问题，而不是猜测"）：
① **先排管线**（可逆性自检 <0.99 → 管线错误，不得下模型结论）；
② **口径失配**（帧率/窗长/反演口径/零分布——M9 教训 B2：口径失配曾致主agent 撤回结论）；
③ **调质系统**（H6）；④ **抑制亚型比例与时间常数**（H3）；⑤ **感觉运动耦合**；⑥ **状态切换机制整体**（回 P6）。
每项写出**具体可分辨的差异方向**（例如"模型右尾过重 + 静默偏低 → tonic 偏置仍主导"）。

### 8.4 扰动预测 <70%（P12）

前置门（操作有效性/sham/随机对照/P6）→ 扰动协议（注入语义/幅度，M9 RB3 代理池塌缩教训）→ 权重 →
活动耦合 → 状态切换（回 P6）→ 逐项排查；**锚级 vs 池级口径差异必须显式报告**。

### 8.5 三态裁决

✅ 通过（进入 M11）/ ❌ 反证（缺失机制清单累积——**"哪些结构/机制在幼鱼全脑尺度上必不可少"是科学产出**）/
↩️ 打回（仅清单/报告不完整）。**"连接组 + 成像齐备仍不涌现"本身 = 决定性反证结论**，直接写入缺失机制清单。
