## 3b. 主agent 追加裁决 R6（**结构性**）：活动通道改向 + S 门目标带必须自建

**问题**：M11 的 **S 门（首要机制门）** 判据是"慢变量时间尺度与**目标 dwell** 同阶"，而该目标原计划自 MICrONS 同源成像自建。
但 R1/R2 已定案 **MICrONS 侧没有任何可用活动时间序列**（体素 `format_unverified`、逐细胞 `unavailable`、144 field 仅 2 个含 `functional_series`）
⇒ **S 门"无目标可依"**，会连带卡死 P14（活动金标准）。

**裁决**：
1. **活动通道改用 Allen Brain Observatory 2p 钙成像**（`visual-coding-2p`）——**主agent 亲测可达**：
   `https://allen-brain-observatory.s3.amazonaws.com/visual-coding-2p/manifest.json` → **HTTP 200 / 1340 B / manifest JSON**；
   该源**自描述、有文档、带帧率**，与 M10/ZAPBench 的"钙成像群体活动"语义同族；
2. **M11 的 dwell/τ 目标带必须自建**：用**与 B4 完全相同的管线**（0.914 s 箱 → 5 帧平滑 → z → AR(1)；**并同时给未平滑口径**）；
   **禁止**沿用 ZAPBench 的 26.5 s / 37.180 s（跨物种 + 跨帧率 + 跨口径）；
3. 若 2p NWB 不可得 ⇒ 回退 **literature 带**（up/down state 量级 + PMID provenance），并**显式声明目标带为跨制备代理、S 门判据降级为"形状 + 存在性"判据**；
4. **S 门主判据相应改为**：① 占用非退化（两态各 ≥5% 帧）② 转换存在 ③ 低态 dwell **重尾**（p90/中位 ≥2 且 KS 拒绝指数 p<0.05）
   ④ 慢变量**去趋势**后 \|r\| ≥0.30 **且 lead-lag 峰值 lag>0**（机制领先，防"跟随者/共同趋势"伪相关）；
   绝对尺度按**与自建目标带的比值**报告，容差来源预先写清（口径差 3.87× / 跨条件 6.9× / τ 跨条件 3.94×）；
5. **"同源"表述降级（诚实性要求）**：P2 结论与 M12 交接必须写
   **"结构同源仅就结构侧成立（MICrONS EM/seg，measured）；功能侧为跨源代理（Allen 2p / Allen NWB），证据级别 `derived/cross_source`；不得声称 M11 用同源成像数据约束"**。

## 3c. 主agent 追加证据（R7）：**"5 帧平滑是模型侧 τ 存在的必要条件"**

M10-B1 交叉核对时发现（已入档）：λ×1 臂的模型群体序列**未平滑时 φ = −0.41 / −0.14 / −0.31 / −0.34（全为负 ⇒ 无慢过程）**，
**5 帧平滑后 φ=0.56–0.67**；唯一例外为 M-4 λ×4（未平滑 φ=0.904 ⇒ 慢结构对平滑稳健）。
- **对 M10 结论的影响（强化，非削弱）**：模型侧**连不依赖平滑的内在慢自相关都没有**，`τ≈1.58–2.31 s` 应读作
  **"由 4.6 s 平滑窗诱导的上界"**，即真实内在慢尺度更低；⇒ **P6 的"结构缺失"结论更强**；
- **但两侧必须对称**：成像侧此前只报了**平滑后** φ=0.9757。⇒ 已要求 B4 补 **stage H**：同一 `ser_ref` 序列的
  **未平滑/平滑双口径** φ、τ、ll/帧、Ljung-Box，并给"成像侧是否存在不依赖平滑的慢结构"的结论。
  **若成像侧未平滑 φ≈0 ⇒ 两侧同病，M10 主判据的表述必须立即改写**（已预先告知 B4：如实报告，不得为维持既有结论挑口径）。

## 4. 对 P2 判定的影响（诚实记录）

**M11 的核心方法学卖点是"结构-功能同源"**，但本轮实测后必须**收窄**：
- **结构侧**：MICrONS EM/seg 真实可达且自描述 ✅（主agent 复算 1.2861 mm³ 一致）；
- **功能侧**：体素序列 `format_unverified`（R2）、逐细胞轨迹 `unavailable`（R1）、**144 个 field 中仅 2 个含 `functional_series`**
  ⇒ **"同源"实际退化为"结构同源 + 两个 field 的元数据"**；
- **活动通道**因此改由 **Allen NWB（R3）**承担 ⇒ **结构与功能不再同源**（跨制备、跨品系、跨实验室），
  这一**降级必须在 P2 结论与 M12 交接中显式写出**（不能只写在限制登记里）。

## 6. 纪律条目（本里程碑新增/沿用）

1. **RF-M11-1**：§0.7 #2 的**依据已更正**——禁移植 M9/M10 绝对数值的理由不是"+28% 不可复现"（已否证），而是 ① **可复现 ≠ 正确**（M9 绝对值是缺陷档，修正后 −24.7%）、② 跨物种/跨制备/跨口径；
2. **同源 ≠ 可用**：数据可达性与数据可用性必须**分开**判定（R1/R2 即此）；
3. **跨节点 sha256 必须标注基准**（`file_bytes` / `payload` / `semantic`）——同一批 pop trace 的 file-bytes 与 payload 哈希不同，曾被误疑为"重复作业覆盖"；
4. **双估计器必须一致**（R5① 即此纪律在**描述统计量**上的又一次适用）；
5. **机制实验阳性对照协议**（作用域断言 + 最小对照）——M11 的四亚型槽实施中强制适用（继承 M10 的 A10 教训）。
