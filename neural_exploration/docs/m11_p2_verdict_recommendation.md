## 三、为何建议上调（相对上一轮 `partial_pass`）

上一轮判 `partial_pass` 的唯一实质缺口是「四类参考量重建未交付」，其前置是两条待核口径
（`int16/uint16`、4 px/µm vs 2.5 µm/px 的 10× 差）。本轮两项**均已解决且有实测证据**：
- **格式/量纲**：解析门（R2 反转）＋ 哨兵定稿（无掩膜 + 登记）；
- **空间口径**：实像素同格性（尺度扫描峰值唯一 **f=2.50**、位移 **(0,0)**、r = 地板 **9.0×**）＋ 层级解释
  （**4 px/µm = raw 子场；2.5 µm/px = 处理后**，比值恰 **10.0**；R-27/R-28）；
- 且 **C3 已从「待重建」变为「已自建并经两独立实现交叉核对」**。
⇒「同口径可算」已从「设计可达」落为「**实测可行**」；剩余缺口作为**限制登记**而非判据缺项。
