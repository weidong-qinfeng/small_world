## §0 总则

### 0.1 里程碑目标与交付物

**一句话目标：结构完备假设的决定性检验——139,255 神经元完整连接组（54.5M 化学突触 + ~8.5k 缝隙）
+ GPU 引擎下，行为/活动/扰动三通道能否被确定性动力学复现。**

设计文档 §五 M9：FlyWire 2024 发布史上第一张完整成年动物大脑连接组（Dorkenwald et al., Nature
2024；Science 2024；hemibrain Scheffer 2020 ~25k 核对子集）。**内容**：① 引擎升级（GPU 仿真，
point-neuron 为主，按需回归精细模型）；② 虚拟果蝇身体（六足步态、翅、触角/复眼感觉输入；
VR 实验范式复刻——与真实实验同一协议）；③ 涌现功能（MB 联想泛化、CX 航向地图、觉醒/睡眠样状态、
趋利避害决策）；④ 扰动预测（全脑扰动图谱模拟 vs 实验库）。
**Pass**：嗅觉条件化学习曲线与泛化梯度一致；航向地图与导航行为一致；求偶/逃跑行为序列一致
（扩展级，见 §4.5）；**扰动预测命中率 ≥70%**；全脑活动统计（发放率分布、群体相关性）与成像一致。
**反证路径**：连接组完备仍不涌现 → 突触权重/神经调质/身体反馈缺失 → 逐级排查（§8）——这是
"连接组完备性假设"的关键检验，反证结论直接写入缺失机制清单；若 MB/CX 功能不涌现 → 检查可塑性
规则与调质（DA 在 MB 中的奖赏编码已知）。

**交付**：成年果蝇全脑仿真（行为 + 活动 + 扰动三通道验证报告）+ GPU 引擎对齐验证报告 + 扰动预测
命中率报告 + 活动金标准统计对照 + 必需机制清单追加（反证/测量限制累积，M14 交付物②组成部分）。

### 0.3 铁律落地（M9 版，叠加阶段一/阶段二全部铁律）

1. **自底向上逐层验证（工作流 §三，不跳层）**：G2 数据门（FlyWire）→ **G0 引擎门（GPU 与 M8 CPU
   引擎同一模型逐神经元对齐）** → 身体（P3）→ 全规模装配与静息（P4）→ 涌现功能（P5–P8）→ 扰动
   （P9）→ 活动（P10）。**引擎正确性未过 G0，全规模协议不得定稿**（避免在未验证引擎上烧预算）。
2. **只为可验证而精细（铁律 A）**：point-neuron 为主；精细模型（HH/多隔室）仅按需回归（抽象登记
   册登记：GPU 引擎、点神经元、压缩时间尺度、VR 球体——替代了什么/误差/回归条件，§0.3.5）。
3. **失败即反证（工作流 §四）**：任何 Pass 失败 → 反证路径（§8）+ 缺失机制清单逐条入档 + 三态裁决
   （✅ / ❌ 反证+缺失机制清单 / ↩️ 打回），**绝不静默重试**。
4. **确定性 + 局部物理随机**：p=1/n=1；试次方差来自伪随机起点（固定 seed）；随机仅限突触量子释放/
   通道噪声（设计文档 §3.2）；`PYTHONHASHSEED=0` 固化（R8）；同参数重跑逐位或统计级一致（GPU
   浮点重排预注册，§0.7 #3）。
5. **判据带定稿纪律（M8 教训）**：行为/成像/扰动对照带**协议运行前定稿于 CSV**（
   `data/m9_behavior_reference.csv` / `data/m9_imaging_reference.csv` / `data/m9_perturbation_plan.csv`），
   **不事后调带**。
6. **数据隔离预注册（设计文档 §6.2，防过拟合）**：拟合集 A（自发分布/静息发放率——权重校准）vs
   held-out B（学习/泛化/决策）+ C（活动成像）+ D（扰动库）——**三通道必须同时成立**（§0.8）。
7. **计算预算先例（M4–M8 教训）**：**先探针测墙钟，再裁决，再烧预算**；每步骤标注墙钟/预算上限
   （§0.9/§10）；超出 → 最短协议 + 测量限制 + 三态裁决（M4 L21 模式）。
8. **冻结基线保护（组合不修改纪律，M5–M8 惯例）**：M0–M8 全部冻结文件（`src/` 下 M0–M8 交付、
   `tests/`、`tools/validate_*`、`data/` 定稿 CSV 含 `m8_larva_params.csv`/`m8_behavior_reference.csv`）
   **零修改**；M9 **只新建**（§0.10 L1 清单）；确需 API 兼容微调 → 逐条登记 m9_env_notes。

### 0.7 判据可测性预注册（结构性限制——判据设计时就要考虑模型结构性限制，M3–M8 全部教训）

1. **时间尺度压缩（规模化第一限制）**：全规模单试次预算 ≤1 GPU-h（预注册，§0.9）→ 昼夜节律
   24h/长时程协议**不可全跑** → 预注册压缩语义（节律周期压缩到协议窗内，状态切换统计级判据）；
   逐时刻相位/逐神经元对应不声称（测量限制，不伪造）。
2. **全规模协议预算上限**：单试次 ≤1 GPU-h、单协议 ≤24 GPU-h（草案，探针实测修正）；行为协议
   T 取「参考模型通过率 ≥80% 最短 T」× 墙钟 ≤ 预算（M5 §3.5 公式沿用）；超出 → 最短协议 + 测量
   限制 + 三态裁决（M4 L21 模式）；**先探针测墙钟再裁决再烧**（M4–M8 教训）。
3. **GPU 浮点重排（G0 对齐判据预注册）**：GPU 与 CPU 浮点运算顺序不同 → **逐位一致不承诺**；
   主判据为统计级：spike 时间差 <0.1ms 比例 ≥99% + 状态比例差 <1pp + 发放率分布 KS p>0.05 +
   行为指标落带一致；同引擎（GPU）同参数重跑统计级一致（固定 kernel + seed）。
4. **活动金标准成像分辨率限制（设计文档 §九）**：钙成像 ~1–2Hz、群体信号、分辨率有限 →
   **只承诺统计级**（发放率分布 KS、群体相关性、状态占用/转换）；逐神经元对应不声称。
5. **扰动预测实验锚可用性（P9 判据可测性前提）**：**有锚下限 ≥20/50 预注册**（M8 R5 教训）；

## §2 引擎升级（GPU，G0 门前置；P2 验证对象；5–10 天，含探针）

### 2.1 候选路线对比（预注册，选型判据定稿于 `data/m9_engine_params.csv`）

| 路线 | 生态/语言 | 本机现实性（单机 macOS） | 与 M8 CPU 引擎对齐成本 | 备注 |
|---|---|---|---|---|
| **Brian2CUDA** | Brian2 生态（Python），NVIDIA CUDA only | ❌ 本机 macOS 无 CUDA → 需云/外置 NVIDIA GPU | **最低**——同一 Brian2 网络定义直接换后端，larva_circuit 语义复用 | 设计文档首选提及；对齐最直接 |
| **NEST GPU** | NEST 生态（C++/Python），CPU+GPU | ⚠️ macOS 编译支持有限，GPU 路径需 Linux | 中——网络定义迁移到 NEST 模型，需等价性验证 | 大规模点神经元成熟 |
| **PyTorch 自研点神经元内核** | Python/PyTorch，CUDA + **MPS（Apple Silicon）** | ✅ MPS 本机可行（若本机 Apple Silicon）；CUDA 云可行 | 高——网络定义重写，需参考实现做等价性 | 完全可控；确定性可工程化（固定 kernel/seed） |

### 2.2 选型判据（预注册：**正确性对齐 > 速度**）与推荐默认

1. **对齐可实现性（第一判据）**：能否在**同一网络定义语义**下与 M8 CPU 基线逐神经元比对
   （Brian2CUDA 天然满足；PyTorch 自研需实现等价参考 + 对齐探针协议 §2.3）；
2. **本机硬件现实性**：macOS 无 NVIDIA → CUDA 路线需云裁决；MPS 路线本机可行；
3. **开发风险/成本**：自研内核 bug 面 vs 生态成熟度（时间预算 5–10 天含探针）；
4. **确定性可工程化**：固定 kernel + seed + 统计级重跑一致（§0.7 #3/#10）；
5. **规模/速度**：54.5M 突触点神经元单 GPU 实时~数倍实时（设计文档 §7.1）；内存预注册：
   连接表 54.5M×2×4B ≈ 436MB + 权重/延迟 float32 ≈ 436MB + 状态 ~MB → **<1.5GB 单 GPU 显存可行**。

**推荐默认（预注册建议，最终由主 agent 裁决）**：本机 Apple Silicon → **PyTorch MPS 自研点神经元
内核**为本地主路线（无需云、本机可跑全规模探针）；裁决云 GPU → **Brian2CUDA**（对齐成本最低）；
**NEST GPU** 为备选（仅当前两者裁决不达时评估）。

#### 2.2.3 NG 门（无 GPU 三态裁决预案，§0.5）

| 状态 | 路线 | 处置 |
|---|---|---|
| ① 本机 Apple Silicon + MPS 自研内核 | 全规模本机可跑（主路线） | 进入 G0 对齐 |
| ② 云 GPU（Brian2CUDA） | 成本/配额/网络裁决 | 主 agent 裁决；云环境运行纪律（确定性、日志、产物回传）预注册 |
| ③ 降规模（hemibrain 25k 子集或 FlyWire 核心子集：MB+CX+感觉运动） | 全规模不可得时 | **记录测量限制（全规模反证路径降级）+ 三态裁决**（✅ 降规模验收 / ❌ 反证 / ↩️ 打回）；降规模下 P5–P8 判据带按子集重定稿（预注册：子集连接组 ≠ 全连接组，泛化/航向判据以子集结构可达性为准） |

### 2.3 GPU 正确性验证（G0 门——铁律：同一模型逐神经元对齐，通过后才放行 M9 全规模）

- **参考模型**：M8 冻结 **300 two_comp 定稿配置**（CPU Brian2 基线；同一连接组 CSV、同一权重参数
  `m8_larva_params.csv`、同一 dt=0.05ms、同一协议注入/seed）——**"同一模型" = 同一网络定义语义 +
  同一输入/seed，仅执行后端不同**（Brian2CUDA 天然满足；PyTorch 自研需等价参考实现）。
- **对齐判据（预注册，统计级主判据 + 参考判据）**：
  - (a) **逐神经元 spike 时间对齐**：≥99% spike 时间差 < 0.1ms（主判据；GPU 浮点重排为测量限制，
    逐位一致不承诺，§0.7 #3）；
  - (b) **状态比例**：静默比例差 < 1pp；发放率分布 KS p>0.05；
  - (c) **行为指标**：自发分布（run/turn/pause）落带一致；CI 符号与幅度一致（Δ < 判据带）；LI 获得
    方向一致；
  - (d) **确定性**：GPU 同参数重跑统计级一致（固定 kernel/seed）。
- **探针墙钟实测（先算墙钟再烧预算）**：300 two_comp CPU 基线（118s/试次）vs 候选 GPU 引擎加速比
  落盘（`data/m9_engine_probe.csv`）→ 全规模单试次预算裁决（≤1 GPU-h）；**G0 不通过 → 引擎不得
  放行全规模，协议不得定稿**（避免在未验证引擎/失控预算上烧计算）。

### 2.4 点神经元为主 + 按需回归精细模型（铁律 A）

- point-neuron（LIF/CUBA 类）为主——M9 全规模唯一可行保真度（M8 缩放扫描依据：3016 point 行为层
  退化反证记录 → 全规模行为判据以点神经元 + 关键回路精细回归组合验证）；
- 精细模型（HH/多隔室）按需回归：仅当某行为/功能判据在点神经元下不达且机制指向树突/簇发放计算时
  （抽象登记册回归条件，§0.3.5）；回归范围限相关神经元子集（MB KC、CX EPG——科学看点回路优先）。

### 2.5 引擎冻结为基线（迁移原则：引擎是手段不是目的）

- 对齐通过后，选定 GPU 引擎**冻结为 M9 基线**（版本/参数/kernel 定稿于 `data/m9_engine_params.csv`）；
- 引擎改动（kernel/优化/参数）必须重新过对齐探针（回归门：对齐判据 (a)–(d) 全过）；
- 与 M8 CPU 引擎的关系：CPU Brian2 为**对齐参考 + 判据脚手架**，不承担 M9 全规模（§0.9）。

**验收（P2）**：`adult_engine.py` + `data/m9_engine_params.csv` + `m9_engine_probe.csv` +
`reports/neuro/m9_engine_alignment.png`（CPU-GPU 逐神经元对齐图 + 行为指标对照）；G0/G0-NG 决策记录
完整；对齐判据全过 = G0 门通过。

  bout 结构；**时间压缩语义预注册**（§0.7 #1：节律周期压缩到协议窗内，统计级判据，逐时刻相位不
  声称）。
- **判据（P7）**：
  (a) **状态切换**：活动/静息 bout 时长分布与果蝇睡眠文献一致（统计级：分布形状/bout 时长带落带，
  定稿于 CSV）；
  (b) **昼夜调制**：昼活动 vs 夜静息比例差显著（配对 t p<0.05）；
  (c) **消融（机制归属）**：节律输入=0 → 昼夜差异消失（H4）；
  (d) 确定性重跑统计级一致。
- **承接**：M8 G1 双状态（静默 0.8477/0.8167 + bout）经验——M9 全规模双状态 + 节律调制为升级版。

### 4.4 P8：趋利避害决策（H5——冲突刺激下的选择概率）

- **范式**：冲突刺激（奖赏气味 + 惩罚刺激同时呈现）→ 二选一/接近-回避选择 → 选择概率。
- **判据（P8）**：
  (a) **选择概率与行为学落带**：冲突条件下选择概率落带（定稿于 CSV，果蝇趋利避害行为学文献校准）；
  (b) **机制归属**：MBON 价效输出差分 → 选择（价效整合机制验证，Aso 2014 方向）；
  (c) **消融**：MBON 通路消融 → 选择随机化（H5）；
  (d) 确定性重跑统计级一致。
- **承接**：M8 P6 反证（伤害性通路无联想可塑性 R4）——伤害性通道三因子门控是否纳入本判据（扩展
  级）由主 agent 裁决；不纳入则 M8 反证 6/7 项继续累积（§0.2 R4）。

### 4.5 扩展级行为（P-EXT1/P-EXT2，预算门控——设计文档 Pass 含求偶/逃跑序列）

- **P-EXT1 巨纤维逃跑序列**：光刺激 → 逃跑序列（潜伏期 + 跳跃/翅展时序）与文献统计一致（扩展级；
  机制前置 = §3.3 逃跑反射 sanity）；预算不允许 → informational + 反证记录。

  度高）；预注册为 budget-gated：预算不允许 → informational + 记录，不参与总路径判定（§0.4）。

**验收（P5–P8）**：四个验证脚本 + 输出落盘（图 + CSV）；每个功能：行为判据落带 + 消融机制归属 +

### 5.2 模拟与命中率（`src/adult_perturb.py` + `tools/validate_p9_perturbation.py`）

## §6 活动金标准（P10 验证对象；4–6 天）

### 6.1 活动正向模型与统计对照（`src/adult_activity.py`）

```
F_i(t) = Σ_k exp(−(t−t_ik)/τ_GCaMP)·1[t−t_ik>0]    # 发放 → 荧光卷积（τ_GCaMP 预注册 0.5–1.5s）
F_i^img(t) = F_i(t) 降采样至成像采样（1–2Hz，窗口平均）   # 与成像数据同采样对齐
```

- **统计对照（P10，只承诺统计级——设计文档 §九 + M8 教训）**：
  (a) 全脑发放率分布 vs 中枢脑钙成像统计（KS p>0.05 或 <20% 偏差）；
  (b) **群体相关性**：相关矩阵统计（平均相关系数/特征值谱）vs 成像（预注册区间，定稿于
  `data/m9_imaging_reference.csv`）；
  (c) 行为切换窗状态序列一致（预注册活动态定义：全局活动分位 + 降维主分量）；
  (d) 逐神经元对应**不声称**（测量限制，§0.7 #4）。

### 6.2 成像数据可得性与回退（M8 R7 教训）

- 成像源：中枢脑钙成像（GCaMP）文献数据/统计带；网络受限不可得 → **文献统计回退 + 测量限制记录**
  （M8 P8 先例：文献带回退，只承诺统计级）；不静默、不伪造。

**验收（P10）**：活动正向模型冒烟（无 NaN、确定性）+ 统计对照落盘（`data/m9_p10_activity.csv` +
`reports/neuro/m9_activity_stats.png`）；不通过 → 活动耦合排查（调质/抑制亚型/感觉运动耦合——活动
数据把"缺什么"变成可定位问题，设计文档 §9）→ 反证记录。

## §8 反证路径（结构完备假设的决定性检验——连接组完备仍不涌现的逐级排查）

设计文档 §五 M9 反证路径的落地（每个 Pass 失败走此路径 + 三态裁决，不静默重试）：

1. **行为不涌现（自发分布/泛化/航向/决策任一不达）** → 逐级排查并记录（每级排查 = 显式消融/
   替换实验，不猜测）：
   ① **突触权重**（54.5M 权重为自由参数——类级缩放 ≤40 全局参数行为学反推，M5/M8 哲学；不做
   逐突触拟合，§0.7 #7）；
   ② **递质/受体映射**（真实 GABA 抑制平衡 H6；DA 受体映射 R6——FlyWire 标注缺失 → 限制记录）；
   ③ **神经调质缺失**（DA/5HT/章鱼胺全局状态变量，T2——M9 首次面对调质系统显式建模）；
   ④ **身体反馈缺失**（感觉运动耦合/肌肉映射/VR 闭环——M8 R3 curl 教训）；
   ⑤ **可塑性规则**（STDP 形式/时间常数/三因子门控——DA 在 MB 的奖赏编码已知，设计文档 §五 M9）；
   → 输出"缺失机制清单"逐条入档（M14 交付物②组成部分）。
2. **MB/CX 功能不涌现（专项）**：MB 不泛化 → 检查可塑性规则与调质（H2：DA 奖赏编码）；
   CX 无航向地图 → 检查 EPG 环结构/缝隙连接（H3）。
3. **活动统计对不上（P10）**：活动数据把"缺什么"变成可定位问题（调质系统/抑制性中间神经元亚型/
   感觉运动耦合细节，设计文档 §9）；逐项对照成像定位。
4. **扰动预测 <70%（P9）**：扰动协议（注入语义/幅度）→ 权重 → 活动耦合 → 逐项排查。
5. **GPU 不可得/引擎对齐失败**：NG 门三态裁决（§0.5/§2.2.3）——降规模（hemibrain 25k 子集）时
   记录测量限制（全规模反证路径降级），不静默。

**三态裁决**：✅ 通过（进入 M10）/ ❌ 反证（缺失机制清单累积，是科学产出——"哪些结构/机制在
139,255 尺度上必不可少"）/ ↩️ 打回（仅清单/报告不完整）。**连接组完备仍不涌现本身 = 决定性反证
结论**（结构完备假设不成立 → 权重/调质/身体反馈必需），直接写入缺失机制清单。

| 步骤 | 预计墙钟 | CPU 预算上限 | GPU 预算上限 | 裁决/回退 |
|---|---|---|---|---|
| 前置确认（L1–L7） | 1–3 天 | ≤4 CPU-h | 0 | 无 |

| 交接处置（P12） | 1–2 天 | ≤2 CPU-h | 0 | 反证/限制逐条入档 |

> 规模换算——GPU 小时成本远高于 CPU，超支触发三态裁决，不静默）。
