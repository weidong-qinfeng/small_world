### 判据可测性预注册（结构性限制，吸取 M3/M4 全部教训——判据设计时就要考虑模型结构性限制）

1. **CI 统计陷阱（M4 L7/L23）**：单试次 CI 高方差 → 判据同时要求显著性（t + d≥0.5）与效应量
   （落带）；无梯度对照为**主判据**（p>0.05），|CĪ|<0.1 点值 informational（N=20 有限样本
   点判据不可靠，M4 L7 实测）。**统计功效由降阶模型正面解决**：行为验证用点神经元/大 dt，
   协议 T 按「参考模型自身 N=20 通过率 ≥80%」的 T 定稿（M4 L23 参考模型 N=20/T=10s 仅 43% 的
   教训——M5 协议必须把 T 推到稳健显著区，且**预算上可承受**）。
2. **自发行为分类的操作化**：状态（前进/后退/转弯/暂停）由 (v, ω, C_fwd, C_back) 阈值定义，
   **阈值定稿于 CSV，不做事后调阈值**（M3 P5 ×1.2 教训）。后退需要身体方程支持负速度
   （M4 身体 v ≥ 0——M5 规格扩展，§5.2 #3）。
3. **咽部节律窗口的操作化**：设计文档带 [0.1,2] Hz 与 Avery & Horvitz 1989 食物下 ~2–5 Hz 的
   差异 → **预注册操作协议**：无食物节律（设计文档带 [0.1,2]）或有食物节律（[2,5] 或记录双窗），
   定稿于 CSV 并报告注明；不事后选窗口。
4. **电生理发放率对照的操作化**：电生理数据（来源/品系/温度一致性）整理为
   `data/m5_behavior_reference.csv` 唯一定稿源；操作化阈值（静默比例 ≥70%±10%、
   组中位数 <1 Hz、最大发放率 <60 Hz 生理上限）**预注册**——不声称复现逐神经元电生理，
   只对照分布统计（L4 验证标准语义：分布一致 <20% 或统计一致）。
5. **连接组计数**：权威数据（White 1986 / Cook 2019）为唯一计数源；**预注册目标区间 ±10%**；
   **不得为过 Pass 而改权威数据**（解析差异如实记录，超容差 → 数据管线 bug 排查，不静默）。
6. **权重反推的不可辨识性（连接组只有连接有无、无强度）**：~7000 个权重是**自由参数**，逐突触
   拟合必然过拟合 → **类级缩放 + M3/M4 子图先验 + 行为学反推少量全局参数**（§6），过拟合即
   反证记录（缺失机制），不静默。
7. **降阶正确性（逐层验证铁律）**：降阶网络必须先复现 M3/M4 已验证子回路的对应行为
   （趋化 ΔCI ≤ 0.15、逃避方向/潜伏期一致），才允许作为行为验证主体（§3.4）——降阶不是
   "偷工减料"，是"保真度与验证绑定"（铁律 2）在计算可行性下的正确落地。
8. **计算预算**：探针先行（每保真度档 T=1s 单试次实测墙钟）；预算上限预注册（§3.5）；
   超出 → 最短协议 + 记录测量限制 + 三态裁决（M4 L21/L25 教训——不静默推进、不烧 CPU）。
9. **反证路径预演**：M3/M4 已单独验证 → M5 行为不涌现时问题必在网络耦合/神经调质/缺失环节 →
   逐回路排查流程（P1 数据核对 → §3.4 降阶一致性 → 权重校准 → 调质模型）预注册，产出
   "哪些生物机制必不可少"的清单（设计文档 §九 理念）。

## 2. 步骤 1：连接组规格与数据管线（2–3 天，纯文档 + 数据）

### 2.1 数据源与获取

- **权威源**：White et al. 1986（原始连接组）；Cook et al. 2019（hermaphrodite 全连接组，含递质标注）；
  OpenWorm 项目结构化数据（openworm.org，MIT 协议，JSON/CSV）为推荐获取渠道；Varshney et al. 2011
  为 White 1986 的数字化版本（备选）。

### 2.2 解析与校验（P1 的验证对象）

## 3. 步骤 2：降阶模型设计与铁律 C 缩放定律扫描（3–4 天，**第一关键决策步**）

### 3.1 问题陈述（M4 教训的正面解决）

M4 L23 结论：20 神经元多隔室 HH 闭环（rk4 dt=0.01ms）T≥15s×N≥20 ≈ 数千 CPU-小时，单机不可行；
302 神经元全虫若同款必然更差。**M5 行为层（P4/P5/P6）必须降阶**；P2/P3 电路级验证可用 HH 局部子图。

### 3.2 降阶方案评估（三选项 + 决策标准）

| 方案 | 神经元模型 | dt | 优点 | 缺点 | 适用 |
|---|---|---|---|---|---|
| ① 点神经元（单隔室 HH / Izhikevich / LIF） | 单变量膜电位（HH 简化为单隔室或 Izhikevich） | 0.05–0.1 ms（可探针 0.25） | 302 全虫可行；保留发放动力学与突触事件语义（M2 组件兼容） | 无树突计算/空间传导 | **行为层主选**（P4/P5/P6） |
| ② 双隔室（soma+轴突/近端树突） | 2 变量 | 0.05 ms | 保留最小空间效应 | 302 全虫仍贵（~2× 方案①） | 缩放扫描中间档；关键子图可选 |
| ③ 多隔室 HH（M1 冻结组件） | 18 隔室 | 0.01 ms | 已验证最高保真 | 302 全虫不可行（M4 教训） | **仅限局部子图**（P2 静息态子图、P3 咽部、M3/M4 一致性） |

- **行为层率模型（第三降阶轴，可选）**：若点神经元闭环仍超预算，行为层退到**率模型**
  （发放率 ODE 网络 + 运动学，numpy 侧；行为参考模型同哲学）——作为方案 ① 的兜底档
  （缩放扫描纳入 fidelity 轴一档，防 M4 式预算失控的最终保险）。
- **dt 提升**：点神经元档探针 dt ∈ {0.05, 0.1, 0.25} ms（Brian2 对 dt 变更重编译——M4 L16
  dt=0.02 不可行的教训：**固定 dt 后不再变**，扫描按档位一次定稿；冷编译预算记入 §8 风险表）。

### 3.3 缩放扫描设计（铁律 C 第一次实战；G0 的核心产物）

**扫描矩阵**（每个格点 1–3 试次短协议 T≤5s，确定性；总格点 ≤ 30 控制预算）：

- **规模轴**：{20（M4 子图，基线）, 50, 100, 302}（神经元数，从连接组按拓扑序取子集：
  20=趋化子图、50/100=命令/运动上下文扩展、302=全连接组）；
- **保真度轴**：{点神经元(单隔室 HH), 双隔室, 多隔室 HH(仅 ≤50 规模档), 率模型(302 档可选)}；
- **dt 轴**（并入保真度档，不做独立全网格）：每保真度档固定一个 dt（点=0.1ms、双隔室=0.05ms、
  HH=0.01ms）——降维，避免组合爆炸；
- **行为指标轴**：CI（趋化，食物梯度短协议）、逃避方向/潜伏期（机械刺激短协议）、
  静息发放率分布（无刺激）、自发状态比例（无刺激短协议）；
- **性能指标轴**：单试次墙钟（每格点实测记录，T=1s 探针 + 缩放因子）。

**产出**（M5 报告必含，P7 判据）：
- `data/m5_scaling.csv`（每格点：规模/保真度/dt/各行为指标/墙钟）；
- `reports/neuro/m5_scaling_curves.png`（行为指标 vs 规模曲线，按保真度分色；墙钟 vs 规模
  双轴）——三组曲线：规模曲线（行为复现度的跳变点 = 关键回路证据）、保真度曲线（点 vs 双隔室
  vs HH 的指标差）、性能曲线（墙钟）。

**决策规则（预注册）**：
- 行为层配置 = **使各行为指标与高保真档收敛（相对差 < 阈值，如 ΔCI ≤ 0.15、逃避方向一致、
  静默比例差 < 10 个百分点）的最小规模×最低保真度组合**（铁律 2：不为精细而精细；
  铁律 C：用曲线决定保真什么、抽象什么）；
- 若 302 档点神经元仍超预算（§3.5 上限）→ 方案 ① 内再降 dt 或退率模型档，并记录
  **抽象登记**（替代了什么、误差量级、回归条件——阶段二铁律 A 提前实践）；
- 若行为指标随规模不收敛（20→302 行为反而消失）→ **反证记录**（网络耦合/缺失环节）+
  三态裁决（不静默——这是 M5 反证路径的第一现场）。

### 3.4 降阶正确性验证（逐层验证铁律）

- **趋化一致性**：20 规模档（= M4 子图在降阶组件下的重实现）CI vs M4 已验证结果
  （参考模型同协议 CI、M4 决定性点 CI=0.099@10s 为记录点）：ΔCI ≤ 0.15 或方向一致
  （记录测量限制，不静默）；
- **逃避一致性**：M3 反射弧子图在降阶网络中的方向/潜伏期 vs M3 验证结果（神经潜伏期
  [5,20]ms、方向 D_peak>0.3）：一致；
- 通过后，降阶组件（点神经元/大 dt）作为 P4/P5/P6 的**已验证主体**（G0 门）；
  P2/P3 保留 HH 子图。

### 3.5 计算预算协议（预注册，M4 L21/L25 教训）

- **探针先行**：每个保真度档先跑 T=1s 单试次（record=[]），实测墙钟 → 填 §3.3 性能轴；
- **预算上限（预注册）**：行为验证总预算 ≤ 200 CPU-小时（单机 10 核 ~2–3 个工作日）；
  单试次上限：T=10s 点神经元档 ≤ 10 min 墙钟（探针实测为准，M4 经验预估 302 点神经元
  ≈ 20 神经元 HH 的 1/50–1/200，需实测校准）；
- **协议定稿规则**：T_total 取「参考模型 N=20 通过率 ≥80% 的最短 T」× 降阶实测单试次时间
  的乘积 ≤ 预算上限 → 定稿；否则 → **最短协议 + 记录测量限制 + 三态裁决**（M4 L21 模式）；
- **长任务纪律**：任何 > 1h 的后台任务必须有完成标记 + 超时看门狗（M4 L25 僵尸进程教训）；
  多进程并发 ≤ 2 worker（锁竞争，M4 L21）；验证执行前检查并发清空（M4 L24b）。

### 3.6 决策点与三态裁决

- G0 通过 → 行为验证协议（P4/P5/P6）按定稿配置执行；
- G0 部分通过（如 302 点神经元可行但自发分布不涌现）→ P6 单独反证记录（命令子图/调质缺失），

  （≥2 种行为的组合调整）/ 反证笔记（缺失机制清单）——按 WORKFLOW 流程，不静默推进。

### 5.2 实现要点（延续 M1–M4 经验 + M5 新机制）

3. **身体方程升级（规格公式，P6 前提）**：
   ```
   v(t) = v_fwd0·clip(C_fwd,0,1) − v_rev0·clip(C_back,0,1)     # 前进 − 后退（M4 只有 v≥0）
   ω(t) = ω_max·(C_left − C_right) + 转向事件项（机制 A 沿用）  # 头摆 → 转向
   正弦爬行：body_y(x, t) = A·sin(2π(x/λ − t/T_gait))（姿态行波；运动学仍用点身体+朝向，
            行波用于头部摆幅 → 转向耦合与可视化，informational→验证级由 G0 决定）
   ```
   `virtual_body.py` 提供 `classify_state(v, ω, C_fwd, C_back)`（前进/后退/转弯/暂停，阈值 CSV 定稿）。
4. **机械刺激（P5，M3 方案 A + 转导延迟）**：触电流 I_touch = I0·s_i·1[t0+τ_trans, t0+τ_trans+dur]
   （µA/cm²，注入 PLM/ALM 树突端——点档注入 soma 等效位点）；τ_trans 定稿于 CSV
   （生物行为潜伏期 30–50ms − 神经潜伏期 5–20ms ≈ 转导+肌肉 10–30ms，M5 补齐的对照前提）；
   刺激开始 ≥ 40ms（HH 静息漂移纪律——点档同适用）。
5. **咽部节律（P3）**：咽部子图（HH 或点档，G0 决定）无刺激/有食物驱动 → MC 等发放序列 →
   功率谱主峰/自相关 → 主频 vs [0.1,2]Hz（操作协议 §0 预注册 #3）。
6. **闭环 epoch（复用 M4 机制）**：`WormLoop` 照 `ChemotaxisLoop`——固定形状 TimedArray +
   显式命名 + pad 零（M2 L6/M4 L12 缓存命中）；store/restore + 重播种；epoch ΔT=Δt_b
   （M4 双时钟纪律）；302 神经元的 stim 数组内存控制（M4 L12 越界钳位 → (1,n) 零数组模式）。
7. **构造参数默认 None**（M3 L13）：`WormCircuit(csv_path=None, dt_ms=None, method=None, ...)`。
8. **编译缓存预算**：302 神经元 × 突触的内核数远大于 M4 的 193 → **冷编译预算预注册**
   （§8 风险表；必要时分模块编译/预热 1 epoch；dt/形状定稿后不再变——M4 L16 教训）。

### 5.3 冒烟测试 `tests/neuro/test_worm_smoke.py`（≥8 断言）

- P1 前置：`load_connectome` 302 神经元/四类计数/化学/缝隙计数断言 + 自连接/孤立检查；

## 6. 步骤 5：权重定稿与行为带校准（3–4 天；M5 特有，判据可达性的前提）

- **权重策略（连接组只有连接有无、无强度 → 权重是自由参数）**：
  1. **先验**：M4 子图权重（`data/m4_chemotaxis_params.csv`：AMPA 5.0nS/0.5ms、GABA 15.0nS/0.5ms、

  2. **类级缩放**：其余连接按 (pre 类, post 类) 分桶（sensory→inter、inter→inter、inter→motor、
     motor→motor、motor→muscle、pharyngeal 内部…），每桶一个缩放因子 s_k（~10–20 个全局参数），
     w_ij = w0_class · s_k ——**不做逐突触拟合**（§0 预注册 #6，防过拟合）；
  3. **行为学反推**：以行为带为目标调 s_k（趋化 CI、逃避潜伏期、自发分布、静息发放率四个目标
     联合），少量点（≤10 组）× 降阶模型 → 定稿 `data/m5_worm_params.csv` 权重行。
- **校准协议（两阶段，M4 L18 模式）**：阶段 1 numpy 行为参考快扫（定候选带/参数锚）；
  阶段 2 Brian2 降阶模型少点确认（≤10 组合 × N=10 短协议）；选最小充分组合 →
  最终点全协议复核（N=20）→ 写 CSV 定稿 + `data/m5_calibration.csv` +
  `reports/neuro/m5_calibration.png`。
- **校准失败处置（不静默）**：无解 → 记录缺失机制（如静息态失稳/自发分布偏差）→ 三态裁决
  （调质模型 / 类级调整 / 反证笔记）——M4 L21 点 7 同款处置。

**验收**：CSV 权重定稿；校准记录图/CSV 落盘；校准集上趋化 CI 落带、逃避方向正确、
自发分布落带、静息无失稳。

## 7. 步骤 6：逐项验证（4–5 天）

### 7.1 P1 连接组加载 → `tools/validate_p1_connectome.py`
- 判据（§0 P1 + §2.2）：计数/分类/标注/自连接/孤立/确定性断言全过；M4/M3 子图交叉核对一致。
- 输出：`reports/neuro/m5_p1_connectome.png`（四类计数 + 连接数柱状 vs 权威带）+ `data/m5_p1_connectome.csv`。

### 7.2 P2 静息态动力学 → `tools/validate_p2_resting.py`
- 协议：无刺激降阶全虫（G0 定稿配置）T≥10s×N=5（确定性，试次方差来自起点扰动）；
  发放率分布统计。
- 判据（§0 预注册 #4）：无 NaN/无发散/发放率有限；静默比例 ≥70%±10%、组中位数 <1Hz、
  最大发放率 <60Hz（以 `data/m5_behavior_reference.csv` 电生理行为带为准）；重跑逐位一致。
- 输出：`reports/neuro/m5_p2_resting.png`（发放率直方图 vs 电生理带）+ `data/m5_p2_resting.csv`。

### 7.3 P3 咽部节律 → `tools/validate_p3_pharynx.py`
- 协议：咽部子图（G0 定稿）无食物/有食物驱动 T≥10s；发放序列 → 主频。
- 判据：主频 ∈ [0.1,2]Hz（操作窗 CSV 定稿，§0 #3）；节律稳定（主频漂移 <50%）；无发散。
- 输出：`reports/neuro/m5_p3_pharynx.png`（发放栅栏图 + 功率谱 + 主频标注）+ `data/m5_p3_pharynx.csv`。

### 7.4 P4 趋化行为 → `tools/validate_p4_chemotaxis.py`
- 协议：食物梯度 N≥20（协议 T 由 §3.5 功效预注册定稿——**降阶模型必须使 T≥15s 可行**）；
  无梯度对照同协议。
- 判据（§0 P4 a–d）：显著性（p<0.05 且 d≥0.5）；落带 [0.25,0.75] 且与行为参考 ΔCI ≤ 0.15；
  终态偏向；对照 p>0.05。计算可行性：单试次墙钟 ≤ 预注册上限（记录实测，超限 → 三态裁决）。
- 输出：`reports/neuro/m5_p4_chemotaxis.png`（典型轨迹 + CI 分布 vs 生物带 + 统计标注）+
  `data/m5_p4_chemotaxis.csv`（逐试次 CI/墙钟）。

### 7.5 P5 机械逃避 → `tools/validate_p5_escape.py`
- 协议：触刺激 N=20（转导延迟 τ_trans 定稿）；记录方向/神经潜伏期/行为潜伏期/反应概率。
- 判据（§0 P5）：方向正确（C_back>C_fwd 或 D_peak>0.3）且反应概率 ≥0.8；神经潜伏期 ∈ [5,20]ms；
  行为潜伏期 ∈ [30,50]ms（容差 [25,60]）；消融 sanity（删 PLM→AVM → 反应消失）；
  与 M3 结果一致性。
- 输出：`reports/neuro/m5_p5_escape.png`（刺激-反应轨迹 + 潜伏期分布 vs 窗）+ `data/m5_p5_escape.csv`。

### 7.6 P6 自发行为分布 → `tools/validate_p6_spontaneous.py`
- 协议：无刺激无梯度 T≥30s×N≥10（降阶配置；记录 v/ω/C 序列 → `classify_state`）。
- 判据（§0 P6）：前进 ∈ [60,80]%、后退 ∈ [10,25]%、转弯 ∈ [5,20]%（带定稿于
  `data/m5_behavior_reference.csv`，容差预注册）；bout 时长量级 informational；阈值不做事后调。
- 反证联动：后退比例 < 带 → 命令子图排查（AVA/AVD/AVB/PVC 耦合）→ 调质模型候选 → 三态裁决。
- 输出：`reports/neuro/m5_p6_spontaneous.png`（状态时间线 + 比例条 vs 行为带）+ `data/m5_p6_spontaneous.csv`。

**验收**：P1–P6 六个验证脚本 + `tools/run_m5_validation.py`（顺序运行，汇总 →
`reports/neuro/m5_validation_summary.json`，各 pass_=true；结构沿用 run_m4_validation.py，
含 `M5_REUSE=1` 读回机制与 `--skip-heavy` 选项）。
