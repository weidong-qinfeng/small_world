## 0. M6 目标与验收标准（Pass 定义）

**目标**（设计文档 §四 M6）：引入 **STP + STDP + 神经调质（多巴胺/血清素）调节**；
行为验证 **习惯化**（重复机械刺激 → 逃避反应衰减）并与真实习惯化曲线对照
（Rankin et al. 1990：重复触刺激 → 反应幅度指数衰减）；探索 **联想学习**
（盐+食物关联，AWC 神经元——C. elegans 经典学习范式）。
**交付**：学习行为仿真 + 习惯化/联想学习对照报告。

**M5 核心教训（本清单必须正面解决）**：
1. **夹带极限环**（L37/L39/L40#3）：单一张力驱动（AVB 14µA/cm²）+ 全互兴奋命令回路 →
   86% 神经元同步 2.7–13.8Hz → 静默上限 ~44%、fwd/back 运动池共同发放 → v≈0 → pause 主导。
   **M6 通过调质层/连接补充落地 M5 反证清单（RIM 酪胺/命令互抑/AVA→DD GABA 链/自发输入），
   并复核 M5 的 P2/P4/P6**——这是 M6 引入调质层的科学依据（m5_report §8）。
2. **同步发放网络上的 STDP 需要预判**（任务关键设计决策 2）：全同步 → 全部突触对 Δt≈0 →
   STDP 饱和（权重齐涨齐跌、无结构学习）。**STDP 必须在夹带缓解后（或限定子图+协议窗内）开启，
   否则学习必然不出现**——预注册为结构性限制（§0 #1）。
3. **P5 方向相位敏感**（L39/L40#5）：定稿 τ_trans=23 → 触注入 73ms → not_back；touch@50ms → back。
   习惯化协议需要**每个刺激都有可测反应**——协议前必须先修方向相位（命令互抑/调质落地后复核），
   否则"习惯化"无可衰减对象（G1 门，§0 预注册 #2）。

**Pass 标准（全部满足才进入 M7；每项可测，禁止模糊标准）**：

- [ ] **P1：STP/STDP 组件正确性（L2 突触层验证标准）**：STP 沿用 M2 已验证基础
      （`SynapseParams.u0/tau_fac_ms/tau_rec_ms` 开关，50Hz×10 脉冲易化/抑制曲线 M2 P3 已过，
      M6 重跑确认不回归）；**STDP 新建**：2 神经元对 + 成对脉冲协议（Δt ∈ {−60,…,+60}ms）→
      权重变化量 ΔW 与文献标准曲线一致（**ΔW ∝ exp(−|Δt|/τ)**，τ=20ms 量级；LTP 窗 Δt>0 /
      LTD 窗 Δt<0；幅值比 A₋/A₊ 预注册）；权重有界 [0, w_max]；确定性重跑逐位一致。
- [ ] **P2：神经调质系统 + M5 反证清单落地（M6 引入调质层的核心判据）**：多巴胺/血清素浓度模型
      数值稳定（无 NaN/无发散/浓度有限）；**RIM 酪胺（AVA 激活 → 酪胺释放 → 抑制前进命令）、
      命令互抑（AVA/AVD ↔ AVB/PVC 组装层加互抑边，不动 m5_connectome.csv）、AVA→DD/VD GABA
      功能链、自发/调质输入** 四项全部落地并冒烟验证（每个机制单独消融 sanity：删该项 →
      对应现象消失）；**复核 M5 的 P2/P4/P6**（判据带沿用 `data/m5_behavior_reference.csv`
      预注册带，不做事后调）：

        或方向一致；无梯度对照 p>0.05；

      三项**全部通过 → M5 的 P2/P6 反证记录解除（升级为 pass）**；部分通过 → 更新反证笔记

- [ ] **P3：习惯化行为（Rankin et al. 1990 对照）**：重复机械刺激（协议定稿于

      (a) 曲线形状：逐刺激反应幅度 R(n) 单调递减，指数拟合 R(n) = A·exp(−n/τ_hab) + B

### 判据可测性预注册（结构性限制，吸取 M3/M4/M5 全部教训——判据设计时就要考虑模型结构性限制）

1. **STDP 饱和（M5 夹带联动的结构性限制，任务关键设计决策 2）**：302 全同步发放网络
   （M5 D4 权重下 86% 同步）中所有突触对 Δt≈0 → STDP 权重齐涨齐跌、无结构学习。
   **预注册**：(a) STDP 默认**协议窗内开启**（学习协议 run 窗口内开、基线/复核协议关），
   且**限定突触子集**（学习相关通路：习惯化 = 触觉通路 PLM/ALM→命令中间神经元；
   联想学习 = ASE/AWC→AIY/AIB 趋化链）——不做 3638 化学突触全图 STDP（避免全同步饱和 +
   编译预算失控）；(b) G1 门先行：夹带缓解前不开启网络级学习协议；
   (c) 若 G1 后仍同步 → STDP 只做组件级（P1）验证 + 子图学习，网络级学习行为反证记录。
2. **习惯化协议的可测性（M5 P5 方向相位敏感，L40#5）**：M5 定稿 τ_trans=23 → 触注入 73ms →
   not_back；touch@50ms → back。**习惯化的反应量 R(n) 必须逐刺激可测**——预注册：
   (a) 习惯化刺激注入时刻在 G1 复核后定稿（优先保持定稿 τ_trans=23，若方向仍相位敏感则
   记录测量限制 + 裁决调整）；(b) 反应量操作化：R(n) = D_peak = max(C_back − C_fwd)（响应窗内，
   `WormLoop.run_escape` 同款度量）；方向判据 C_back 峰值 > C_fwd 或 D_peak>0.3 为前置 sanity；
   (c) 若某刺激反应 < 阈值（无可测反应）→ 该试次计 0 反应并如实入档（不剔除）。
3. **习惯化曲线拟合的操作化**：R(n) 逐刺激离散值 → 指数拟合 R(n)=A·exp(−n/τ_hab)+B
   （scipy curve_fit 或 numpy lstsq 固定初值，确定性 seed=0）；判据 (a) 单调性（相邻差中位数 <0
   或拟合 A>0）(b) 拟合优度 R²≥0.5（预注册；拟合失败 → 记录形状偏差，不静默重试）
   (c) τ_hab ∈ [3,15] 次（Rankin 1990 ISI=10s 量级，**带/容差定稿于 `data/m6_behavior_reference.csv`，
   不事后调**）。
4. **自发恢复的时程限制（真实恢复分钟~小时 vs 仿真时间尺度）**：真实 C. elegans 短期习惯化
   恢复需 ~10–60 分钟（Rankin 1990），302 点神经元仿真跑分钟级动力学不可行（预算）。
   **预注册**：恢复协议 = 休息窗（模拟时间，定稿于 CSV，如 30–120s 仿真）+ STP/酪胺恢复
   时间常数按生理量级取值（τ_rec 数百 ms~s）；判据用相对恢复（R_rest ≥ 0.3×R(1)），
   真实恢复时程的完整复现记录为测量限制（不伪造）。**恢复为 M6 相对强度判据，不是绝对时程判据**。
5. **联想学习的可逆性操作化**：设计文档 Pass = "行为改变可逆"。操作化 = 消退（extinction）：
   CS 单独重复呈现 → 行为回落。**判据用显著性（回落至与训练前 p>0.05），不是绝对 0**（M4 L7
   CI 统计陷阱教训：点值不可靠，显著性为主判据，|ΔCI| 点值 informational）。
6. **调质模型语义（非快突触，慢门控）**：神经调质 = 浓度变量（数百 ms~s 时间常数），
   调制目标突触电导/增益（gate），**不是**直接快 EPSP/IPSP——调质受体（dopamine/serotonin/
   mod 受体）在 M5 连接组标注中 g=0 占位（L20：mod 294 + none 872 跳过），M6 将其从"占位跳过"
   转为"功能门控"。时间尺度预注册（τ_mod 100–1000ms），不伪造毫秒级调质 PSP。
7. **计算预算（M4 L23/M5 §3.5 教训，任务关键设计决策 4）**：沿用 M5 降阶模型
   （302/point/0.1ms/exponential_euler，`PROTOCOL_WINDOW_MS=30000` 固定 stim 形状——**M6 协议
   单试次 T ≤ 30s，形状定稿后不变，不触发重编译**）；**预算预注册：行为验证总预算 ≤ 150 CPU-小时**
   （M5 200 CPU-h 内）；习惯化全协议（20–30 刺激 × T=150ms + ISI 10s 模拟 + 恢复窗）预估
   2–4 CPU-h；联想学习（训练 20 试次 × T≤15s + 测试 10 + 消退 20 + 对照 2 组）预估 10–20 CPU-h；
   探针先行实测墙钟（M5 302 档 T=1s≈3.8s，T=15s≈50s/试次为锚）；超出 → 最短协议 + 记录测量
   限制 + 三态裁决（M4 L21 模式）。
8. **冻结基线保护（组合不修改纪律）**：M0–M5 全部冻结文件（`src/` 下 M0–M5 交付、
   `tests/`、`tools/validate_*`、`data/m0–m5 定稿 CSV`——含 `m5_connectome.csv` 内容不变，
   M5 P1 复核 SHA 惯例）**零修改**；M6 **只新建**：`src/plasticity.py`（STDP + 三因子规则）、
   `src/neuromod.py`（调质池：多巴胺/血清素/酪胺）、`src/learning.py`（习惯化/联想学习协议
   运行器）、`data/m6_learning_params.csv`、`data/m6_behavior_reference.csv`、
   `tools/build_m6_ref.py`/`validate_p6_*.py`/`run_m6_validation.py`/`gen_m6_report.py`。
   若确需对 M5 文件做 API 兼容微调（如 `worm_loop` 增加可选参数）→ 逐条登记 m6_env_notes
   （M5 L42 惯例，未改签名/默认行为）。
9. **三态裁决纪律**：任何预注册判据与实测不符 → 先排查（数据/协议/实现），超容差 →
   如实记录 + 三态裁决请求（① 接受反证记录 ② 调整机制/参数重新校准 ③ 缩小验证范围），

## 2. 步骤 1：STDP 组件规格与验证（2–3 天，P1 验证对象；纯组件 + 文档）

### 2.1 突触层规格（设计文档 L2 验证标准：STDP 时序依赖可塑性 ΔW ∝ exp(−|Δt|/τ)）

`src/plasticity.py` 新建 `StdpSynapse`（Brian2 `Synapses` 包装，成对 STDP，规格公式）：

```
Δw = A₊·exp(−Δt/τ₊)    若 Δt = t_post − t_pre > 0   （pre→post 因果：LTP）
Δw = −A₋·exp(Δt/τ₋)    若 Δt < 0                    （post→pre 反因果：LTD）
w ← clip(w + Δw, 0, w_max)
参数（预注册，m6_learning_params.csv stdp 行定稿）：
  τ₊ = τ₋ = 20 ms（文献典型值，Bi & Poo 1998 量级；预注册 [10,40] 可调窗）
  A₊ = 0.01·w0（预注册 [0.005, 0.02]·w0）
  A₋/A₊ = 0.9（预注册 [0.5, 1.0]，LTD/LTP 平衡防发散）
  w_max = 2.0·w0；w0 = 连接组 g_max_ns 占位（ampa 5.0nS 语义，M5 先验）
实现要点（Brian2 2.6.0）：
  - on_pre/on_post 双事件：pre 发放记录 t_pre，post 发放按 Δt 更新 w（成对最近邻或
    全对——预注册最近邻 all-to-all 简化，文档记录）；Δt 从 SpikeMonitor 时间戳计算
    （numpy 侧批处理，避免 Brian2 方程内复杂逻辑）或 on_pre 内近似；
  - 权重存储：w 作为 Synapses 状态变量（单位 = 电导缩放因子，乘进 gmax 或 as gmax）；
  - 编译纪律：STDP 开启的 Synapses 为**独立编译产物**（协议窗内开启），与 M5 基线
    化学 Synapses（无 STDP）并存但物理分离——基线协议不触发 STDP 代码路径；
  - 确定性：p=1/n=1；ΔW 计算无随机性；同参数重跑逐位一致。
```

### 2.2 三因子调质门控可塑性（联想学习机制，P4 前提；规格公式）

```
de/dt = −e/τ_e + pre·post             （资格迹 eligibility trace，τ_e 预注册 100–500ms）
dw/dt = η·M_mod(t)·e(t)                （三因子：pre·post 时机 × 调质浓度门控）
M_mod(t) = 血清素/多巴胺浓度（US=食物信号，步骤 4 协议注入）
参数：η（学习率，预注册 [1e-4, 1e-2]）、τ_e、w 边界 [0, w_max] 同上。
```

- 作用域（§0 #10）：联想学习链 ASE/AWC→AIY/AIB（趋化链，M4/M5 验证过极性）与
  盐梯度行为读出共用同一通路；三因子规则在该子集上开启，其余突触不开启。
- **STDP 与三因子的分工（预注册）**：P1 验证成对 STDP 组件正确性（文献标准曲线）；
  网络级习惯化以 **STP 抑制 + 酪胺调质**为主（P3 机制）；联想学习以**三因子调质门控**
  为主（P4 机制）；成对 STDP 在 302 网络的完整开启与否由 G1 复核结果裁决
  （夹带缓解 → 可开子集；未缓解 → 组件级通过 + 网络级反证记录，§0 #1）。

### 2.3 P1 验证协议（`tools/validate_p6_stdp.py`）

- 组件：2 点神经元（`PointNeuron`）+ 1 条 `StdpSynapse`（ampa，w0=5.0nS 语义）；

```
    感受器级 US 注入功能模型，与 M4 ASE 转导简化同哲学，不伪造真实 NSM 序列）
训练（获取）：配对期 N_train 试次（预注册 20 试次 × T≤15s，盐梯度 + C_5ht=1）
测试（行为读出）：N_test 试次（预注册 10 × T=15s，盐梯度 + C_5ht=0）→ CI_salt
对照 1（未配对）：同试次数，CS/US 时间随机（种子固定）→ CI_salt 应无显著获得
对照 2（盐+饥饿，US 反号）：C_5ht=0 且 C_da 升高或负门控（预注册语义）→ 回避或中性
消退（可逆性）：N_ext 试次（预注册 20 × T≤15s，盐梯度 + C_5ht=0）→ CI_salt 回落
机制：三因子规则（§2.2）在 ASE/AWC→AIY/AIB 子集开启，η/τ_e 定稿于 CSV；
      e 资格迹跨试次持续（会话内连续性），测试期 M=0 → 无进一步更新（读取基线）
```

### 5.3 P4 判据（§0 P4 细化）

- (a) 获得：CI_salt(训练后) vs CI_salt(训练前基线，预注册 10 试次测) 配对 t p<0.05 且 d≥0.5；
- (b) 对照：未配对组 CI_salt 与基线无显著差异（p>0.05，主判据）；盐+饥饿组方向相反或中性；
- (c) 可逆：消退后 CI_salt 与训练前基线无显著差异（p>0.05）且显著低于训练后峰值（p<0.05）；
- (d) 消融：η=0 或 M≡0 → 无学习（无显著变化）——证明三因子门控必需；
- (e) 确定性重跑逐位一致；参考模型（L4②）同协议预测时间线对照（ΔCI 差 ≤ 0.15 或方向一致）。

**验收**：`learning.py` 联想学习运行器冒烟（3 试次快速训练窗）+ 协议/参数 CSV 定稿。
