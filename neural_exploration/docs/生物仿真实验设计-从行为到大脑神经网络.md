# 生物仿真实验设计·阶段二：从全连接组行为到大脑的神经网络

> 版本：v0.1（阶段二整体实验设计稿，承接阶段一）
> 前置假设：**阶段一（M0–M7）全部实现**——C. elegans 全连接组虫已通过趋化/逃避/自发行为/习惯化/联想学习的统计验证，学习机制（STP/STDP/多巴胺/血清素）已在 C. elegans 范式上验证，工具链与冻结基线就绪；M7（更复杂生物或机制迁移）至少部分完成。
> 终极目标：**大脑的神经网络**——一个自底向上搭建、结构与动力学尽量复刻真实生物、行为与神经活动双金标准验证的闭环电子大脑。
> 核心科学问题：**从 302 个神经元的线虫到"大脑"，跨过的不是一条更大的线虫，而是一系列新功能（工作记忆、决策、导航地图、联想泛化、状态组织）的涌现。这些功能究竟是"更大的网络"必然涌现的，还是需要新的结构（脑区分化）、新的机制（多尺度可塑性、神经调质）与新的验证方式（全脑活动记录）？**
> 实验路线：C. elegans（302）→ 果蝇幼虫全脑（3,016）→ 成年果蝇全脑（139,255）→ 斑马鱼幼鱼全脑（~10 万）→ 小鼠皮层微环路 → 小鼠全脑介观 → 灵长类认知抽象 → **"大脑的神经网络"终态**。
> 验证金标准（阶段二升级为**双金标准 + 扰动预测**）：行为学统计一致（沿用阶段一）＋ 全脑活动统计一致（新增）＋ 扰动预测命中（最强测试）。

## 二、从 C. elegans 到"大脑"：差距的三维刻画

M6/M7 之后仍然"离大脑很远"，差距不是线性的，而是三个维度的质变：

### 2.1 结构差：302 神经元没有"脑"

C. elegans 的神经环（nerve ring）不是大脑：没有皮层/基底节/海马/小脑/杏仁核的分区，没有层流与细胞类型分化，没有局灶化功能（focal functions）。而"大脑"的操作特征恰恰是**结构分化承载功能分化**：
- 皮层：感觉表征、工作记忆、决策的证据累积；
- 海马：空间地图、情景记忆、巩固；
- 基底节：动作选择、奖赏学习；
- 小脑：时序与运动学习；
- 神经调质系统：全局状态（觉醒、注意、动机）调制。

### 2.2 验证差：行为学数据约束不了"神经活动"

C. elegans 无法全脑记录神经活动，阶段一只能验证"行为"，无法验证"活动"（模型内部如何组织）。而大脑级假设（如工作记忆的持久活动、决策的累积动力学、空间地图）是**关于活动本身**的假设——必须用全脑活动记录来验证。阶段二新增的验证物种（斑马鱼幼鱼全脑成像、小鼠 Neuropixels）正是为此存在。

### 2.3 学习差：习惯化/联想学习 ≠ 大脑的学习

C. elegans 的学习是单一模态、单一突触尺度的简单可塑性。大脑的学习是多尺度、多系统的：
- 时间尺度：STP（ms–s）→ STDP（s–min）→ 稳态可塑性（min–h）→ 结构可塑性（h–d）→ 系统巩固（d–w）；
- 空间尺度：突触 → 神经元 → 局部回路 → 脑区 → 全脑（调质系统全局调制）；
- 功能尺度：习惯化 → 经典/操作条件化 → 泛化 → 工作记忆 → 序列学习 → 元学习（学习如何学习）。

### 2.4 认知差：行为 → 认知的鸿沟

阶段一产出的是"行为"，数字大脑（同仓库上层项目）产出的是"认知"（应用题文本 → 推理链）。中间缺少的正是"大脑的神经网络"：一套从生理机制里长出来、能被认知层调用的表征与动力学。

**阶段二的目标就是同时填补这四道沟：用真实数据约束结构（2.1），用全脑记录约束活动（2.2），用多尺度可塑性补齐学习（2.3），最终以"大脑的神经网络"作为机制层与认知层的接口（2.4）。**

## 三、阶段二科学命题与三条新铁律

### 3.1 阶段二总命题（可证伪的核心假设）

> **大脑功能不是某个分子的属性，也不是单个神经元/突触/回路的属性，而是"结构尺度 × 多尺度可塑性 × 闭环生态"三者耦合的涌现。** 若在一组确定性动力学 + 局部物理随机的网络（无参数级概率推理）中，随着结构尺度（≥10⁴–10⁵ 神经元、≥10⁷ 突触）与可塑性机制的配齐，工作记忆、决策、导航地图、联想泛化、觉醒/睡眠等"类脑功能"涌现，且其**行为与全脑活动统计在真实生物数据上不可区分**，则证明"理解"不需要概率推理引擎，只需要真实的结构与动力学（阶段一结论在大脑尺度的推广）。

**可证伪性**：任一尺度上功能不涌现、或活动统计与真实记录显著不符，都是反证（见各里程碑"反证路径"），并输出"缺失机制清单"——这是本实验最重要的科学产出。

### 3.2 "大脑的神经网络"操作定义（终态验收标准）

一个单一代码库内的闭环系统，同时满足：

1. **结构**：以真实生物连接组/图谱为骨架，包含皮层、海马、基底节、小脑、杏仁核、丘脑、脑干与神经调质系统的分区（有连接组的尺度用真实连接组，无连接组的尺度用可验证抽象，见铁律 A）；
2. **动力学**：确定性离子/通道动力学或经校准的降阶动力学，局部物理随机（突触量子释放、通道噪声）为唯一随机源；
3. **学习**：多尺度可塑性同构（STP/STDP/稳态/结构/系统巩固/调质调制），支撑工作记忆、习惯化、经典与操作条件化、空间导航、序列学习；
4. **闭环**：虚拟身体 + 环境 + 生态学时间尺度（发育、昼夜节律、经验史），实时或超实时运行；
5. **验证**：每个尺度在其对应物种的真实数据上通过"行为 + 活动 + 扰动预测"三层检验；
6. **合并**：与数字大脑认知层接口，形成"从离子通道到推理"的单链系统。

**诚实的边界声明**：本终态不声称"复刻人脑"（人脑无突触级连接组、无全脑活动记录，无法按本实验的金标准验证）。它是在**可验证数据约束下的、自底向上逼近大脑的电子神经网络**；其最高实现形态 = 小鼠全脑介观（活动验证）+ 灵长类抽象架构（认知验证）+ 数字大脑（推理验证）的合并体。

### 3.3 阶段二三条新铁律（叠加在阶段一三条铁律之上）

| # | 铁律 | 内容 |
|---|---|---|
| A | **结构已知用真实结构，结构未知用可验证抽象** | 有连接组（幼虫/成年果蝇）必须用真实连接组；无连接组（小鼠/灵长类）必须用"可验证抽象"（规范微环路、介观群体、图谱投射），且每个抽象必须在**它替代了什么真实结构、在什么尺度上可被数据区分**的意义上登记（抽象登记册，见 §十一）。抽象-验证绑定，延续阶段一"不为精细而精细" | 
| B | **活动与行为双金标准** | 从 M10（斑马鱼）起，全脑活动记录成为与行为并列的金标准：模型不仅要复现行为，还要复现全脑活动的统计（发放率分布、群体相关性、刺激解码、状态转换）。最强测试是**扰动预测**：模型预测"激活/沉默某神经元（组）"后的行为与活动变化，与真实光/热/化学遗传学扰动实验对照。预测不准 = 反证，不预测 = 不合格 |
| C | **先缩放定律，后放大尺度** | 任何尺度跃迁之前，先在当前尺度做"保真度-性能-功能"扫描（神经元数、突触类型、可塑性机制逐项加一），记录功能指标的缩放曲线，用曲线决定下一尺度**保真什么、抽象什么**。防止"为精细而精细"与"为规模而规模"两个方向的浪费 |

## 四、多尺度建模框架升级（L0–L7 + 横切层）

阶段一框架（L0–L5）原样保留（冻结基线）。阶段二在其上叠加：

```
┌───────────────────────────────────────────────────────────────┐
│ L8 认知层（数字大脑接口，非离子级仿真；输入/输出约束）           │
├───────────────────────────────────────────────────────────────┤
│ L7 全脑与生态层：全脑分区装配 + 身体 + 环境 + 发育/节律/经验史    │
├───────────────────────────────────────────────────────────────┤
│ L6 脑区/核团层：皮层柱、海马、基底节、小脑、杏仁核、丘脑、脑干    │
│    ＋ 细胞类型分化（兴奋/抑制亚型 PV/SST/VIP、调质神经元）       │
├───────────────────────────────────────────────────────────────┤
│ L5 行为层：虚拟身体 + 环境（阶段一已通过，冻结）                │
├───────────────────────────────────────────────────────────────┤
│ L4 网络层：连接组 + 网络动力学 + 可塑性（阶段一已通过，冻结）    │
├───────────────────────────────────────────────────────────────┤
│ L3 回路层（阶段一已通过，冻结）                                 │
├───────────────────────────────────────────────────────────────┤
│ L2 突触层（阶段一已通过，冻结）                                 │
├───────────────────────────────────────────────────────────────┤
│ L1 神经元层（阶段一已通过，冻结）                               │
├───────────────────────────────────────────────────────────────┤
│ L0 离子通道层（阶段一已通过，冻结）                             │
└───────────────────────────────────────────────────────────────┘
横切层（cross-cutting，贯穿 L0–L7）：
  T1 多尺度可塑性：STP/STDP → 稳态 → 结构 → 系统巩固 → 元可塑性
  T2 神经调质与内稳态：DA/5HT/NE/ACh 全局调制 ＋ 能量预算（突触成本）
  T3 缩放与抽象管理：点神经元/规范微环路/介观群体/统计连接组学；抽象登记册
```

**新增层说明**：

- **L6 脑区/核团层**：阶段二第一次面对"局灶化功能"。每个脑区有独立的结构模板（层流、细胞类型构成、输入/输出投射模式）与独立验证点（该脑区的电生理/成像特征）。脑区模板优先来自真实数据（连接组聚类、细胞类型转录组、图谱），抽象来自可验证的规范微环路。
- **L7 全脑与生态层**：全脑 = 脑区装配 + 长程投射 + 调质系统 + 身体 + 环境。生态学时间尺度（昼夜节律、经验史）首次成为建模对象（对应觉醒/睡眠、习惯化/巩固等行为）。
- **T1 多尺度可塑性**：阶段一的 STP/STDP 是 T1 的底座；新增稳态可塑性（防失稳）、结构可塑性（突触增减/棘重塑）、系统巩固（海马→皮层重放）、元可塑性。每级可塑性引入前必须在当前物种的对应现象上验证（习惯化、成瘾样、记忆巩固曲线）。
- **T2 神经调质与内稳态**：多巴胺（奖赏/动机）、血清素（状态/逃避）、去甲肾上腺素（警觉）、乙酰胆碱（注意/唤醒）作为**全局状态变量**调制各层增益——这是 C. elegans 阶段没有的（阶段一只有多巴胺/血清素局部作用）。能量预算把"突触成本"计入可塑性目标，驱动稀疏化与去冗余（大脑是预算约束机器）。
- **T3 缩放与抽象管理**：铁律 C 的落地层。登记每一个抽象：它替代了什么真实结构、引入误差的量级、在哪个尺度上可被数据区分、何时必须回归精细模型（例如：发现点神经元丢失树突计算 → 对相关神经元子集回归多隔室）。

## 五、里程碑规划 M8–M14（承接 M0–M7，每个可独立交付）

> 两条并行轨道：**昆虫轨道**（果蝇幼虫→成年果蝇，连接组完备，验证"结构→行为"）与**脊椎动物轨道**（斑马鱼→小鼠，记录完备，验证"结构+活动→行为"）。两轨在 M12 汇合为全脑介观，M13/M14 通向终态。预估总周期：第 17–72 月（约 4.5 年，单人全职含学习曲线，多轨可并行压缩）。
> 每个里程碑仍遵循阶段一规则：**Pass/Fail 明确，未通过不得进入下一层；失败即反证，输出"缺失机制清单"。**

### M8：果蝇幼虫全脑——第一个"真脑"闭环（第 17–21 月）

- **背景**：果蝇幼虫连接组已完整发表（3,016 神经元、约 55 万突触），且是**迄今唯一一个伴随"全连接组驱动仿真"尝试的完整神经系统**（原作者已可驱动其复现前进/后退等运动模式）。我们站在其经验上，但按阶段一哲学做**逐层生物验证**。
- **数据**：
  - 连接组：Winding et al. 2023（3,016 神经元、~548,000 突触；感觉/中间/运动/咽部分区）；
  - 行为：趋化、避温、避痛、嗅觉联想学习、习惯化（幼虫行为学成熟）；
  - 活动：幼虫全脑体积成像（GCaMP）数据集；
  - 扰动：热/光遗传激活-行为筛选（幼虫是"全神经元激活图谱"研究的经典对象）。
- **内容**：
  1. 阶段一代码库直接迁移（L0–L5 冻结件复用），载入幼虫连接组（含神经递质/受体类型标注）；
  2. 虚拟幼虫身体：分段体 + 真实运动模式（前进/后退/侧转/蜷缩/掘进），肌肉耦合沿用 L5 验证件；
  3. 行为验证：自发行为状态分布（前进/转弯/停驻时间比例）、气味联想学习指数、避痛学习；
  4. **扰动预测（首次引入）**：模型预测"激活/沉默第 i 个神经元（组）"的行为后果 → 与实验扰动图谱对照。
- **Pass**：≥3 种行为统计一致（p>0.05 或 <20%）；扰动预测命中率 ≥70%（按预先注册的 top-N 神经元子集）；行为切换时的全脑活动状态序列与体积成像统计一致。
- **新增科学问题**：302→3,016 神经元，第一次出现"多感觉整合 + 中央处理"——行为不再只是反射叠加；量化学习（嗅觉联想）需要哪些回路与可塑性，为 M9 蘑菇体研究铺路。
- **反证路径**：行为不涌现 → 连接组只有连接有无、无权重（权重为自由参数，用行为学数据反推，沿用阶段一 M4/M5）→ 身体耦合过简 → 缺失感觉通道编码 → 逐项排查并记录。

### M9：成年果蝇全脑——首个完整成年脑连接组（第 21–30 月）

- **背景**：FlyWire 项目 2024 年发表了**史上第一张完整成年动物大脑连接组**：139,255 个神经元、54.5M 化学突触、~8.5k 缝隙连接。这是"结构完备假设"的决定性检验场：结构全知时，行为与活动能否被确定性动力学复现？
- **数据**：
  - 连接组：FlyWire（Dorkenwald et al., Nature 2024；Science 2024）＋ 已核对子集 hemibrain（Scheffer et al. 2020，~25k 神经元）＋ 全脑细胞类型标注（Nature 2024）；
  - 行为：球上虚拟现实行走、嗅觉经典条件化（成熟范式）、求偶序列、巨纤维逃跑、觉醒/睡眠样状态；
  - 活动：中枢脑钙成像、胞外电生理；
  - 扰动：中枢脑神经元的 optogenetic 激活/沉默实验库。
- **内容**：
  1. **引擎升级**：GPU 仿真（Brian2CUDA / NEST GPU / PyTorch 自研，参考公开的"果蝇脑 GPU 仿真"工程路线）；point-neuron 为主，按需回归精细模型（铁律 A）；
  2. 虚拟果蝇身体：六足步态、翅、触角/复眼感觉输入；VR 实验范式复刻（与真实实验同一协议，数据可直接对照）；
  3. 涌现功能目标（**本里程碑的科学看点**）：
     - **蘑菇体（MB）**：联想泛化——训练后对新刺激的泛化梯度与真实一致；
     - **中央复合体（CX）**：航向地图（昆虫的"海马"）——虚拟现实中的航向保持、旋转补偿；
     - 觉醒/睡眠样状态：昼夜节律调制下的状态切换；
     - 趋利避害决策：冲突刺激下的选择概率。
  4. 扰动预测：全脑扰动图谱模拟（激活/沉默 → 行为/活动变化）与实验库对照。
- **Pass**：嗅觉条件化学习曲线与泛化梯度一致；航向地图与导航行为一致；求偶/逃跑行为序列一致；**扰动预测命中率 ≥70%**；全脑活动统计（发放率分布、群体相关性）与成像一致。
- **反证路径**：连接组完备仍不涌现 → 突触权重/神经调质/身体反馈缺失 → 逐级排查（这是"连接组完备性假设"的关键检验，反证结论直接写入缺失机制清单）；若 MB/CX 功能不涌现 → 检查可塑性规则与调质（多巴胺在 MB 中的奖赏编码已知）。

### M10：斑马鱼幼鱼全脑——"记录一切"的第二金标准（第 24–33 月，与 M9 并行）

- **背景**：斑马鱼幼鱼是唯一能在行为发生的同时以细胞分辨率记录**全脑**活动的脊椎动物（光片显微镜，~10 万神经元，~1–2 Hz），且全脑 EM 连接组正在重建（含神经调质类型标注）。这是**"结构 + 活动 + 行为"三者齐备的验证平台**——本实验的验证方法学主战场。
- **数据**：
  - 活动：全脑光片钙成像数据集（Ahrens et al., Nat Methods 2013 开创的范式）＋ fictive 游泳虚拟现实（双光子）；
  - 行为：捕食（prey capture）、视动/视震反应（OMR/OKR）、惊吓（Mauthner 回路）、群聚、习惯化；
  - 连接组：幼虫全脑 EM 重建进行中（含调质类型标注的重建、"connectomic resource" 持续发布）；
  - 扰动：全脑 optogenetic/化学遗传扰动实验（与成像同体制）。
- **内容**：
  1. 降阶动力学校准：验证目标是群体活动而非单神经元波形 → L0 抽象为经校准的点神经元（Izhikevich/LIF+），除非某行为需要 HH（铁律 A 应用实例，记录入抽象登记册）；
  2. **双金标准管线**：行为复现 + 全脑活动逐神经元预测（发放率分布、相关性矩阵、行为状态解码、状态转换的时序）；
  3. 神经调质系统显式建模（T2）：多巴胺/血清素等对全局活动的调制，对照成像中的调质相关信号；
  4. 扰动预测：模型预测光遗传扰动后的全脑活动 + 行为变化 vs 实验。
- **Pass**：全脑活动统计与成像数据不可区分（分布/相关性/解码准确率三指标）；行为（捕食成功率、OMR/OKR、惊吓潜伏期）一致；**扰动预测命中率 ≥70%**。
- **反证路径**：全脑活动统计对不上 → 这是最强的反证信号：缺调质系统？缺抑制性中间神经元亚型？缺感觉运动耦合细节？逐项对照成像数据定位（活动数据把"缺什么"变成了可定位的问题，而不是猜测）。

### M11：小鼠皮层微环路——进入哺乳动物（第 30–40 月）

- **背景**：从昆虫到哺乳动物的跨越。哺乳动物皮层有层流、丰富的抑制性中间神经元亚型（PV/SST/VIP）、振荡动力学——这些是昆虫脑没有的（或极简的）。
- **数据**：
  - 结构：大鼠皮层柱数字重建（NMC：31k 神经元、~8M 突触，Markram et al. 2015）；小鼠视觉皮层 ~1 mm³ 功能连接组学（MICrONS：多视觉区、突触级重建 + 双光子活动）；
  - 活动：Allen 视觉编码 Neuropixels 数据集（小鼠 V1 等多区，细胞类型 × 反应性质）；
  - 行为：标准化视觉决策任务（IBL：行为 + 全脑多探针记录，公开大规模数据集）。
- **内容**：
  1. 皮层模板：层流结构、兴奋/抑制平衡、PV/SST/VIP 亚型配置（权重与连接规则来自 MICrONS/NMC 统计）；
  2. 验证单元从"行为"细化为"单细胞/群体反应性质"：方向/取向调谐、对比度-反应曲线、γ 振荡谱、视觉刺激的群体解码；
  3. IBL 任务复刻：视觉决策中的证据累积动力学（ramping）、选择解码、反应时分布。
- **Pass**：V1 调谐与层流反应模式 vs Neuropixels 数据一致（调谐宽度、方向选择性分布、层间差异）；γ 振荡谱一致；IBL 行为（正确率/反应时/策略）复现；任务相关群体动力学（解码准确率曲线）一致。
- **反证路径**：若 γ/兴奋-抑制平衡对不上 → 抑制性亚型比例与连接权重 → 增加细胞类型多样性；若决策累积动力学缺失 → 检查突触后整合时间常数/循环连接 → 增加时间常数多样性（T1 可塑性的时间尺度）。

### M12：小鼠全脑介观模型——"全脑"的首次闭环（第 36–48 月）

- **背景**：小鼠无突触级全脑连接组，但有**介观级全脑结构**（Allen 图谱：~500 区域投射矩阵）＋**全脑活动记录**（IBL：上千 session 的同一决策任务 + 全脑 Neuropixels）＋ 近年发布的神经调质全脑投射图谱。这是"大脑的神经网络"的第一实现形态。
- **数据**：
  - 结构：Allen Mouse Brain Connectivity Atlas（Oh et al. 2014 介观连接组）＋ CCFv3 脑图谱 + 调质系统全脑投射图谱；
  - 活动/行为：IBL 标准化决策数据集（正确率/反应时 + 全脑神经活动，公开）；
  - 扰动：药理学、局部光遗传、局部损伤的行为/活动效应（文献）。
- **内容**：
  1. 介观降阶（T3）：每区域数千点神经元群体 + 区域间加权投射（图谱强度为参数，用 IBL 数据拟合，沿用阶段一"权重是自由参数"哲学）+ 调质系统全局调制（T2）；
  2. 脑区功能分化落地（L6）：皮层（感觉/前额）、海马、基底节、小脑、丘脑、脑干核团——验证每个脑区承担其文献角色（如基底节负责动作选择）；
  3. 行为闭环：视觉决策、探索/奖励学习、习惯化与巩固（系统巩固首次引入：T1）；
  4. 验证：行为（正确率/反应时/策略切换）＋ 全脑活动（区域发放率、抉择相关活动、任务依赖动力学）＋ 扰动模拟（药物/损伤 → 行为效应与文献对照）。
- **Pass**：IBL 行为统计一致；全脑活动统计一致（区域级）；扰动模拟与文献定性/定量一致；"区域级"损伤-功能对应关系成立（如 PFC 损伤 → 工作记忆缺陷）。
- **反证路径**：区域耦合对不上 → 图谱连接强度/调质权重参数拟合 → 若仍失败：介观抽象丢失了关键机制（如跨区域同步）→ 对该机制回归局部精细模型（铁律 A 的回归通道）。

### M13：灵长类尺度认知架构——"大脑的神经网络"最终形态（第 44–60 月）

- **背景**：灵长类没有突触级连接组、没有全脑活动记录——按阶段一金标准**不可直接验证**。因此本里程碑的验证策略明确降级并重构：**认知任务组 + 神经影像 + 病变/药理 + 行为学**，并保持假设-反证清晰（这是本实验最重要的诚实声明）。
- **数据**：人类连接组图谱（HCP）、规范微环路模板、跨物种保守架构知识（皮层-海马-基底节-小脑-杏仁核-丘脑-脑干 + 调质系统）、认知任务行为学数据（含数字大脑原有应用题测试）。
- **内容**：
  1. 组装：把 M12 验证过的全脑框架 + 阶段一验证过的生物机制（趋化回路、CPG、习惯化、联想学习）升级为"灵长类抽象大脑"（稀疏编码、预测性处理、工作记忆、决策、导航、简化社会性）；
  2. 认知层接口（L8）：数字大脑作为"认知任务组"的生成器与评测器——机制层输出表征，认知层输出推理；
  3. **"最小充分大脑"实验**（本实验的收官科学问题）：从 M12 全脑逐级移除脑区/机制，找出一组"结构 + 可塑性 + 调质"的**最小充分集**，仍能通过全部认知任务组——回答"大脑的哪些结构/机制必不可少"。
- **Pass**：认知任务组（含数字大脑原有应用题测试）通过；神经影像约束（静息态网络、任务态激活模式）统计一致；行为学（反应时、错误模式）一致；"最小充分大脑"清单给出可复现答案。
- **反证路径**：认知层无法由机制层支撑 → 输出"缺失机制清单"（如需要更强的预测性处理、更长的工作记忆时间常数）→ 反哺 M11/M12 的生物建模（本实验的循环价值）；清单中的每一项都成为后续生物实验的具体假设。

### M14（终极集成）：从离子通道到推理的单链闭环（第 56–72 月，最终交付）

- **内容**：一个代码库、一条因果链：L0 离子通道 → L1 神经元 → L2 突触 → L3 回路 → L4 网络 → L5 行为 → L6 脑区 → L7 全脑 → L8 认知（数字大脑）。合并 M0–M13 全部冻结件，做端到端回归（任何一层改动不得破坏下层已通过基线）。
- **验收（终极金标准）**：
  1. 系统在虚拟生态中自主学习，并泛化到训练外的新任务组；
  2. 已在各物种尺度实现的验证全部保持通过（行为 + 活动 + 扰动）；
  3. 与数字大脑合并后通过原有认知测试（应用题），且推理链可追溯至机制层（"为什么能推理"有了物理答案）。
- **科学交付物**：① 可运行的"大脑的神经网络"（§3.2 六条操作定义全部满足）；② **必需机制清单**（哪些结构/动力学/可塑性必不可少——阶段一 §九 理念的最终版）；③ **缩放定律曲线**（功能 vs 尺度/保真度，M8–M13 全程累积）；④ **抽象登记册**（T3：每个抽象的理由、误差、回归条件）；⑤ "从神经到认知"完整模型（与数字大脑合并的最终形态）。

## 六、验证标准总则（阶段二升级版）

### 6.1 双金标准

| 金标准 | 内容 | 对应里程碑 |
|---|---|---|
| 行为金标准（沿用阶段一） | 同环境刺激下，仿真与真实生物的行为指标分布统计不可区分（p>0.05 或 <20%） | 全部 |
| 活动金标准（新增） | 仿真与真实记录的全脑/局部神经活动统计不可区分（发放率分布、群体相关性、解码性、状态转换时序） | M8 起（M10 全脑、M11 皮层、M12 全脑） |
| 扰动预测（最强测试） | 模型预测"激活/沉默神经元（组）/脑区"后的行为与活动变化 vs 真实扰动实验；命中率 ≥70%（预先注册子集） | M8 起，贯穿至 M13 |

### 6.2 数据隔离原则（防止过拟合）

每个里程碑的验证至少使用**三个互相独立的数据源**：拟合参数用数据集 A（如行为学 A），held-out 验证用数据集 B（行为学 B）＋ 数据集 C（活动记录）＋ 数据集 D（扰动实验）。与阶段一的区别：阶段一只有"行为"一个输出通道，阶段二有"行为 + 活动 + 扰动"三个通道，过拟合空间被大幅压缩——**模型必须同时在三个通道上成立**。

### 6.3 通过线总表

| 层/里程碑 | 对照数据 | 指标 | 通过线 |
|---|---|---|---|
| M8 幼虫 | 行为学文献 + 体积成像 + 扰动图谱 | 行为分布/学习指数/活动状态序列/扰动命中 | p>0.05 或 <20%；命中 ≥70% |
| M9 成年果蝇 | FlyWire + 行为学 + 成像 + 扰动库 | 学习曲线/航向导航/活动统计/扰动命中 | p>0.05 或 <20%；命中 ≥70% |
| M10 斑马鱼 | 全脑成像 + 行为学 + 扰动 | 全脑活动统计三指标/行为/扰动命中 | 不可区分；命中 ≥70% |
| M11 小鼠皮层 | Neuropixels + MICrONS + IBL | 调谐/γ谱/决策动力学 | 分布一致（统计） |
| M12 小鼠全脑 | IBL 全脑数据 + 图谱 + 药理文献 | 行为 + 区域活动 + 扰动效应 | p>0.05 或 <20% |

### 6.4 失败即反证（延续并强化）

每一里程碑的反证输出不是"失败了"，而是：**① 具体缺什么（结构/机制/尺度）② 证据指向哪里 ③ 下一步假设**。M8–M13 的反证结论汇总为最终"必需机制清单"（M14 交付物②），并且每一条反证都可能反哺阶段一的 C. elegans 模型（例如 M10 发现调质系统必不可少 → 回查阶段一虫是否低估了血清素的作用）。

## 七、技术选型与计算成本

### 7.1 仿真引擎（阶段二主线）

| 阶段 | 引擎 | 用途 |
|---|---|---|
| M8（幼虫） | 阶段一引擎（Brian2/NEURON）直接复用 | 3,016 神经元、~0.5M 突触，CPU 即可实时 |
| M9（成年果蝇） | **GPU 类**：Brian2CUDA / NEST GPU / PyTorch 自研点神经元内核；参考公开"果蝇脑 GPU 仿真"工程（eonsystemspbc/fly-brain 路线） | 139,255 神经元、54.5M 突触，单 GPU 实时~数倍实时；需要 HH 精度的神经元子集按需回归 NEURON |
| M10（斑马鱼） | 同上（点神经元为主）＋ 钙成像正向模型（神经元活动 → 荧光信号） | ~10 万点神经元 + 成像比较管线 |
| M11（小鼠皮层） | 局部精细：NEURON/Arbor（微环路验证）；行为尺度：降阶 | 31k 神经元微环路验证；皮层群体模型 |
| M12（小鼠全脑介观） | 介观框架（自研或 Nengo 风格群体/率模型）+ 调质状态层 | ~500 区域 × 数千点神经元 ≈ 1–5M 点神经元，单节点 GPU 可行 |
| M13/M14 | 介观框架 + 数字大脑认知层接口 | 与数字大脑同规模 |

> 迁移原则：**引擎是手段不是目的**——每个引擎的引入只为了某一里程碑的规模/精度需求，且该里程碑通过后冻结为基线。GPU 引擎的正确性必须先在 M8 上（与 CPU 引擎同一模型逐神经元对齐）验证，再放行到 M9。

|---|---|---|---|

    perturb_sim.py          # 扰动预测管线（激活/沉默 → 行为+活动）

## 九、风险、假设与反证路径总表

| 假设 | 风险 | 缓解/反证 |
|---|---|---|
| 连接组完备即行为涌现（M9 决定性命中） | 突触权重未知；调质/身体反馈缺失 | 权重反推（沿用阶段一）+ 扰动预测；失败即输出"缺失机制清单" |
| 全脑活动可作金标准 | 成像 ~1–2 Hz、群体钙信号，分辨率有限 | 与电生理互补；只承诺统计级不可区分，用稳健指标（分布/相关性/解码） |
| 点神经元/介观抽象不丢关键机制 | 树突计算、簇发放、跨区域同步可能被抽象丢失 | 铁律 C 缩放扫描量化；抽象登记册强制回归条件；发现即回归精细 |
| 灵长类可验证（降级后） | 无突触级结构、无全脑记录 | 验证目标明确降级为认知/影像/病变/行为级（§M13 诚实声明），假设-反证保持清晰 |
| 计算成本可控 | 139k 神经元 × 54.5M 突触 | GPU 仿真（有先例）；介观层成本低一个量级；铁律 C 决定保真度 |
| 数据可比性 | 不同品系/协议/品系间差异 | 固定实验协议；优先同源公开标准化数据集（IBL/Allen/FlyWire） |
| 多尺度可塑性同时引入会失稳 | 稳态/结构可塑性与 STDP 竞争 | 逐级引入 + 每级对应现象验证（T1 顺序：STP→STDP→稳态→结构→系统巩固） |
| 认知层无法由机制层支撑 | "从神经到认知"的鸿沟大于预期 | M13 反证输出缺失机制清单 → 反哺 M11/M12；清单即未来生物实验假设 |

## 十、与数字大脑项目的终极合并（"大脑的神经网络"落地形态）

| 维度 | 数字大脑（认知层 L8） | 生物仿真（机制层 L0–L7） | 阶段二合并点 |
|---|---|---|---|
| 层次 | 认知（图谱/激活/程序性记忆/推理） | 生理（通道→网络→行为） | L8 接口（M13/M14） |
| 输入 | 应用题文本 | 环境刺激（梯度/触碰/温度/视觉/嗅觉） | 同一虚拟生态 |
| 输出 | 数学答案 + 推理链 | 行为（运动/趋化/学习/决策） | 推理链可追溯至机制层 |
| 关系 | 上层认知 | 下层机制（先天硬件） | **合并为"从神经到认知"单链** |

**衔接点**：阶段一已把验证过的机制（趋化回路、CPG、习惯化）迁入数字大脑作为先天机制（B6）。阶段二在此之上完成**双向闭环**：机制层向上提供"可被认知层调用的表征"（如空间地图、工作记忆缓冲、状态变量），认知层向下提供"认知任务组"作为机制层的验证输入（M13 的 Pass 标准）。最终形态（M14）中，数字大脑的"数字从哪来"得到完整回答：**从离子通道到行为的确定性动力学中来**。

### 12.2 铁律 C 的第一次执行（M8 开工单）

- 在幼虫连接组上做三组缩放扫描并出曲线：
  1. **规模扫描**：神经元子集 300 → 1,000 → 3,016，记录行为复现度（曲线应为阶梯式跃升，跳变点即"关键回路"证据）；
  2. **保真度扫描**：点神经元 vs 双隔室 vs HH，记录行为+活动指标差异（决定 M9 用什么神经元模型）；
  3. **可塑性扫描**：无可塑性 → STP → STDP → +稳态，记录学习行为出现/消失的阈值；
- 三组曲线是 M9–M12 所有保真度决策的依据，也是最终"缩放定律"交付物的数据起点。
