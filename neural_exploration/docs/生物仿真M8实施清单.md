"多感觉整合 + 中央处理"——行为不再只是反射叠加；量化学习（嗅觉联想）需要哪些回路与可塑性。

**交付**：幼虫全脑仿真（行为 + 活动 + 扰动三通道验证报告）+ 铁律 C 三组缩放曲线 + 扰动预测命中率报告

### D2：幼虫连接组数据管线（Winding 2023 获取/解析/校验/递质标注；网络受限回退）

- **权威源**：Winding et al. 2023, *Nature*（"The connectome of the Drosophila larva"，
  3,016 神经元、~548,000 突触，L1 一龄幼虫 EM 连接组；含递质类型标注与仿真先例）；数据分发：
  L1EM CATMAID（Virtual Fly Brain 托管）与论文补充材料/静态导出；脑/VNC 分区、感觉/中间/运动类、
  递质（胆碱能/GABA/谷氨酸/多巴胺/血清素/章鱼胺/酪胺）标注。
- **落盘**：`data/m8_larva_connectome_raw.*`（原始数据 + provenance 注释）+ 解析产物
  `data/m8_larva_connectome.csv`（schema 沿 m5_connectome.csv 扩展：神经元行/化学突触行/缝隙行/肌肉行
  + larva 特有列：分区 brain|vnc、神经递质、受体映射）。
- **网络受限回退**：沙箱无法联网 → 论文补充材料/已发布数据表人工整理为同一 schema（CSV 头注释记录
  provenance/版本）；**计数以权威发布数为准**（M5 P1 纪律：不得为过 Pass 改权威数据）。
- **校验（P1 判据，`tools/build_m8_connectome.py` 内嵌断言）**：3,016 ±0；分区/功能类计数 vs 权威
  ±10%；化学突触 ~548,000 ±10%（突触计数与唯一有向对两套）；缝隙计数 vs 权威；递质/受体覆盖 100%；
  自连接/孤立白名单；SHA-256 确定性重跑；**与 M4/M5 已验子回路同源核对**（AWC 嗅觉链、IV 类伤害
  感受器链、运动命令池——连接存在性与极性，差异逐条入档，连接组是事实不动）。
- **递质 → 受体映射**：沿用 M2 组件语义（ampa/gaba/nmda + mod 占位），映射规则定稿于
  `data/m8_larva_params.csv`（receptor_map 行）；调质（DA/5HT/OA/TA）为功能门控语义（M6 惯例），
  不臆造受体作用域。

### D3：扰动预测协议（top-N 子集预注册 + 激活/沉默模拟 + ≥70% 命中判据）

- **top-N 子集预注册**（N=50）：选择规则（确定性，seed 固定，清单落 `data/m8_perturbation_plan.csv`）：
  ① **中枢命令样/下行神经元**（脑→VNC 投射，行为控制候选——对应幼虫命令神经元）；② **连接度枢纽**
  （入/出度 top 分位）；③ **实验可及性**（有文献驱动线/激活数据的神经元优先）；三层交集/并集由规则
  定稿（不事后改名单）。
- **模拟协议**：基线试次（无扰动）→ 对每个 i：**沉默**（该神经元 gmax→0 或超极化注入，预注册实现
  语义）+ **激活**（tonic 电流注入，预注册幅度/时长）→ 行为后果类（预注册类集：{无变化/前进↑/前进↓/
  转弯↑/停驻↑/蜷缩↑/后退↑}，按行为指标相对基线变化方向/幅度分类，阈值预注册）；sham 扰动对照
  （无注入 → 无变化，sanity）。
- **命中率判据**：命中 = 预测行为类与实验锚效应类一致；**命中率 ≥70%（有锚子集 ≥20/50 预注册）**；
  无锚神经元预注册 "no-experiment"（不入分母）；报告含逐神经元预测 vs 实验对照表 +
  `reports/neuro/m8_perturbation_hitrate.png`。
- **扰动图谱文献**：幼虫光/热遗传激活-行为筛选（"全神经元激活图谱"经典对象；驱动线激活行为模块
  研究 + 奖励/惩罚回路激活效应）；每神经元实验效应预注册为映射表（来源/品系/协议/效应类），
  入 `data/m8_perturbation_plan.csv`。

### D4：活动金标准（全脑活动状态序列 vs GCaMP 体积成像统计）

- **成像数据**：幼虫全 CNS GCaMP 体积成像（Lemon et al. 2015, *Nat Commun* 6:8924——一龄幼虫全 CNS
  功能成像范式）；网络受限 → 文献统计（预注册分布/状态占用）回退并如实登记。
- **活动正向模型**（`src/larva_activity.py`，规格公式）：
  `F_i(t) = Σ_k exp(−(t−t_ik)/τ_GCaMP)·1[t−t_ik>0]`（发放 → 荧光卷积，τ_GCaMP 预注册 0.5–1.5s，
  成像采样 1–2Hz 降采样）→ 逐神经元荧光序列 + 群体统计。
- **活动统计对照**：(a) 群体发放率分布（模型）vs 成像荧光事件率分布（成像）——KS p>0.05 或 <20% 偏差；
  (b) **行为切换状态序列**：自发 run↔turn 转换时刻对齐 ±2s 窗，窗内活动态序列（预注册活动态定义：
  全局活动水平分位 + 降维主分量符号）→ 转换条件发放率分布 KS 一致 + 状态占用/转换矩阵距离 < 预注册
  阈值（草案 ≤0.15，定稿于 CSV）；(c) 逐神经元对应不声称（测量限制，§0.7 #3）。

### D5：权重策略（连接组无权重 → 类级缩放 + M5 先验 + 行为学反推）

- **先验**：① M5 302 网络定稿权重（`data/m5_worm_params.csv` 权重行 + `load_weight_scales()` 返回的
  类级缩放/gap/syn_type/tonic/gL 杠杆）作为**同源通路**（命令池/运动池/感觉链同源）初始权重；
  ② Winding 2023 伴随仿真先例（原作者驱动连接组复现前进/后退）作行为锚（仅参考，不替代本实验
  逐层验证）。
- **类级缩放**：按 (pre 类, post 类) × 递质分桶（sensory→inter、inter→inter（脑/VNC 分区桶）、
  inter→motor、motor→muscle、MB 内 KC→MBON 专桶、下行/上行专桶…），每桶一个缩放因子 s_k
  （~20–30 个全局参数）；w_ij = w0_class · s_k——**不做逐突触拟合**（§0.7 #10）。
- **行为学反推**：以行为带为目标调 s_k（趋化 CI、逃避方向、自发分布、静息发放率、学习指数五目标
  联合），少量点（≤12 组合）× 降阶模型（1,000 档优先，3,016 档确认）→ 定稿
  `data/m8_larva_params.csv` 权重行；校准协议两阶段（numpy 行为参考快扫 → Brian2 少点确认，M5 §6
  模式）；校准失败 → 缺失机制记录 + 三态裁决（不静默）。

### D6：夹带双稳态正面设计（M-7 依据 + 三杠杆 + G1 门）

- **M5/M6 反证事实**：全互兴奋命令回路 + 运动池互驱 → 14–25Hz 共振极限环；调质门控只能整体开/关
  （14Hz→2Hz→静默），无『静息低活动 + 行为 bout』稳定中间态（m6_report §8 第 4 条）。
- **M8 正面设计（三杠杆，G1 门前逐一实现 + 消融 sanity）**：
  ① **命令层去同步**：幼虫连接组有**真实抑制性命令边**（GABA 能命令/抑制回路）——直接用真实递质
    抑制边（与 C. elegans g=0 占位问题不同），打破全互兴奋；
  ② **运动层与命令层分离驱动**：自发/调质输入作用于**运动输出层**（不注入命令池——M6 L9#1 教训：
    命令池注入每脉冲重新点燃夹带）；
  ③ **异质权重/传导**：类级权重 + 异质延迟（delay 分布按连接组事实/类级，M5 恒等权重教训的反面）。
- **G1 判据（双状态同时成立）**：静息静默比例落带（草案 [50,90]%，成像文献校准定稿）+ 自发分布落带
  （P4 带）；三杠杆各 enabled 开关消融 sanity（删杠杆 → 双状态破坏的断言）；G1 不通过 → 三态裁决。

- 基线试次 → 逐神经元扰动试次（每组 N≥3 试次，确定性）→ 行为后果类预测；

- sham 扰动 sanity（无变化）+ 确定性重跑；
- 输出：`reports/neuro/m8_perturbation_hitrate.png`（逐神经元预测 vs 实验对照表 + 命中率）+ `data/m8_p7_perturbation.csv`。

**验收**：命中率达标 + 逐神经元对照表完整；<70% → 反证排查（扰动协议/权重/活动耦合）→ 三态裁决。
