## 0. M7 目标与验收标准（Pass 定义）

**目标**（设计文档 §四 M7）：更复杂生物/应用迁移——**把验证过的生物神经机制（反射弧、趋化回路、
咽部 CPG、习惯化、联想学习、调质层）迁移回数字大脑项目**，作为其"先天感知/运动机制"的真生物来源
（回答"数字大脑的数字从哪来、先天结构从哪来"）；或扩展到果蝇幼虫/斑马鱼幼体复现 ≥1 种行为。
**交付**：机制模块 + 数字大脑接入 + 应用题测试通过；或更大生物行为复现报告。

**M0–M6 核心教训（本清单必须正面解决）**：
1. **"迁移"不是把 Brian2 网络搬进数字大脑**（M6 L7/L9 教训：夹带动力学、并发、数值语义全部
   Brian2 特有）：机制回迁 = **行为级等价抽象**（刺激→反应函数），神经实时动力学与符号推理
   语义不同——等价性判据用**行为量**（方向/增益/衰减/符号），不用神经量（发放率/PSP）。
2. **环境依赖分叉**（本节点实测）：`digital_brain` 依赖 networkx/pydantic/PyYAML，**不在
   `.venv-neuro` 中**（`ModuleNotFoundError`）——"117 测试全绿"判据的**可测性前提是先建立
   digital_brain 可运行环境**（预注册为 §0 #1 结构性限制）。
3. **只回迁已验证项**（M5/M6 反证纪律）：M5 夹带双稳态、M6 网络级 CI 读出不可见等反证项
   **不是**可回迁机制——如实交接为阶段二设计依据（m6_report §8 第 4 条），不作为 M7 交付判据。
4. **更大生物全脑不在 M7 预算**（阶段二 doc §五 M8）：果蝇幼虫全脑 3,016 神经元 / ~0.5M 突触
   是 M8 专属；M7 路径 B 只做**连接组数据管线 + 子图/降阶模型**（局部回路 ≤ 数百神经元），
   不跑全脑仿真（预算预注册 §0 #4）。

**Pass 标准（全部满足才进入阶段二；每项可测，禁止模糊标准）**：

**路径 A（主判据，推荐——机制回迁数字大脑）**：

      （候选池：触觉反射弧/嗅觉趋化/咽部 CPG/习惯化/联想学习/调质层），封装为**与 Brian2 运行时

### 判据可测性预注册（结构性限制，吸取 M3–M6 全部教训——判据设计时就要考虑模型结构性限制）

1. **数字大脑测试环境依赖（可测性前提，本节点实测）**：`digital_brain` 依赖 networkx/pydantic/
   PyYAML，`.venv-neuro`（Brian2 2.6.0 / numpy 1.26.4 / cython 0.29.37，py3.9.6）**无这些包**
   （collect 阶段 `ModuleNotFoundError`）。**预注册**：(a) M7 步骤 2 先建立 digital_brain 可运行
   环境——选项① 系统 python3（/usr/bin/python3 3.9.6，需装依赖）② 独立 venv（.venv-brain）
   ③ 装进 .venv-neuro（**须核对与 brian2 依赖兼容，避免污染神经仿真环境**）；(b) 环境建立后
   先跑 `pytest digital_brain/tests` 确认 117 全绿基线（G1 门）；(c) 数字大脑测试与神经仿真测试
   **环境分离执行**（不混合 pip 依赖），报告分别记录环境路径。
2. **机制回迁 = 行为级等价抽象（语义结构性限制，任务关键设计决策）**：神经仿真（Brian2 实时
   动力学：膜电位/发放率/突触权重）与数字大脑（符号推理：实体/程序/工作记忆）语义不同——
   回迁模块**不是**把 Brian2 网络嵌入数字大脑，而是把"已验证机制"提炼为**行为级接口函数**
   （刺激 → 反应/增益）。**预注册**：等价性判据用行为量（方向 D_peak 符号、CI 符号、衰减形状、
   Δw 符号、增益范围），容差与神经仿真冻结协议同判据带（M3/M4/M5/M6 报告数值，不重新跑协议）；
   神经量（发放率/PSP）仅作 informational 输出。
3. **回迁范围预注册（只迁移已验证项）**：可迁移候选池 = M3 反射弧（P1–P5 全过 32/32）、M4 趋化
   （P1–P8，P4 协议限制反证记录但机制验证）、M5 咽部 CPG（P3 通过 0.40/2.17Hz）、M6 习惯化
   （P3 机制级通过，测量限制记录）、M6 联想学习（P4 机制级通过，CI 读出限制记录）、M6 调质层
   （P2 反证记录型，机制落地+消融 sanity）。**M5/M6 反证未解项（夹带双稳态、网络级 CI 读出
   不可见）不入回迁池**——作为"哪些生物机制必不可少"清单（设计文档 §九）交接给阶段二。
4. **路径 B 预算预注册（更大生物的范围界定）**：果蝇幼虫全脑 3,016 神经元 / ~0.5M 突触不在 M7
   预算（阶段二 M8 专属，CPU 可实时但属整里程碑工作量）。**预注册**：路径 B = 数据管线 +
   局部回路降阶模型（≤ 数百神经元，M5 缩放定律下单试次秒级）；全脑仿真不纳入 M7 范围；
   路径 B 预算 ≤ 20 CPU-小时（数据管线一次性）+ 行为复现 ≤ 30 CPU-小时。
5. **应用题场景范围预注册（认知层能力边界）**：数字大脑当前能解"0–20/0–100 加减法 + 关系推理"
   类应用题（grade1_math/base_curriculum 知识包 + test_dag_reasoning.py 场景）。**预注册**：
   先天机制场景 = 在**现有认知范围内**加入"感知/运动底座"语义（如"闻到香味走向厨房"= 趋化
   驱动行为选择），**不**要求数字大脑涌现新推理能力；超出认知层能力的场景（如多步物理推理）
   不纳入 M7 判据（如实记录为测量限制）。
6. **冻结基线保护（组合不修改纪律，M5/M6 惯例延续）**：M0–M6 全部冻结文件（`src/` 下 M0–M6
   交付、`tests/`、`tools/validate_*`、`data/m0–m6 定稿 CSV` 含 `m5_connectome.csv` 内容不变）
   **零修改**；M7 **只新建**：机制模块（规格 `src/innate/` 或 `digital_brain/` 侧适配层，
   位置步骤 1 裁决）、`data/m7_*.csv`、`tools/validate_p7_*.py`/`run_m7_validation.py`/
   `gen_m7_report.py`。数字大脑侧同样遵守：既有 117 测试**零修改**（只新增文件）。
7. **确定性纪律**：机制模块确定性（无随机，参数从冻结 CSV 唯一定稿）；数字大脑确定性推理
   （solve 同输入同输出）；重跑逐位一致（M5 SHA 惯例）。
8. **三态裁决纪律**：任何预注册判据与实测不符 → 先排查（数据/协议/实现），超容差 → 如实记录 +
   三态裁决请求（① 接受反证记录 ② 调整机制/参数重新校准 ③ 缩小验证范围），不静默推进。
9. **语义边界预注册（不越界）**："先天机制"注入数字大脑 = 机制层提供感知/运动底座，**认知层
   推理链不被机制层替换**（不把符号推理改写成神经计算）——"从神经到认知"的完整合并是阶段二
   /终极目标（设计文档 §八），M7 只做**接口对接 + 最小验证**。
10. **计算预算（M4 L21/M5 L27/M6 L24 教训）**：路径 A 单试次轻量（模块级毫秒~秒，数字大脑
    solve 秒级）；路径 A 总预算 ≤ 10 CPU-小时；路径 B 按 §0 #4；编译纪律沿用（M7 无新 Brian2
    编译产物，除非路径 B 子图仿真——形状定稿后不变）。

## 关键设计决策（规划节点裁决，执行节点不得擅自变更）

### D1：路径选择——路径 A（机制回迁数字大脑）优先，路径 B（更大生物）为可选延伸

| 维度 | 路径 A（回迁数字大脑） | 路径 B（更大生物） |
|---|---|---|
| 科学价值 | **闭环**：验证过的机制 → 数字大脑"先天结构从哪来"（设计文档 §八 终极问题） | 规模扩展：幼虫连接组 → 行为复现（阶段二 M8 起点） |
| 与终极目标 | **直接一致**（两者最终合并为"从神经到认知"完整模型） | 间接（M8 起才进入主线） |
| 计算成本 | 低（模块级 + 轻量测试，≤10 CPU-小时） | 中（数据管线 + 子图仿真，≤50 CPU-小时） |
| 风险 | 语义映射（神经→符号）需行为级抽象（§0 #2 预注册） | 连接组数据解析工作量 + 行为复现不确定性 |
| 判定 | 主判据（P-A1 ∧ A2 ∧ A3 ∧ P5 ∧ P6） | 延伸（P-B1/B2/B3 任一满足即加分） |

**裁决：路径 A 为主线，路径 B 为预算内的预研延伸**（步骤 5，可选）。若执行节点实测 A 的
语义映射不可行（三态裁决①反证记录），则自动切换 B 为主判据（需 P-B1∧B2∧B3 全过）。

### D2：迁移机制清单（从 M3–M6 已验证机制提取；每项标注验证状态、封装接口、回迁接入点）

| # | 机制 | 验证状态（冻结报告） | 神经仿真接口（真实签名，已核实） | 回迁接入点（数字大脑） |
|---|---|---|---|---|

### 2.1 可移植机制模块接口规格（`InnateMechanism`——行为级抽象，纯 python，无 brian2 依赖）

```
InnateMechanism（接口规格，src/innate/ 或 digital_brain/ 侧，位置由 D3 裁决）:
  name: str                                    # 机制名（reflex/chemotaxis/cpg/habituation/
                                               #   associative/modulation）
  params: Dict[str, float]                     # 从冻结 CSV 提取（M3 reflex / M4 chemo /
                                               #   M5 behavior_ref / M6 learning_params）
  respond(stimulus: Stimulus) -> Response      # 环境刺激 → 行为反应
                                               #   reflex: 触碰强度 → 方向(back|none) + 强度
                                               #   chemotaxis: 梯度采样 → 趋利转向量（CI 语义）
                                               #   cpg: 时间 → 节律相位/频率（带宽）
                                               #   habituation: 刺激序号 → 反应幅度 R(n)（衰减）
  associate(cs, us) -> DeltaW                  # 联想学习：CS-US 配对 → 权重变化（Δw 语义）
  gate(motivation: float) -> float             # 调质门控：C_da/C_5ht/C_tyr → 增益（[floor,1.2]）
  reset()                                      # 试次开始：状态清零（确定性）
```

  联想：M6 Δw_train=+0.432、Δw_ext=−0.108（方向性判据，绝对值不作硬判据）；
  调质：M6 fwd_gate ∈ [tyr_floor, 1.2]、酪胺关 → gate≡1（消融 sanity 语义保留）。
- **参数定稿**：全部机制参数落 `data/m7_innate_params.csv`（唯一定稿源，位置解析沿用 M5
  `load_m5_worm_params` 惯例），模块只读 CSV 不硬编码。
