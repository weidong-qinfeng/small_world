## 六、主agent记录的方法学纪律（供 M10 承接）

1. **自检式判据设计**：判据必须**原则上可证伪** —— 例：三因子"无学习臂必须为 0"（P5）、
   环状吸引子"无输入时必须自持"（P6）。**"有输入时的行为"对任意跟随器成立，不可作机制证据**。
2. **判据口径与物理档可比性**：跨脚本/跨版本比较前必须核对**全部实验口径**（背景驱动、参数形式、
   反转电位）。主agent曾因三重失配（`g_ext` 480×、AHP 形式、探针版本）得出错误结论并**主动撤回**（L28.3/L28.4）。
3. **参数名变更 → 静默失效**：字段存在但在特定模式下不生效，比字段消失更隐蔽 →
   必须**读回断言** + **作用域守卫**（B2 已将教训转为代码级校验）。
4. **终止长任务前查进度**：主agent曾因仅看"运行 2.8h"误杀实际 82% 全绿的回归进程 →
   **"耗时长" ≠ "卡死"**；长任务须**直写日志 + 增量行 + 完成标记**。
5. **长协议一律分段调用**（`segment_steps`）+ 段间记录 RSS/ms-step；并知悉**分段调度存在
   0.2–0.7% NON_COMPOSABLE 依赖**（< 判据带容差，但须登记）。
6. **引擎改动必须重过对齐门**（§2.5）；**point 档改动不影响 two_comp 档对齐**时需显式声明范围论证。
