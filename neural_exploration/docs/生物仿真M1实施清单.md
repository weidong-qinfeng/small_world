## 2. 步骤 1：形态学与电学参数规格（1 天，纯文档 + 数据）

### 2.1 形态学规格（参照真实皮层锥体神经元简化版）

采用文献经典形态学（参考 Mainen & Sejnowski 1996 皮层锥体神经元多隔室模型，ModelDB 有完整参数）：
简化 6–10 隔室形态：

| 区段 | 隔室数 | 直径 | 长度 | 主动通道 |
|---|---|---|---|---|
| 树突（基树突合并） | 2–3 | 1–2 µm | 50–100 µm 每段 | Na/K（密度低于胞体，见 §2.3） |
| 胞体（soma） | 1 | 15–20 µm | 15–20 µm | Na/K/漏 全密度 |
| 轴突起始段（AIS） | 1 | 1–2 µm | 20–30 µm | Na 高密度（触发点） |
| 有髓鞘段 | 2–3 | 1–2 µm | 100–200 µm 每段 | **无**（被动，高绝缘） |
| 郎飞结（node） | 2–3 | 1–2 µm | 1–2 µm | Na 高密度（跳跃再发放） |

### 2.2 电学参数（HH 1952 通道 + 电缆方程）

```
C_m   = 1.0 µF/cm²        （沿用）
Ra    = 150 Ω·cm          （轴向电阻，皮层神经元典型值）
gNa   = 120 mS/cm²（胞体/AIS/郎飞结）  ENa = +50 mV
gK    = 36  mS/cm²        EK  = -77 mV
gL    = 0.3 mS/cm²        EL  = -54.4 mV
树突通道密度：gNa 降为 胞体的 10–30%（主动树突），gK 同比例
髓鞘段：gNa=gK=0（纯被动），可设 gL 极低（绝缘）模拟髓鞘
```

### 2.3 通道分布表（数据文件 `data/m1_channel_map.csv`）

每行：`segment, compartment_index, gna, gk, gl, diameter, length`
—— 用 CSV 驱动模型构建，保证可复现、可调参。

**验收**：CSV 存在且可被 `tools/load_morphology.py` 读入（见步骤 2）。

## 3. 步骤 2：多隔室参考解（1 天）

多隔室模型没有解析解，**参考解 = 高精度独立数值解**：

- 用 **NEURON 9.0.1**（M0 已装，多隔室最成熟）构建同一形态学/通道参数
- NEURON 用 `cvode` 变步长 + 高精度（`atol/rtol=1e-8`）作为"参考真理"
- 输出：胞体 V(t)、树突端 V(t)、轴突端 V(t) 三轨迹 → `data/m1_multicomp_ref.npz`
- Brian2 解（rk4, dt=0.01ms）与 NEURON 参考解对比，`waveform_rmse < 5%` 为 P2 判定

**注意**：这要求 NEURON 能跑通相同形态学——若 NEURON 形态学构建脚本与 Brian2 差异过大，
退化为"Brian2 高分辨率自检"（dt=0.001ms rk4 作参考），并记录为已知局限。

**验收**：`m1_multicomp_ref.npz` 生成，P2 判定脚本可运行。

## 4. 步骤 3：Brian2 多隔室实现（2–3 天）

### 4.1 代码结构

```
neural_exploration/src/
  morphology.py        # 形态学构建：CSV → Brian2 Soma/Cylinder 树
  ion_channels.py      # M1 正式实现：HH Na/K/漏 通道类（可配置密度）
  neuron_model.py      # 多隔室神经元组装：morphology + channels → SpatialNeuron
  neuron_model.py      # （同时保留单隔室版供 f-I 对照）
```

### 4.2 关键实现要点（M0 已踩坑的延续）

1. **Brian2 单位**：门控速率函数沿用 `hh_spec.py`（已无量纲化，M0 验证通过）
2. **SpatialNeuron 方程**：`dv/dt = (gl*(El-v) + ... + Ra_inv*(v_prev-v) + ...)`，注意轴向耦合项
3. **主动树突**：树突隔室也挂 Na/K 通道（低密度）——这是"主动树突"的关键
4. **髓鞘/郎飞结**：髓鞘段 gNa=gK=0（被动绝缘）；郎飞结高密度 Na
   —— Brian2 中不同隔室不同电导：用 `gna : 1 (membrane)` 声明为位置相关变量，按 CSV 赋值
5. **refractory**：沿用 M0 的 refractory=2ms（生理合理）
6. **注入刺激**：胞体电流注入（µA/cm² 或 nA，按面积换算）

### 4.3 冒烟测试

- 胞体注入 10 µA/cm² → 产生动作电位 → 沿轴突传导 → 郎飞结处依次再发放
- 断言：胞体发放数 >0、轴突末端发放数 >0、轨迹有限

**验收**：`tests/neuro/test_multicomp_smoke.py` 3 断言绿。

## 5. 步骤 4：逐项生理验证（2–3 天）

### 5.1 P2 波形误差（工具复用）
- `waveform_rmse(v_brian, v_ref, dt)` vs NEURON 参考解 → <5%

### 5.2 P3 f-I 曲线
- 注入电流扫描：0, 5, 10, 15, 20, 30, 40, 50 µA/cm²（或 nA 按面积）
- 每档统计发放频率（Hz）
- 判定：单调递增；阈值电流处从 0 到 >0；斜率与皮层神经元文献量级一致（~20–100 Hz 在 2–3× 阈值区间）
- 输出：`reports/neuro/m1_fi_curve.png` + 数值表 `data/m1_fi_curve.csv`

### 5.3 P4 树突→胞体 PSP
- 树突远端注入短脉冲（如 1ms）→ 胞体记录 PSP
- 判定：PSP 幅度衰减、时延（传导时间）与文献一致；时间常数 τ ≈ 5–20ms（皮层典型）
- 输出：`reports/neuro/m1_psp_propagation.png`

### 5.4 P5 轴突传导速度
- 测量：刺激胞体 → 记录轴突末端首次发放时间差 → 除以轴突长度
- 判定：速度落在 0.5–2 m/s（无髓鞘）或更高（有髓鞘跳跃传导）
- 输出：`data/m1_conduction_speed.csv`

### 5.5 P6 郎飞结跳跃传导
- 逐隔室记录发放时刻 → 验证：郎飞结依次发放、髓鞘段无主动发放
- 可视化：`reports/neuro/m1_saltatory.png`（各隔室 V 轨迹堆叠，显示"跳跃"）
- 判定：每个郎飞结都有动作电位，髓鞘段膜电位只被动波动（无全幅峰）

**验收**：P2–P6 五个验证脚本全部输出 + 判定通过记录在 `docs/m1_report.md`。
