### 0.4 铁律落地（M12 版，叠加阶段一 + 阶段二全部铁律）

1. **不跳层**：**G2-M 数据门 → G0-M 引擎门 → G1-M 区域工作点门 → C-M 区域耦合门 → L6 区域角色 / 行为 / 活动 / 扰动**。
   **G1-M ∧ C-M 不过 ⇒ P7–P11 协议不得定稿**（反面教材 = M9/M10 在未修复动力学上跑功能判据）。
2. **铁律 A**：**介观投射矩阵是"结构已知但权重未知"** ⇒ 用**图谱强度为自由参数**（设计文档第 215 行原文），
   每个抽象（区域内群体、区域间率/点混合、调质全局标量）逐项登记 `data/m12_abstraction_ledger.csv`（替代了什么/误差量级/回归条件）。
3. **铁律 B**：三通道（行为/区域活动/扰动）**必须同时在 M12 上成立**；任一通道回退到 `literature` 必须显式标注。
4. **铁律 C**：**1–5M 点神经元必须先做 ms/step 探针 + 尺度-功能曲线**（§3.4 探针计划），**禁止**凭 M9/M10/M11 锚外推放行（§7 纪律 9）。
5. **只为可验证而精细**：逐区域保留点神经元是**为了**区域级活动判据；树突/双房室仅经 P-EXT 回归通道引入。
6. **失败即反证**：任何 Pass 失败 → §6 反证设计逐条 + 缺失机制清单 + 三态裁决，**不静默重试**。
7. **确定性**：`PYTHONHASHSEED=0`；固定 seed；网络定义确定性哈希（禁 Python `hash()`）；跨后端只承诺统计级，同引擎同参数仅改分段 ⇒ **要求逐位**。
8. **判据带纪律**：全部带落在 `data/m12_targets.csv` / `m12_reference.csv` / `m12_equivalence_protocol.csv`，
   **协议运行前定稿**，修改**只允许新增行 + 保留原行**（append-only）。
9. **数据隔离**（设计文档 §6.2；M12 为**四通道 + 区域级隔离**，见 §0.8）。
10. **预算纪律**：**先探针 → 裁决 → 再烧**；超出包络**必须显式裁决**，**不得静默超支**。
11. **冻结基线保护**：M0–M11 全部冻结件**零修改**；M12 **只新建**（M11 §0.3 #11 沿用的"组合不修改"）。
12. **未测 ≠ 未命中**：预算/环境/门控/吞吐导致的未运行逐条登记 `unavailable` 并**排除出分母**。
13. **静默失效分级**：四态 `pass` / `fail` / `invalid` / `unavailable`；异常被吞成 `False`/半成品对象入统计 ⇒ `invalid`。
14. **机制结论前置断言**（R-5/R-6 的判据化）：作用域断言 + 最小阳性对照（sha256 不等）**缺一不可**。
15. **抽象登记册强制**（T3）：M12 的**每一个降档档位**（D1–D6，§3.5）都是一条抽象登记行。

### 0.7 科学假设（预注册，可检验，每条配反证路径）

- **H1（M12 总命题，铁律 A+B+C 的检验）**：在**介观级全脑结构 + 图谱投射权重 + 调质全局状态层**的约束下，
  500 区域 × 数千点神经元（1–5M）的确定性网络能**同时**复现：IBL 行为统计、**区域级**全脑活动统计、药理/损伤扰动效应。
  任一通道失败即反证 → 缺失机制清单。
- **H2（区域耦合可解释性；设计文档第 220 行反证首项）**：区域间加权投射（图谱强度 + ≤40 全局参数）**足以**复现目标数据的区域级活动统计。
  **否定形式**：参数拟合后仍不符 ⇒ "**介观抽象丢失了关键机制（如跨区域同步）**" ⇒ 对预注册子集回归局部精细模型（铁律 A 回归通道，P-EXT1）。
- **H3（L6 区域角色）**：存在一张**预注册**的 `区域 × 功能` 映射表（≥6 区域：皮层感觉/前额、海马、基底节、小脑、丘脑、脑干核团），
  使"灭活该区域 → 该功能的预注册指标按预注册方向变化"的命中率 ≥70%。
  **H3 的否定形式（假区域对照命中率 ≈ 真区域命中率）**= "区域分化是假的"（介观抽象把区域职责抹平）→ 缺失机制清单。
- **H4（T2 调质的必需性）**：DA/5HT/NE/ACh 全局状态变量是"探索/奖赏学习 + 策略切换"的必需条件；
  调质通路关闭 ⇒ 学习指数/策略切换率下降 ≥ 预注册带。**前置**：作用域断言 + 最小阳性对照（`sha256` 不等）。
- **H5（T1 系统巩固首次引入）**：海马→皮层重放（replay）是"习惯化与巩固"的必需条件；replay 关闭 ⇒ 延迟保留指数下降 ≥ 带。
  **前置**：replay 事件计数非零 + 作用域断言（否则 `MECHANISM_NOT_IMPLEMENTED`）。
- **H6（负向假设，诚实性）**：介观群体抽象（含 D4 率模型档）**不声称**逐细胞波形、树突计算、spike-timing 级 γ、单突触参数；
  违反即触发 P-EXT1 回归或抽象登记册更正。
- **H7（铁律 C 的尺度命题）**：功能指标随 N 档（0.25M/1M/5M）呈**单调或阶梯**变化，且存在"最小充分尺度"（给出可复现的三点曲线）；
  无曲线 ⇒ 不得声称缩放结论（M12 是设计文档 §7.2 第 299 行"单节点 GPU 小时级"的实测检验点）。
- **H8（负向假设，数据诚实）**：M12 的"全脑"= **500 区域介观抽象**，**不声称**突触级全脑连接组；
  区域级活动对照的可得性受 IBL 可达性约束——**若 IBL 活动数据 `unavailable（吞吐限制）`，则 P10 判 `unavailable` 而非 pass/fail**（M11 §7.3 #4）。

### 0.8 判据可测性预注册（结构性限制；M3–M11 全部教训的强制落地）

1. **口径一致才可比（EQ-1）**：跨脚本/跨入口/跨里程碑比较绝对量前，必须核对**测量窗口径 + 初值语义 + 单位**。
   M12 特有口径：**区域映射口径**（CCFv3 区域层级取到哪一级；500 区域是"汇总层级"还是"叶层级"）、**bin 宽**（活动率的分箱）、
   **试次对齐口径**（刺激 onset / 反应时刻）、**活动率口径**（spike count / window 还是 firing rate 平滑）、**药理学口径**（剂量/给药途径/行为时窗）。
   ⇒ 每条判据必须在 `data/m12_criteria.csv` 的 `calibration_note` 列**逐字写明**。
2. **绝对数值不可跨里程碑移植（EQ-2）**：**禁止**把 M9/M10/M11（及本清单内 M11 目标带）的任何绝对速度/相关/dwell/τ 作 M12 判据带。
   依据两条（M11 §0.7 #2 改写后的仍在事实）：① **可复现 ≠ 正确**（M9 绝对值是缺陷档，修正后 −24.7%）；② **跨物种/跨制备/跨口径不可移植**，
   M12 新增第三条：③ **跨尺度不可移植**（介观群体抽象改变慢状态结构与相关结构，M11 §10.4 明示"M11 的 S 门结论在 M12 尺度必须重测"）。
   M12 的带**只能**来自：（a）**M12 同口径实测量**（本项目自己算的 IBL/图谱统计）或（b）**逐条 provenance 化文献**（每行给 PMID/DOI + `value_verified`）。
3. **"分布一致"必须操作化为检验**：见 §1.2 的 F1–F6；**禁止**用 `p>0.05` 单独作为通过（样本量小则平凡成立）。
4. **样本量门**：每条判据给 `n_min`（由预注册 margin 反解的 80% power 或 bootstrap CI 宽度要求）；
   `n_valid < n_min` ⇒ 判 **`invalid`**（**不是** pass，也**不是** fail）——沿用 SESSION_CONTEXT §0 纪律 2。
5. **判据必须显式排除退化结构**（能通过 ≠ 排他；M11 §7.3 #2 + L25.1 cumsum 教训）：
   M12 强制两条**抗伪影判据**：① **声明域约束**（值必须落在 metadata 声明的取值域/物理域内）；② **非退化判据**
   （对"必然给出强相关/必然给出 0"的构造性结构必须给反例臂，如恒定高活动、恒定静默、单调累积）。
6. **负对照臂强制**（M11 §0.7 #5）：每条判据先跑"**应当给 0/不落带**"的臂；聚合落 `data/m12_negative_controls.csv`；
   负对照不过 ⇒ 该判据 `invalid`。M12 的负对照清单见 §5.4。
7. **机制级阴性结论的三层前置断言**（SESSION_CONTEXT §0 D1 家族协议）：① 接线（读回断言）② 实现（引擎内该状态变量确有动力学）③ **动态范围**（`std` 落量级门，**仅 >0 不够**）。
8. **量纲自检（每个"率/计数/积分"量）**：`率 × T = 计数`；`相关 ∈ [−1,1]`；`dwell ≥ 采样间隔`；`权重 ∝ 投射强度分位`；
   能量的单位与符号约定（沿 M1/M2 教训）。每条判据给一条 `dimension_check` 表达式（写入 CSV 列），并在验证脚本中断言。
9. **同一量的两个独立估计器必须断言一致**：M12 的配对至少三对：
   ① 区域率 = `spike 计数 / T`（估计器 A）vs 群体平均瞬时率的时间平均（估计器 B）；
   ② ms/step = **探针直接实测** vs **拟合模型 `t = a + b·N + c·E` 的 held-out 预测**；
   ③ 区域间权重 = 图谱强度归一（A）vs 由 IBL 活动相关反解的权重（B）（**允许不等，但必须报差异并解释**：这正是 C-M 要判的东西）。
   任一"配对未断言"⇒ 视为埋着的 bug 检测器未启用（SESSION_CONTEXT §0 纪律③）。
10. **长任务/设备纪律**：**MPS 作业严格串行**（并发实测 `ms/step` **2.4 → 14.1，6× 退化**）；CPU 作业设 `OMP_NUM_THREADS=1`；
    **>10 min 的作业由主 agent 以托管后台作业启动**；**判断进度看"累计 CPU 时间 / 墙钟"之比，不看 `ps %CPU`**（macOS 近期采样）。
11. **判据命名必须与实测范围一致**（M11 §7.3 #3）：例如**不得**把"关闭区域间投射臂 ≡ 单区域基线"表述为"图谱权重下的区域耦合对齐"。
    M12 的命名规范：`P{k}-[{覆盖范围}] {量} {检验形式}`，覆盖范围必须写明**区域数 / session 数 / 可达子集**（如 `P10a-[IBL bw 可达 S session / 区域级]`）。
12. **引用纪律**：引用本清单或其他笔记中的分析结论时，凡**未亲自复算**的一律标 **`unverified（来源文件 + 行号）`**；判据带中 `unverified` 行**不得**作为带。

### 0.10 计算预算先例与纪律（M9/M10/M11 实测锚 → M12 预注册）

- **实测锚（全部 `unverified（继承）`，来源 `data/m11_engine_probe.csv` / M10/M9 记录）**：
  M9 139,255 point **0.42–1.02 ms/step**（静息定稿 0.898）、规模分解 `t = a + b·N`（a = 0.29–0.07 ms、b = 3.3–5.2e-6 ms/神经元/步）；
  M10 100,000 / 2M 边 **1.4285 ms/step**、RSS 2.2 GB；
  M11 三档 8,192 / 31,000 / 75,909 = **0.6615 / 1.1362 / 1.7165 ms/step**、RSS 630 / 877 / 1,222 MB、30 s 单试次 0.11 / 0.19 / **0.2861 GPU-h**。
  **由 M11 三档直接算出的斜率** `b ≈ (1.7165−0.6615)/(75,909−8,192) = 1.56×10⁻⁵ ms/神经元/步`（**本轮由表内数字自行相减，`derived（本轮复算）`**）。
- **⚠️ 外推禁区（本清单最强约束之一）**：M12 的 1–5M 档是**实测范围（≈8k–139k）之外 7–40 倍**；

  **该数字不得用于放行协议**——必须由 §3.4 的**三档探针实测**替换（内存带宽、核函数实现、区域间稀疏度都会改变斜率）。
- **预算模型（必须写在报告中）**：`GPU-h = Σ_档 Σ_条件 Σ_试次 [ N_steps(T, dt) × ms_per_step(该档实测) × 3.6e-6 × (1 + 消融臂数) ]`
  （换算常数 `GPU-h = ms/step × steps / 3.6e6`，与 M11 §3n 采信形式一致；**M11 §3n 发现 B 的疑点已被主 agent 核查为"未在清单中找到该常数"⇒ M12 直接采用清单内自洽形式**）。

### 1.2 ★ Pass 线 `p>0.05 或 <20%` 的操作化（**全 M12 判据统一统计口径**）

> **设计文档原文（第 250 行 / 第 266 行）**：行为金标准 = "仿真与真实生物的行为指标分布**统计不可区分**（`p>0.05` 或 `<20%`）"；
> M12 行 = "行为 + 区域活动 + 扰动效应 ⇒ `p>0.05` 或 `<20%`"。
> **问题**：`p>0.05` 单独使用**不是等价证据**（样本量小 ⇒ 平凡通过；"未测 ⇒ p 未知 ≠ 未命中"）。
> ⇒ 本清单定义 **F1–F6 六种判据形式**；每条判据必须**显式指定**其形式与参数，全部写入 `data/m12_criteria.csv`。

| 形式 | 适用量 | 判定式（**可计算**） | 不通过/失效条件 |
|---|---|---|---|
| **F1 等价检验（TOST）** | 连续/分布型指标（率、RT 分位、相关、dwell） | 预注册 margin `δ`（**优先用相对 margin**：`δ_rel = 0.20 × ref`；若跨零量则用标准化 margin `δ_std`）。**等价 ⟺ `max(p_low, p_high) < 0.05`**；同时**必须报告** `δ`、`Δ̂`、`CI95`、`p_low`、`p_high`、`n_sim`、`n_data` | `CI95` 宽度 > `2δ`（信息不足）或 `n_valid < n_min` ⇒ **`invalid`**（不得当成 pass） |
| **F2 相对偏差（`<20%` 支路）** | 单点量（斜率、阈值、命中率、耦合系数） | `|θ̂_sim − θ_ref| / |θ_ref| ≤ 0.20` **且** bootstrap（≥10,000 次）**95% CI 上界 ≤ 0.20** | 若点估计 ≤20% 而 CI 上界 >0.20 ⇒ 判 **`invalid`（样本量不足）**；若 `θ_ref` 不可得 ⇒ `unavailable` |
| **F3 优越性（信息类）** | 解码准确率、互信息 | `acc_sim ≥ acc_min`（预注册下限）**且** `acc_sim > Q95(置换零分布)`（`n_perm ≥ 1,000`，同管线同管线长度） | 未跑置换臂 ⇒ `invalid`；`acc_min` 无 provenance ⇒ `invalid` |
| **F4 命中率（扰动）** | P11 | Clopper–Pearson 95% CI **下界 ≥ 0.70**（或 ≥预注册锚级下限，如"有锚 ≥20/50"）；**分母预注册**，`unavailable`/`injection_ineffective`/`no-experiment` **不入分母** | 分母 < 预注册 `n_min` ⇒ `invalid`；把 `unavailable` 计入分母 ⇒ **该判定作废**（"未测 ≠ 未命中"） |
| **F5 机制归属（消融/关闭臂）** | 全部机制类结论（H3/H4/H5） | **三层断言齐备**：① 作用域断言（读回 + 表达式级）② 最小阳性对照（开/关两臂**逐位不同**：`sha256` 不等 **且** 目标量变化 > 带/2）③ 动态范围（`std` 落量级门）。全过后再判"机制有效/无效" | 任一层不过 ⇒ 记 **`MECHANISM_NOT_IMPLEMENTED`**（**不是** fail，**不是**反证） |
| **F6 方向性（文献定性）** | 区域角色（P7）、药理方向（P11） | `方向一致率 ≥ 0.70`（预注册方向表逐行给"预期方向 + 依据 PMID/DOI"）；若幅度带可得 ⇒ 叠加 F1/F2 | 方向表事后修改 ⇒ 该轮 `invalid`（方向表必须运行前定稿） |

**统一附加条款（对 F1–F6 全部适用）**：
1. **口径声明**：比较前必须核对 §0.8 EQ-1 的**全部口径项**（区域映射层级 / bin 宽 / 试次对齐 / 率口径 / 药理口径）；
   `calibration_note` 列逐字写明；**口径不一致的比较结果判 `invalid`**（不允许"粗略比较"）。
2. **样本量门**：每条判据给 `n_min`（由 `δ` 反解的 80% power **或** bootstrap CI 宽度要求），并报 `MDE@n_min`；
   `n_valid < n_min` ⇒ `invalid`。
3. **多重比较**：按**预注册 family**（如 P8-行为 family 的 5 个指标；P10-活动 family 的 3 个指标）用 **Holm–Bonferroni** 校正；
   报告 raw p 与 adjusted p；**family 必须在运行前定义**（禁止"20 个指标挑 1 个通过"）。
4. **边界可达性自检**（M10 L20.3 / M11 §0.7 #4）：把**目标数据**按区组随机劈两半，用**同一协议同一 margin** 判等价 ⇒ **必须通过**；
   不通过 ⇒ margin 或指标口径重定稿（**在跑模型之前**）。
5. **判据带 `final=1` 才可入判定**；`evidence_level=unverified` 的行**不得**作带（M11 R-21 纪律）。
6. **`p>0.05` 永远不能单独作 pass**：必须与 `CI95` 或 `MDE` 或 F1 的 margin 一并报告。

### 2.1 ★ 取数判定的唯一规则："可达 ≠ 可行"（本机纪律的判据化）

> **来源**：`SESSION_CONTEXT.md` §0 算力纪律 + `m11_acceptance_master.md` §7.3 #4 + §3p/§3r 裁决。
> **本机已记录的事实（全部 `unverified（继承）`——本清单未亲自复测吞吐）**：
> ① 对 S3 **10–17 KB/s**（主 agent 实测，M11 §7.3 #4）；② 同源 S3 在数小时内 **194–349 KB/s → 16 KB/s**（L9.3 / L22.9）；
> ③ DANDI 路由 **7,237 B/s**；④ `api.brain-map.org` **1.6 KB/s**（DQ-6 停滞于 3.3%）→ 另处记录 **16 KB/s**（L28.2）；
> ⑤ GCS `iarpa_microns` 的 info 首字节 **5.6–8.9 s**（连元数据小文件也慢）；⑥ M10 曾实测 GCS **2.8–4.0 MB/s**；
> ⑦ **8 路并发 Range 持续 17 min 仅聚合 ≈10–16 KB/s**（各分片 ≈1.2 KB/s，DQ-4）；⑧ Europe PMC 每次查询 ~1–2 s。
> ⇒ **吞吐在本机是时变的、跨时段可差 10–100×** ⇒ 任何"按早前吞吐推算的工期"都会失效（L22.9）。

**强制流程（每个源的每一步都要走完）**：

| 步骤 | 动作 | 硬条款 |
|---|---|---|
| **T1 列举/计数** | 桶 `list-type=2` 前缀列举 **或** API `count$eqtrue` 单次查询拿**对象数/行数** | 列举 `truncated=true` 或 `KeyCount=0` 时**不得**当作"数据可得"（L9.2 #4 `REACHABLE_NO_DATA` 陷阱） |
| **T2 对象级取证** | `curl -r 0-1023`（HEAD/Range）拿 `HTTP 200/206` + `content-length` + `content-type` | **父进程硬回收**（`Popen + communicate(timeout) + kill()`）——`curl --max-time` 实测失效（挂死 **925.9 s**，L9.3a） |
| **T3 吞吐实测** | `-r 0-1048575`（1 MiB）取 3 轮，取**中位** `speed_download`；**先测吞吐再决定取数** | 记 `speed_Bps` 落 `data/m12_source_reachability.csv`；**单流慢 ⇒ 试 4/8 路 Range 并发**，但**绝不同时起两个大作业**（L9.3c） |
| **T4 ETA 裁决** | `ETA_s = bytes / speed_Bps` | **`ETA_对象 > 30 min` 或 `ETA_总计 > 4 h` ⇒ 判 `unavailable（吞吐限制）`**（"可达 ≠ 可行"）；`30 min < ETA ≤ 4 h` ⇒ 需**主 agent 托管作业** + 断点续传 |
| **T5 内容级证据** | 解压/解析 + **尺寸自洽**（`raw == 期望元素数 × 元素字节`）+ SHA-256 | 完整性门 5 步 = `http → 大小 → SHA256 → 解压/解析 → 尺寸自洽`；**`curl_exit==0` 强制**；`INCOMPLETE/MISSING` **不得进统计**（L25.4 / R-10） |
| **T6 装配可行性** | **M12 新增第 4 层**：该对象能否**装进模型**（矩阵稀疏度、内存、装配时间） | 若"取得到但装不进"⇒ 判 `unavailable（装配不可行）` 并给降级（这是 M12 特有的第四种"可达≠可行"） |

## §3 引擎门（G0-M，P3 验证对象；6–10 天，含探针）

### 3.1 ★ 介观降阶框架的选型裁决（自研 spiking vs Nengo 风格群体/率模型）

设计文档第 286 行原文："M12（小鼠全脑介观）｜**介观框架（自研或 Nengo 风格群体/率模型）+ 调质状态层**｜~500 区域 × 数千点神经元 ≈ 1–5M 点神经元，单节点 GPU 可行"。
**"自研或 Nengo"是一个待裁决项** ⇒ 本清单预注册**三候选 + 探针驱动的裁决规则**（**先探针 → 再裁决 → 再烧**）。

| 候选 | 内容 | 与既有已验证栈的关系 | 保真度代价（抽象登记册预登记） |
|---|---|---|---|
| **A（默认，主路线）自研 spiking 点神经元内核** | 扩展现有 torch-MPS 内核（R-2/R-3）：区域槽 + 调质槽 + 慢变量槽；区域间投射为**加权稀疏 CSR**（延迟打包 2–4 档） | **同族** ⇒ 可复用 M11 的对齐门 (a)–(h)、分段/跨进程/密度复测范式、判据管线 | 点神经元 ⇒ 不声称树突/波形；介观群体 ⇒ 不声称逐细胞 |
| **B（降档）率/群体模型（Nengo 风格）** | 每区域一个率群体（NP/rate）或每区域多个率单元；区域间为加权率投射 + 延迟 | **异族** ⇒ 对齐门需自建（对 LIF 稳态解/解析解对齐）；**不能**复用 spike 级判据 | 🔴 **不声称** spike-timing、γ 谱、dwell（spike 门控）、脉冲级相关；P10a 的"率分布"仍可算（率域），但 P10c 的"任务依赖动力学（状态转换）"须换成率域口径并**重定稿判据带** |
| **C（混合）区域内 spiking + 区域间率/事件节流** | 区域内保留点神经元（数千个），区域间投射降为率或**节流事件**；调质层为全局标量 | 部分同族（区域内可复用对齐门）；区域间为异族 | 中间档；必须**分列**"区域内 spike 统计"与"区域间率统计"，**不得**把两者混成一个"活动统计"判据 |

**裁决规则（预注册；一次探针定档，档位是 P3 协议的一部分、必须显式登记）**：

| 条件（以 §3.4 探针实测为准） | 裁决 | 理由 |
|---|---|---|
| 1M 档 **ms/step ≤ 8** 且 RSS ≤ 24 GB ≈ 且 5M 档 ≤ 40 ms/step 且 RSS ≤ 30 GB | **选 A 全档（1M 主档、5M 目标档）** | 与已验证栈同族，判据与对齐门全复用 |
| 1M 档 **8 < ms/step ≤ 16**（或 RSS 24–30 GB） | **选 A（1M 主档）+ 5M 仅探针/关键条件**；区域间投射稀疏度上调（E/N 从 50 → 20） | 保判据、牺牲规模档 |
| 1M 档 **> 16 ms/step** 或 RSS > 30 GB | **选 C**（区域内 spiking 降到 500–1,000/区域 + 区域间率）**或 降 N 到 0.25–0.5M** | 先保判据可算，再保规模 |
| 5M 档不可行且 **1M 也不可行** | **选 B**（率模型）+ **判据带按率域重定稿**（运行前）+ 抽象登记 | 率模型是本里程碑的**诚实降档**，不是失败；但**必须**写明"P10c/P12 的 spike 级子判据 `unavailable`" |
| **Nengo 依赖问题** | 若选 B 但需引入 Nengo 系依赖 ⇒ **新增依赖必须逐项登记**（M11 L5 纪律）；**优先用纯 torch 实现率模型**（零新增依赖） | 依赖最少的实现风险最低 |

> **强制前置**：任何档位裁决**之前**，必须先完成 §3.4 探针；**禁止**用 §0.10 的线性外推（1M ≈ 16 ms/step、5M ≈ 78 ms/step）直接裁决（那是 `derived（本轮复算，仅供量级参照）`）。

### 3.2 介观内核扩展（E1-M–E5-M；逐项标注复用/扩展/新建）

| 扩展 | 内容 | 判定 | 理由 |
|---|---|---|---|
| **E1-M 区域槽（`region_id`）** | 每神经元标注所属区域（0..R−1）；区域槽用于**区域级读出**（率/相关/事件）与**区域级扰动**（灭活/激活整区） | **新建** | 设计文档第 218 行要求"区域发放率、抉择相关活动"⇒ 区域级读出是判据的**基础设施**；且 P7/P10 需要"区域"作为一等对象 |
| **E2-M 调质全局状态层（DA/5HT/NE/ACh，T2）** | 4 个全局（或按核团源局部）状态变量 + 逐区域增益表（`gain[mod, region]`）；支持"通路开关"与**读回断言** | **扩展**（`src/neuromod.py` 语义 + M11 慢变量槽范式） | 设计文档第 215 行原文"调质系统全局调制（T2）"；且 **R-5（A10 作用域）**要求每条调质通路有作用域断言与最小阳性对照 |

| **E4-M 慢变量槽（T1/T2 的载体）** | 逐区域（或逐类）慢状态 `s_r(t)`；H→C replay 事件注入接口；**读回 + 动态范围（std 落量级门）断言** | **扩展**（E2b 范式） | M10 M-4 的失败模式 = "慢变量未接线" ⇒ 必须是**内核级可读量**（§0.8 #7 三层断言） |

- **融合/向量化纪律**：沿"融合内核 + 事件投递向量化 + **改后重过对齐门**"；**禁止用隔离吞吐基准推断逐步依赖内核墙钟**（M9 L20.2#6 反例）。
- **缓存纪律**：**任何以"每次调用的动态规模"为键的缓存都是 bug**（M9 真 bug）⇒ 新内核过**无泄漏自检**。

### 3.3 引擎正确性验证（G0-M）

- **参考模型**：① M9 冻结 300 two_comp 定稿配置（CPU Brian2；**稀疏工况**，"非投递语义不动"）；② **LIF 解析解**（单神经元 + 两神经元链；不依赖 Brian2 安装）；
  ③ `data/m11_engine_probe.csv`（同族引擎的三档墙钟与 RSS，仅作**量级参照**）；④ **M12 新增：区域级目标密度判别网络**（区域率分布 + 同步发放率取自 M12 目标带）。
- **对齐判据（预注册；(a)–(h) 沿 M9/M10/M11，(i)(j) 为 M12 新增）**：
  - (a) **逐神经元 spike 时间对齐**：≥99% spike 时间差 <0.1 ms（GPU 浮点重排为测量限制，**逐位不承诺**）；
  - (b) **状态比例**：静默比例差 <1 pp；率分布 **KS p>0.05**；⚠️ **范围声明强制**：若该臂是"关闭态"臂 ⇒ **判据名必须写"关闭态 ≡ 单区域基线"**，**不得**表述为"目标密度下活动统计对齐"（M11 §7.3 #3）；
  - (c) **机制指标**：同输入/seed 下，调质/慢变量级电导积分与 PSTH 形状一致（Δ < 带）；
  - (d) **确定性**：同引擎同参数重跑逐位/统计级一致；
  - (e) **分段可组合性**：`k=1/2/5` 分段 ⇒ 总脉冲与逐神经元计数**逐位相同（0.0%）**；⚠️ 必须 `ext_abs_index=True`（E-M10-1）；
  - (f) **同步发放判别**：构造"同一步 ≥2 源神经元持续发放"的网络 ⇒ M12 内核必须正常（M9 冻结内核在此必须报错/异常，作判别对照）；
  - **(g) 目标密度复测（M9 §10 铁律）**：在**区域级目标密度**下重跑 (a)–(c)（该密度由 §2 的 IBL 区域率带给出；若 IBL 不可得 ⇒ 用 `literature` 区域率并**在判据名中标注证据等级**）；
  - (h) **跨进程一致性**：≥3 个**独立新进程**、同一网络/事件表/seed ⇒ **脉冲总数逐位相同**；
  - **(i) 区域槽守卫（M12 新增）**：`region_id` 槽关闭但存在跨区域边 ⇒ `finalize()` **必须拒绝**（同型于 R-3 的 `syn_class` 守卫）；
  - **(j) 调质槽守卫（M12 新增）**：调质通路关闭但存在 `mod_id>0` 的调制边 ⇒ **必须拒绝**；且**逐通路最小阳性对照**（开/关两臂 `sha256` 不等）。

  - **E1-M 关闭**（区域槽归并）⇒ 必须退化回 M11 语义（**逐 spike 一致**）；

### 3.4 ★ ms/step 探针计划（**不得凭锚外推**；P3 的核心实测项）

**目标**：用**本机 MPS 实测**决定 ① 定档（§3.1）、② 单试次预算、③ 降档菜单触发点。**探针未出结果 ⇒ 功能协议不得定稿**。

| 维度 | 预注册档位 |
|---|---|
| 规模 N | **{0.25M, 0.5M, 1M, 2M, 5M}**（5 档；由"R × 每区域点数"实现：R ∈ {200, 500} × 点/区域 ∈ {500, 1000, 2000, 5000, 10000}） |
| 稀疏度 E/N（区域间入度上限） | **{20, 50}** 两档（区域间投射是全连接核的替代 ⇒ 入度上限是**必须预注册的自由度**） |
| 状态档 | **{on（区域间投射 + 调质 ON）, off（区域间投射关闭）}** 两档（沿 M11 的 on/off 口径；**off 臂更活跃会显得更慢 ⇒ 不构成内核更贵的证据**，M11 §2.3 口径警告） |
| 分段 | 每臂 **≥3 段**（每段 ≥2,000 步），取**稳态** ms/step（**禁用段 0 / 试次 0 预热值**） |
| 重复 | 每档/每臂 **2 个独立新进程**（跨进程一致性 + 抖动估计） |
| 生理标定 | **探针网络必须标定到生理活动区**（M10 L18.4）：预注册目标 = 区域平均率 **1–5 Hz**、静默比例落带；落 `spk/neuron` 列以证标定 |
| 记录 | `ms/step`、墙钟、`RSS`、`driver_allocated`、对象数、段间残差、`spk/neuron`、`edges`、`delay_groups` |
| 并发 | 🔴 **MPS 严格串行**（并发实测 `ms/step` **2.4 → 14.1，6×**）；开跑前 `ps aux | grep` 查同名进程；违规 ⇒ 该轮 `invalid` |
| 成本上界 | 5 档 × 2 稀疏度 × 2 状态 × 3 段 × 2 进程 = **120 段**；按段长 2,000 步、最慢档 100 ms/step 计 ⇒ **单段 ≤200 s** ⇒ **总墙钟 ≤ 6.7 h（上界）**，对应 **GPU-h ≤ 6.7**（上界） |

**探针的两个独立估计器必须一致（§0.8 #9 的强制落地）**：
① **直接实测**每档 ms/step；② 用 {0.25M, 0.5M, 1M} 三档拟合 `t = a + b·N + c·E`（或 `a + b·N + c·(N·E)`），
在 **held-out 档 {2M, 5M}** 上预测 ⇒ **预测与实测相对偏差 ≤ 15%**；否则判 `invalid` 并重跑（**不得**用拟合值代替实测放行）。
**产物**：`data/m12_engine_probe.csv`（逐档逐臂 + 拟合系数 + held-out 误差）+ `reports/neuro/m12_engine_probe.png`（ms/step vs N 曲线 + RSS vs N + held-out 对照子图）。

| **D6** | 云 GPU（成本/配额裁决） | 前五者皆不可行且判据必需 | **主 agent 裁决**；云环境纪律（确定性、日志、产物回传 SHA 校验、逐子进程隔离）预注册 |
| — | **CPU 兜底** | — | **仅用于对齐与探针**，**不承担**全规模功能协议 |

**硬条款**：**任何降档都必须重过该档的 G0-M（对齐门 + 守卫 + 探针）与 G1-M/C-M**（工作点与耦合随 N/档位变——这正是 M12 要判的事）；
降档**不得**静默发生，且必须在 `data/m12_abstraction_ledger.csv` 有对应行。

### 3.6 引擎冻结为基线

对齐 + 探针 + 定档通过后，M12 内核**冻结为 M12 基线**（版本/参数/kernel 定稿于 `data/m12_engine_params.csv`）；
任何改动（kernel/优化/参数/机制开关/稀疏度）必须重过 (a)–(j) + 关闭态等价 + 槽守卫 + 参数审计；
若改动仅影响某档 ⇒ **显式范围论证**，否则全门重跑。

**验收（P3）**：`src/mouse_brain_engine.py` + `data/m12_engine_params.csv` + `data/m12_engine_probe.csv`（5 档 × 2 稀疏度 × 2 状态 × 3 段 + RSS）
+ `data/m12_slot_assertions.json`（区域槽/调质槽/慢变量槽断言）+ `data/m12_param_audit.csv` + `reports/neuro/m12_engine_alignment.png`（对齐/密度/分段/跨进程四子图）
