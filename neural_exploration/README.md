# neural_exploration — 神经网络探索（从单神经元到行为）

本目录是**独立于数字大脑（digital_brain）认知层**的神经网络探索工作区。
目标：自底向上搭建尽量复刻真实生物神经系统的电子神经网络，以生物行为为验证标准。

## 目录结构

```
neural_exploration/
  docs/     # 设计文档（整体实验设计、M0 实施清单、混合架构方案）
  src/      # 仿真核心代码（离子通道 → 神经元 → 突触 → 回路 → 连接组 → 行为）
  tests/    # 每层生物验证测试（波形对照、反射弧、趋化、习惯化…）
  tools/    # 引擎基准、指标计算、参数拟合、可视化
  data/     # 行为学/电生理对照数据（HH 1952、C. elegans 行为学…）
```

## 实验铁律

1. **自底向上，逐层验证**：每层必须通过该层的生物对照验证才能进入下一层
2. **保真度与验证绑定**：只为可验证而精细，不为精细而精细
3. **失败即反证**：某层不通过是有价值的科学结论，不是实验失败
4. **确定性 + 局部物理随机**：神经元动力学用确定性方程；突触量子释放用局部概率模型
